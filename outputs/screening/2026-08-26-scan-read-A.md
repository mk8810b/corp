### 株価データ取得不能の原因

2026-08-25引け後の開示のため、当日の株価反応（終値・前日比・出来高）の確認が必要でしたが、以下の技術的制約により取得に至りませんでした。

**試行方法**：  
```bash
curl -sS --compressed -A "Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36" \
  "https://kabutan.jp/stock/kabuka?code=4424&ashi=day" -o 4424_kabutan.html
```

**結果**：  
- HTTP ステータス 200、HTML取得成功
- ただし、取得された HTMLには最新の日足データ（2026-08-25）が含まれていない
- 日付 2026-08-25 の検索では未検出
- 最後のデータ行は 2026-07-13 の日足情報

**原因推測**：  
kabutan.jp のサーバサイドレンダリングでは、日足テーブルの一部の行を動的に（JavaScript側で）読み込んでいる可能性があり、`curl` の単純な GET では完全なテーブルが返らない。同サイト側のポリシー変更（bot遅延ポリシー）または API の可用性制約の可能性。

**代替案（未試行）**：  
- Yahoo!ファイナンス 等の別データソース
- selenium等のブラウザ自動化による完全なレンダリング取得
- TDnet開示元のサイト内に過去の株価データが含まれているか確認

**結論**：  
2026-08-26 の朝スキャンルーチン試験運用では、開示当日の株価反応確認ができなかった（データソース技術的制約）。本報告書では「取得不能」と明記します。
