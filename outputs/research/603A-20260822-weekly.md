### 2-2. 発行目的（原本記載）— オーバーアロットメントの決済であり、独立の資金調達イベントではない

原本本文:

> 「当社では、当社普通株式の東京証券取引所グロース市場への上場に伴う公募による募集株式発行並びに
> 引受人の買取引受による株式売出しに関連して、野村證券株式会社を売出人として、当社普通株式1,611,000株の
> 売出し（以下「オーバーアロットメントによる売出し」という。）を行いました。本第三者割当増資は、この
> オーバーアロットメントによる売出しに関連して、**当社株主である伊藤忠商事株式会社より借入れた当社普通株式の
> 返却を目的として**、野村證券株式会社に対し行われるものです。」

**これは日本のIPOで一般的に用いられるグリーンシューオプション（オーバーアロットメント）の標準的な決済
スキームである。** 主幹事証券（野村證券）が既存株主（伊藤忠商事）から株式を借りて追加売出しを行い、
その返却原資として会社が新株を発行する。有価証券届出書（`https://disclosure2.edinet-fsa.go.jp/`、
EDINET docID S100YL2O、6節参照）で伊藤忠商事が2025年1月6日付で普通株式5,435,000株を保有する
大株主上位10名の一員であることを確認しており、貸株関係と整合する。**本件は2026年6月25日・7月10日の
取締役会で既に決議され、IPO時の有価証券届出書で開示済みの仕組みの結果確定報告であり、本日新たに
決定された資金調達ではない。**

### 2-3. 希薄化率（自社Python再計算）— BUY方向の材料ではない。規模を確定させる

```python
pre_shares = 34_799_000   # 増資前発行済株式総数（原本記載）
allot_shares = 1_581_000  # 発行株式数（原本記載）
post_shares = 36_380_000  # 増資後発行済株式総数（原本記載）
print(pre_shares + allot_shares == post_shares)      # -> True（整合確認）
print(round(allot_shares / pre_shares * 100, 3))      # -> 4.543
```

**対直前発行済株式数比の希薄化率: 4.54%。** 調達額（払込金額の総額）は9.944億円。
資金使途は原本記載により「設備投資（関連費用含む）及び運転資金（人材採用・教育研修費用及び
外部コンサルティング費用）」（一般募集による新株式発行と同一の使途、後述6-3節）。

### 2-4. 行使価額修正条項の有無 — **該当なし**（D-015フラグ(c)に直結、11節で再掲）

本件は**普通株式の直接発行**であり、新株予約権（ワラント）ではない。原本を「行使価額」
「修正条項」で検索したが該当箇所は0件。有価証券届出書に記載された既存の新株予約権3種
（後述11節）も、市場価格に連動して行使価額が下方修正される条項（MSワラント型）ではなく、
株式分割時・時価未満発行時の希薄化防止目的の通常型調整条項のみであることを別途確認した。
