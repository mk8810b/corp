### 1-4.【重要】権利落ち説の裏付け確認と、magnitude（下落幅）との整合性チェック

まず、7035が実際に8月期末を権利確定日とする株主優待制度を持つかを独立に確認した。

|---|---|

| 優待内容 | プレミアム優待倶楽部ポイント（カタログギフト等に交換） |
| 配当利回り | **－%（無配）** |
| 優待利回り | **2.07%** |

これは決算短信の記載（3節参照、年間配当0.00円）とも整合する（無配）。**したがって、8月28日が
2026年8月期の株主優待の権利付き最終日に該当するという記事の説明は事実と整合する。**

**ただし、この優待価値だけで下落幅を機械的に説明できるかを検算した:**

```python
min_investment = 241000   # 1,000株保有時の最低投資金額
benefit_yield_pct = 2.07  # 優待利回り
shares_needed = 1000
benefit_value_yen = min_investment * benefit_yield_pct / 100
value_per_share = benefit_value_yen / shares_needed
print(round(value_per_share, 2), "円/株")               # 4.99円/株
print(round(value_per_share/26*100, 1), "%")             # 下落幅26円に対する割合
```

**結果: 優待価値は1株あたり4.99円相当であり、実際の下落幅26円（-9.74%）のわずか19.2%に
とどまる。** 権利落ちによる機械的な理論下落はこの程度が上限であり、**残り約8割の下落幅は
権利落ちだけでは説明できない。**

参考情報として、当日出来高421,700株は直近20営業日平均280,870株の**1.5倍**であり
（`check_floor()`再計算、11節）、通常日を上回る商いはあったが、突出した急増ではない。


**原本は負数を英語式の括弧表記「(8.7)」で印刷しており、日本語短信で通例の「△8.7」「▲8.7」

FAILはFAILのまま記録し、上記引用で読者が独立に検証できるようにする。売上高の増減率
