## 6. 当社標準判定枠組みの保険業への適用可否（PBR・PER・自己資本比率の解釈上の留保）

**【本銘柄に固有】8729は生保・損保・銀行の複合金融持株会社であり、当社の標準的な判定枠組み
（`playbooks/judgement.md`の同業比較・バリュエーション基準）をそのまま機械適用することには
以下の留保が必要である。**

### 6-1. 連結自己資本比率 —— 事業会社と単純比較不能（適用不能に近い）

- 有価証券報告書ベース（FY2026.3実績）: 連結自己資本比率**2.64%**（前回メモ`8729-20260718.md`
  2節より引用、EDINET S100YCL0、取得日時2026-07-18T00:18 UTC。本サイクルでの更新開示なし）。
- **この低さは個別企業の財務リスクではなく、生命保険会社の巨額の保険契約準備金・銀行の預金等が
  負債として計上される金融コングロマリット特有の会計構造**（前回メモの注記を踏襲）。
  一般事業会社の「自己資本比率20%以上」といった水準観と単純比較すると誤った印象を与えるため、
  **本銘柄への機械的な自己資本比率フィルタの適用は「解釈に留保が必要」と明記する**。
  健全性の実質評価には5節のESR（経済価値ベース指標）を用いるべきである。

### 6-2. PBR・PER —— 双方向に乖離し、単純な「割安/割高」判定が成立しない

```python
price = 165.8  # 2026-08-28終値
shares_incl_treasury = 6_770_358_214
treasury = 61_912_091
shares_ex_treasury = shares_incl_treasury - treasury
equity_attrib_owners = 876_175_000_000  # Q1末（2026-06-30）、直近開示

mcap = shares_incl_treasury * price
bvps = equity_attrib_owners / shares_ex_treasury
pbr = price / bvps
eps_fy_forecast = 23_000_000_000 / shares_ex_treasury
per = price / eps_fy_forecast
implied_roe = eps_fy_forecast / bvps * 100
```
実行結果:
```
時価総額 = 1,122,525,391,881円（約1兆1,225億円）
BVPS = 130.6077円
PBR = 1.2695倍
EPS(会社予想) = 3.4285円
PER = 48.3591倍
インプライドROE(会社予想ベース) = 2.6250%
```
（kabutan.jp表示値: PER 48.3倍・PBR 1.27倍・時価総額1兆1,225億円と整合。3者独立確認済み）

- **PBR（1.27倍）は同業比較先4社の中で最高水準**だが、08-10時点の1.20倍からは株価上昇により
  再び上昇。
- **PER（48.3倍）は比較先4社（12.9〜17.1倍）の約2.8〜3.7倍**という突出した高水準。
- **両者が逆方向に乖離する理由は、会社予想ベースのインプライドROEが約2.6%と極めて低い
  ことにある。** PBRが相対的に低い（＝株価が純資産に対して割安）ように見えても、それは
  収益性（ROE）の低さによって正当化されうる構造的要因であり、**PBR単独で「割安」と判定する
  ことは、生保・銀行複合体という業態のROE水準を無視した一面的な判定になる**。
- **結論**: 当社の標準的なバリュエーション判定枠組み（低PBR＝割安の候補、D-012基準2）を
  8729へ機械適用する場合、**PERとROEを同時に確認しない限り誤判定するリスクが高い**。
  「適用不能」とまでは言わないが、**「PBR単独での適用は不適切、PER・ROEとの併読が必須」**
  という留保を付す。
