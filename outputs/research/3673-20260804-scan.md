### 7-3. 事前の株価トレンド（開示前6週間）

06/23終値370円→07/29終値456円まで**+23.24%**の先行上昇があった（07/06〜08/03の20営業日

急伸を記録している。同日、後述の3182も日経-1.49%の日に+3.96%と急伸しており（案件2の調査
メモ参照）、**この日は複数の無関係な中小型株が同時に急伸する局面（小型株ローテーション等の
可能性）だった疑いがある**（原因は特定できないため断定しない。取得不能）。

### 7-4. 両論併記（本メモの結論）

- **「見過ごされている」を支持する事実**: +34.3%という大幅な営業利益上方修正に対し、開示当日は
  -1.36%とむしろ下落した。2日累計でも-0.23%とほぼ横ばいであり、大幅増益修正の割に株価の反応が
  乏しい。08/04の反発（+1.15%）は出来高0.92倍という**平均以下の商い**で起きており、
  「新規の買い需要が本格的に入って再評価が進んでいる」形にはなっていない。
- **「市場が材料と評価していない（または既に織り込み済み）」を支持する事実**: (i) 開示前6週間で
  +23.24%の先行上昇があり、うち07/29の+4.35%は日経平均が下落した日の急伸で、決算期待の
  先回りだった可能性を排除できない。(ii) 本開示は**中間期（H1）のみの修正**であり、通期予想は
  「現在精査中」で未改定。4-1節の自社試算では、前期のH1/FY比率（37.37%）をそのまま外挿すると
  H1修正値からの通期換算（約3,952百万円）は現行の通期予想（4,800百万円）を**下回る**——
  すなわち市場が「このH1上振れだけでは通期の上方修正を機械的に正当化しない」と冷静に判断して
  いる可能性がある。(iii) 決算発表予定日は2026/08/12（8日後）であり、通期予想の正式な扱いは
  その場で判明する。市場がその確定情報を待って様子見している可能性がある。
- **本メモは断定しない**: 上記いずれの解釈も企業調査メモの事実整理の範囲では確定できない。
  投資判断部が判定を下す際の材料として両論を提示する。

## 9. σ20・出来高20日平均のPython再計算（D-018トリガー設計向け前提データ）

日足データ出典: `https://kabutan.jp/stock/kabuka?code=3673&ashi=day&page=1`（curl、UA指定、
取得日時2026-08-04T08:13:09Z）。窓は**基準日08/04を除く直近20営業日（07/06〜08/03）**
（社内先例——`outputs/judgement/9889-20260803-scan.md`校閲メモB等——に従い基準日を除く窓を採用）。

```python
closes20 = [432,434,424,423,424,432,440,432,437,439,446,422,419,419,435,437,456,452,440,434]
# 07/06,07/07,07/08,07/09,07/10,07/13,07/14,07/15,07/16,07/17,07/21,07/22,07/23,07/24,07/27,07/28,07/29,07/30,07/31,08/03
vols20  = [1156100,1057500,590600,475900,545700,584900,456900,548800,459500,542900,630400,
           1003700,1250400,662200,603600,485300,897200,1536000,633600,1446600]
prev_close = 429  # 07/03 終値（窓の起点直前）
closes_ext = [prev_close]+closes20
rets = [(closes_ext[i]-closes_ext[i-1])/closes_ext[i-1] for i in range(1,len(closes_ext))]
n=len(rets)
mean_r = sum(rets)/n
pop_sd  = (sum((r-mean_r)**2 for r in rets)/n)**0.5
samp_sd = (sum((r-mean_r)**2 for r in rets)/(n-1))**0.5
print(n, mean_r*100, pop_sd*100, samp_sd*100)
# -> 20  0.5750%(平均日次騰落率)  2.1589%(母)  2.2150%(標本)
vol_avg20 = sum(vols20)/20
print(vol_avg20)          # -> 778,390.0株
print(vol_avg20*1.5)      # -> 1,167,585.0株（1.5倍閾値）
basis_close = 439         # 08/04終値
print(basis_close*0.02)   # -> 8.78円（2%成分）
print(pop_sd*basis_close, samp_sd*basis_close)   # -> 9.4775円 / 9.7237円
```

**結果**: σ20（母標準偏差）2.1589%・σ20（標本標準偏差）2.2150%。いずれも2%を上回るため
**σ20が拘束的**（`playbooks/judgement.md` D-018の下限ガード条項に該当）。基準終値439円換算で
σ20は母9.4775円・標本9.7237円。**呼び値1円で切り上げるといずれも10円**となり、
**母/標本の選択は本銘柄の閾値決定に影響しない**（頑健性を確認済み）。20日平均出来高
778,390株、1.5倍閾値1,167,585株。

**社内先例（`outputs/judgement/9889-20260803-scan.md`校閲メモB）は「σ20が拘束的なケースでは
標本標準偏差を保守採用する」ことを確立している**。本銘柄も同様に扱うべきだが、上記のとおり
円換算後の閾値（10円）は母/標本いずれでも変わらないため、投資判断部での裁定コストは小さい。
