## 2. 上方修正の中身: 進捗率・第4四半期含意額のPython再計算（一過性 vs 経常性）

修正お知らせ本文は増益理由として「ゲーム事業においても主力タイトルが想定以上の好調さで推移
すると共に、**第4四半期にあたる2026年7月に提供開始した新規タイトルの初速の良さを勘案し**、
2025年11月14日に公表した前期比減益予想から前期比7.4％増の770億円と前期比増益予想といたし
ました」と記載している（`yosoku.pdf` 2ページ目「2. 修正の理由」）。この新規タイトルの
初速は第4四半期（7〜9月）の実績にまだ反映されていない未確定要素であり、持続性の評価が
必要というタスク指示に基づき、Q3累計実績と通期予想（修正後）から進捗率・Q4単独含意額を
Pythonで再計算した。

```python
q3_cum_26 = dict(sales=709272, op=67449, ord=69182, ni=36035)      # 短信1ページ
fy_forecast_26 = dict(sales=950000, op=77000, ord=78000, ni=41000) # 短信3ページ・修正お知らせ
q3_cum_25 = dict(sales=631993, op=48798, ord=48631, ni=24103)      # 短信1ページ（前年同期）
fy_actual_25 = dict(sales=874030, op=71702, ord=71743, ni=31667)   # 修正お知らせ「前期実績」欄

# 通期進捗率
for k in q3_cum_26:
    print(k, round(q3_cum_26[k]/fy_forecast_26[k]*100, 2))
# 第4四半期(単独)含意額 = 通期予想 - Q3累計
q4_implied = {k: fy_forecast_26[k]-q3_cum_26[k] for k in q3_cum_26}
print(q4_implied)
# 前年同期の進捗率・Q4単独実績（季節性の参考）
for k in q3_cum_25:
    print(k, round(q3_cum_25[k]/fy_actual_25[k]*100, 2))
q4_actual_25 = {k: fy_actual_25[k]-q3_cum_25[k] for k in q3_cum_25}
print(q4_actual_25)
# 第4四半期(単独) 今期含意 vs 前期実績の増減率
for k in q4_implied:
    print(k, round((q4_implied[k]/q4_actual_25[k]-1)*100, 1))
```

**重要な発見**: 修正後の通期予想は、営業利益ベースで**Q3累計だけで既に通期予想の87.60%に
到達している**。この結果、逆算される第4四半期単独の営業利益含意額はわずか95.51億円であり、
これは**前年同期（Q4実績229.04億円）比で-58.3%の大幅な減益**を意味する。前期はQ4が通期営業
利益の31.94%を占めていたのに対し、今期の通期予想が前提とするQ4の取り分はわずか12.40%しかない。

**解釈（両論併記、断定しない）**:
- (a) 前期比較で保守的なQ4計画を置いている可能性: 日本企業に多い保守的ガイダンスの慣行
  （実際、今回の修正自体が2025-11-14の当初予想を大幅に上回った結果であり、当初予想も
  保守的だった前例がある）。この場合、Q4も上振れて着地する余地が残る。
- (b) 新規タイトルを含むゲーム事業の第4四半期の販促費・開発費等の先行投資負担、または
  メディア&IP事業・広告事業の季節的な費用計上により、Q4単独の利益水準が構造的に前年より
  下がることを会社が織り込んでいる可能性。
- 開示原本（決算短信・修正お知らせ）には、この進捗率の高さやQ4含意額の低さについての
  会社自身の説明はなく、上記いずれの解釈が正しいかは**開示情報だけからは判別できない
  （取得不能）**。「新規タイトルの初速の良さ」という定性的な記述はあるが、それがQ4単独の
  利益にどの程度寄与する前提かは開示に定量的な記載がない。
- **本メモの立場**: 上方修正の理由に挙げられた「新規タイトルの初速」は第4四半期にまだ
  実現していない要素であり、通期予想のQ4含意額（前年同期比-58.3%の営業減益を前提とする
  水準）と、修正理由の文言（新規タイトルの好調さを"勘案"して増益予想に転換）との間には、
  数字だけを見る限り緊張関係がある。持続性・一過性の最終判断は投資判断部の範囲だが、
  **この定量関係を事実として記録する**。
