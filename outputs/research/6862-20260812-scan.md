## 2. 旧通期予想（営業利益3,500）はQ1実績で既に維持不能だったか（自社Python再計算）

出典: 決算短信（`https://www.release.tdnet.info/inbs/140120260807515724.pdf`、取得日時
2026-08-11T23:07Z）「３．2027年３月期の連結業績予想」、業績予想の修正お知らせ
（`https://www.release.tdnet.info/inbs/140120260810516638.pdf`、同）「前回発表予想（Ａ）」欄。

```python
q1_sales, q1_op, q1_ord, q1_np = 23_027, 4_771, 4_796, 3_259   # Q1実績（百万円）
old_sales, old_op, old_ord, old_np = 48_000, 3_500, 3_200, 2_150  # 旧通期予想A

for label, q1v, old_v in [
    ("売上高", q1_sales, old_sales), ("営業利益", q1_op, old_op),
    ("経常利益", q1_ord, old_ord), ("純利益", q1_np, old_np),
]:
    pct = q1v / old_v * 100
    flag = " ← Q1だけで旧通期予想を超過済み" if q1v > old_v else ""
    print(f"{label}: Q1実績 {q1v:,} / 旧通期予想 {old_v:,} = 進捗率 {pct:.1f}%{flag}")
```

実行結果:

| 経常利益 | 4,796 | 3,200 | **149.9%** ← Q1だけで旧通期予想を超過済み |

## 3. 上方修正の中身: 「残り9ヶ月」含意額のPython再計算（一過性 vs 経常性）

会社自身が業績予想の修正お知らせで次のとおり明記している（原本より原文引用）:

> 「当第１四半期累計期間においてデジタルデバイスにおけるセグメント利益を押し上げた在庫販売等
> については、第２四半期以降の寄与が限定的となることを見込むとともに、今後のメモリ市場や
> 価格動向等の事業環境を慎重に織り込み、通期業績予想を算定しております。」

この留保が定量的にどの程度の減速を意味するかを、新通期予想からQ1実績を差し引いた
「残り9ヶ月（Q2〜Q4）の含意額」を計算し、前年同期間の実績と比較して検証した（先例4751と
同じ手法）。

```python
# 出典: 決算短信・業績予想の修正お知らせ（いずれも本メモ0節記載の2026-08-10 TDnet開示）
q1_sales, q1_op, q1_ord, q1_np = 23_027, 4_771, 4_796, 3_259          # Q1実績(今期)
q1py_sales, q1py_op, q1py_ord, q1py_np = 5_193, 136, 83, 39            # Q1実績(前年同期)
fy_prev_sales, fy_prev_op, fy_prev_ord, fy_prev_np = 36_572, 4_232, 4_042, 2_108  # 前期(2026/3期)通期実績
new_sales, new_op, new_ord, new_np = 81_000, 10_000, 9_300, 6_000      # 新通期予想B

implied_new = {"売上高": new_sales-q1_sales, "営業利益": new_op-q1_op,
               "経常利益": new_ord-q1_ord, "純利益": new_np-q1_np}
implied_prev = {"売上高": fy_prev_sales-q1py_sales, "営業利益": fy_prev_op-q1py_op,
                "経常利益": fy_prev_ord-q1py_ord, "純利益": fy_prev_np-q1py_np}

headline_pct = {"売上高": 68.8, "営業利益": 185.7, "経常利益": 190.6, "純利益": 179.1}
for label in ["売上高", "営業利益", "経常利益", "純利益"]:
    yoy = (implied_new[label] / implied_prev[label] - 1) * 100
    print(label, implied_new[label], implied_prev[label], round(yoy, 1), headline_pct[label])
```

実行結果:

| 項目 | 新通期予想 | −Q1実績 | ＝**残り9ヶ月含意額(今期)** | 前期通期実績−前期Q1実績＝**前年・残り9ヶ月実績** | **YoY** | 見出しの通期修正増減率 |
|---|---|---|---|---|---|---|
| 売上高 | 81,000 | 23,027 | 57,973 | 31,379 | **+84.8%** | +68.8% |
| 営業利益 | 10,000 | 4,771 | 5,229 | 4,096 | **+27.7%** | +185.7% |
| 経常利益 | 9,300 | 4,796 | 4,504 | 3,959 | **+13.8%** | +190.6% |
| 純利益 | 6,000 | 3,259 | 2,741 | 2,069 | **+32.5%** | +179.1% |

**重要な発見**: 4751先例（第4四半期含意額が前年同期比-58.3%というマイナスの乖離）とは
方向が異なり、6862の「残り9ヶ月」含意額は前年同期間比でなお**プラスの増益**を見込んでいる。
ただし、その伸び率（営業利益+27.7%、経常利益+13.8%）は、見出しの通期修正増減率
（+185.7%、+190.6%）とは**大きく乖離**しており、**見出しの増減率の大半はQ1に発生した一過性
要因（在庫販売・在庫評価益）が押し上げたものであって、残り9ヶ月に投影される「地力」の伸びは
それよりはるかに緩やかである**ことが定量的に確認できる。会社自身の説明（在庫販売等の
寄与は第2四半期以降限定的、メモリ市況を慎重に織り込み）と整合する結果である。

なお、決算説明資料12ページに会社自身が示す通期予想（修正後）に対するQ1進捗率は
「売上高28.4%／営業利益47.7%／経常利益51.6%／純利益54.3%」であり、自社Python再計算
（例: 営業利益4,771/10,000=47.71%）と一致することを確認した

## 5. 配当予想の修正: 増額分はすべて設立70周年記念配当（一過性）

出典: 業績予想の修正及び配当予想の修正（増配）に関するお知らせ
（`https://www.release.tdnet.info/inbs/140120260810516638.pdf`、取得日時2026-08-11T23:07Z）
「２．配当予想の修正」。

| | 中間 | 期末 | 合計 |
|---|---|---|---|
| 前回発表予想（2026-05-12公表） | 12円00銭（普通0円＋記念12円） | 18円00銭（普通18円） | 30円00銭 |
| 今回修正予想（2026-08-10公表） | **24円00銭**（普通0円＋**記念24円**） | 18円00銭（普通18円、据置） | **42円00銭** |
| 前期実績（2026年3月期） | 0円00銭 | 18円00銭 | 18円00銭 |

修正の理由（原本より原文引用）:

> 「当社は、本年12月17日に設立70周年という大きな節目を迎えます。（中略）記念配当を１株当たり
> 12円00銭増額し、中間配当予想を１株当たり12円00銭から24円00銭に修正することといたしました。
> なお、2027年３月期の期末配当予想につきましては、前回発表どおり１株当たり18円00銭として
> おります。」

```python
old_mid, new_mid = 12.00, 24.00     # 中間配当（円）
old_end, new_end = 18.00, 18.00      # 期末配当（円）
old_total, new_total = old_mid+old_end, new_mid+new_end
print(new_total - old_total)          # 増額分の合計
print((new_mid-old_mid), "全額が記念配当増額分")
```

実行結果: 年間配当の増額分は**+12円**（30円→42円）で、これは中間配当の記念配当部分の増額
（+12円）と完全に一致する。**普通配当は中間0円・期末18円の合計18円で、修正前後を通じて
一切変わっていない。** すなわち今回の増配は、経常的な株主還元方針の強化ではなく、
**2026年12月17日の設立70周年に紐づく一過性の記念配当**であり、翌期（2028年3月期）に
同水準の配当が維持される保証は開示上明記されていない（記念配当の性質上、翌期の
剥落リスクを内包する。7節参照）。

## 8. リスク要因（開示原本ベース）

- **メモリ市況の反転リスク**: 通期業績予想・Q1実績とも汎用メモリ（DRAM・NAND）の
  「需給逼迫及び価格上昇」を主因としている（1〜4節）。決算説明資料の価格指数は
  約1年半で約10倍という急騰を示しており、上昇局面の反動（価格下落・在庫評価損）が
  生じた場合の業績への影響度は開示原本からは定量化されていない（取得不能、7節）。
- **在庫販売等の一過性要因の反動**: 会社自身が「デジタルデバイスにおけるセグメント利益を
  押し上げた在庫販売等については、第２四半期以降の寄与が限定的となる」と明記（3節）。
  3節のPython再計算のとおり、「残り9ヶ月」の含意増益率（営業利益+27.7%等）は見出しの
  通期修正率（+185.7%等）よりはるかに緩やかであり、Q1に発生した一過性要因が今回の
  上方修正の相当部分を占めることを会社自身も示唆している。
- **記念配当の翌期剥落リスク**: 5節のとおり、今回の増配（30円→42円）は全額が設立70周年
  記念配当（一過性）であり、普通配当18円は不変。翌期（2028年3月期）以降も同水準の配当が
  維持される根拠は本メモが確認した開示にはなく、記念配当分（中間24円のうち24円）が
  翌期に消滅する可能性を織り込む必要がある。
- **単一セグメントへの依存**: 連結営業利益の98.5%がデジタルデバイス（メモリ関連）
  セグメントに集中している（4節）。他4セグメントの合計利益寄与は限定的。
- **M&Aによる連結範囲拡大の影響の分離困難性**: Q1に富士電工（2026年4月子会社化）・
  ブレイン/インテグ（前期末子会社化、当期より通期寄与）・ピーディック（B/S連結のみ、
  損益は第2四半期以降）が相次いで連結範囲に加わっており、既存事業の成長とM&A効果が
  混在している。決算説明資料のOP増減分析（11ページ）では「M&A効果」として97百万円が
  明示されているが、これは全社レベルの内訳の一部であり、セグメント別のM&A寄与分の
  完全な分離は本メモの調査範囲では確認できていない。
