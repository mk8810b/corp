### 1-3. σ20の独自Python再検証

`corp/watchlist.md` 5253-T2は「日次ルーチンでσ20=7.134%を再計算し閾値1,447円確定」と記録して
いる。上記1-1の日次終値データ（06/26〜07/27の21終値、20リターン）を用いて独立に再計算した。

```python
import statistics as st
closes = [1218,1357,1371,1344,1458,1548,1616,1625,1618,1632,1612,1641,1694,1697,1677,1640,1633,1692,1545,1350,1650]
rets = [(closes[i]/closes[i-1]-1)*100 for i in range(1,len(closes))]
sstdev = st.stdev(rets)   # 標本標準偏差（N-1）
# -> 7.1344% （日次ルーチン記録値7.134%と一致）
base = 1350
threshold = base + max(base*0.02, base*sstdev/100, 1)
# -> 1350 + max(27.0, 96.31, 1) = 1446.31 -> 呼び値1円切り上げで1,447円
```

**一致確認**: σ20=7.134%・閾値1,447円ともに日次ルーチンの記録値と完全に一致した。なお本計算は
07/27（判定当日）自身の日次リターン（+22.22%）を20日窓に含めて算出したものである（窓の終端を
基準価格1,350円決定日07/24とした場合の独自再計算では標本標準偏差5.33%・母標準偏差5.20%となり
7.134%とは一致しない — 参考として付記するが、日次ルーチンの実際の判定方式〔判定当日を含む窓〕
に沿った上記の再計算で日次ルーチンの記録値と一致することを確認した）。**トリガー成立自体に
数値上の疑義はない**（1,650円 ≥ 1,447円、出来高3.389倍 ≥ 1.5倍）。

**価格が実際にストップ高（値幅制限の上限）に到達していたことの確認**: JPX「値幅制限」表
（`https://www.jpx.co.jp/equities/trading/domestic/06.html`、curl取得、取得日時本メモ作成時点）
によれば、基準値段（前日終値）が「1,000円以上1,500円未満」の場合の制限値幅は300円である。
前日終値（07/24）1,350円はこの区分に該当し、制限値幅上限は1,350+300=**1,650円**となる。
