すなわち会社の**通期見込みは38.1%（前期実績）→40%程度**であり（前回判断メモが要約した
「低下」は、8月3日の上方修正前の当初予想〔より高い税率想定〕からの引き下げを指すと解される。
前期実績38.1%との比較では、通期見込み40%は数値上はむしろ上昇である点は前回メモに
明記がなかった新事実）、**この「40%程度」はあくまで通期の見込みであり、Q1の実績税負担率
47.53%はこれを上回っている**。

**なお、会社はこの点についてQ1が未改善であることを織り込み済みの説明をしている**（決算FAQ
p.4「親会社帰属純利益の上方修正及び増配」原文引用）:

> 「B2B事業において、25年9月のシダックス完全子会社化以降、組織再編を順次実施し、
> **2Q以降**の法人税等の負担率が構造的に適正化され、中長期的には適正な水準である
> 30%台になると見込んでいます。」

つまり会社の説明では**税率改善効果は「2Q以降」に発現する計画であり、Q1時点でまだ現れて
いないこと自体は会社の計画と矛盾しない**。ただし、これはあくまで会社側の説明であり、
**Q1実績そのものは「改善が既に確認できた」という根拠にはならない**（次の四半期以降の

低下」を**Q1実績で積極的に裏付けることはできない（会社は「2Q以降」の計画としており、
Q1に表れていないこと自体は想定の範囲内と説明している）**。

その後初めて確定したQ1実績が、修正後の通期予想に対してどの程度の位置にあるかをPythonで

## 12. 株価データ（確定終値・PTS）

**注記**: 開示は15:30 JST＝大引けと同時刻であり、大引け直後の当日終値はこの開示を
織り込んでいない可能性が高い。確定終値は大引けから+30分以降に取得し、PTSの気配・約定を
別途確認する（2026-08-12の実測で+10分時点の値は56銘柄中42銘柄が確定値と異なっていた
先例、`corp/scan-log.md`）。

### 12-1. 確定終値・出来高

| 項目 | 値 | 出典・取得日時 |
|---|---|---|
| 2026-08-13確定終値 | **1,688.0円** | kabutan.jp（日足）／2026-08-13T07:07:49Z・07:2xZ（16:07/16:26 JST、大引け+37分・+56分の2ラウンドで55銘柄すべて完全一致・収束確認済み）。本メモ担当者も2026-08-13T07:28:55Zに同URL（`kabutan.jp/stock/kabuka?code=3182&ashi=day&page=1`）を独立再取得し、同一値（1,688円・出来高68,500株・前日比0/0.00%）を確認 |
| 2026-08-12終値 | 1,688.0円 | 同上（前日比±0.00%の比較対象） |
| 前日比 | **±0.00%**（変化なし） | — |
| 確定出来高 | **68,500株** | 同上 |

**「動かなかった」ことの検討**: 大引けの終値は前日と完全に同値（±0.00%）であり、価格面では
無反応だった。**出来高は20日平均比でむしろ低い**:

```python
vols20 = [72400,69700,78800,79400,71000,115100,139700,105400,118100,170100,
          71400,95500,82700,57100,81900,75900,77200,67200,223900,48800]
avg20 = sum(vols20)/len(vols20)
print(avg20)                          # -> 95,065.0株（直近20営業日平均、本日を含まない窓）
print(68500/avg20)                    # -> 0.7206（本日出来高は20日平均の72.06%）
```

**本日出来高68,500株は直近20営業日平均95,065株の72.06%に留まり、決算発表日としては
薄商いである。** 前日比±0.00%かつ出来高が平均を下回るという組み合わせは、「開示が15:30＝
大引けと同時刻のため、通常取引時間中の株価には織り込みようがなかった」という前提（本節冒頭）
と整合する一方で、**取引時間中に決算内容を先回りして材料視した動きも観測されなかった**
ことを意味する。

### 12-2. PTS（時間外取引）

| 項目 | 値 | 備考 |
|---|---|---|
| PTS気配値 | **1,728円** | kabutan.jp `https://kabutan.jp/stock/?code=3182` |
| ページ内表示時刻 | 15:44　08/13 | **kabutanのライブ相場欄は15〜16分ディレイ**（ページ運営側の仕様）。実際の気配発生時刻はおよそ15:59〜16:00 JST頃と推定される（表示時刻+15〜16分、断定はしない） |
| 取得（curl実行）日時 | 2026-08-13T07:28:39Z（16:28:39 JST） | — |
| PTS出来高 | **取得不能** | kabutanのPTS欄には価格・時刻のみ表示され出来高の表示がない |

```python
close, pts = 1688.0, 1728.0
print(round((pts/close-1)*100, 2))   # -> 2.37
```

**PTSは確定終値比+2.37%。** ディレイを考慮した推定気配発生時刻（15:59〜16:00頃）は、
15:30の開示から30分弱が経過した時点であり、**日中PTSセッションの終盤〜夜間セッション移行期
に相当する早い段階の気配**とみられる。プラス方向の気配ではあるが、(i) PTS出来高が取得不能
のため薄商いによる振れの可能性を排除できない、(ii) この1点のみのスナップショットであり
夜間PTSセッション（16:30以降）を通じた値動きの推移は未確認（第2章-3の無限研磨禁止規定に
従い、追加のモニター待機は行わず本メモはこの1点観測で確定する）。**したがって「PTSで
明確に好感された」と断定はできないが、当日終値の完全な無風（±0.00%）とは異なる、
方向を持った早期の気配が観測された点は事実として記録する。**
