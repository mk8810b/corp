### 6-2. 減資の額と剰余金の処分の内容（原文引用・Python検算）

> (2) 増加する資本剰余金の額　その他資本剰余金 410,393,950円

> 会社法第452条の規定に基づき、上記の資本金及び資本準備金の額の減少の効力発生を条件に、以下のとおりその他資本剰余金を繰越利益剰余金に振り替えることで、欠損填補に充当いたします。これにより、振替後の繰越利益剰余金の額はマイナス1,520,000円となります。

```python

other_cap   = 410_393_950     # その他資本剰余金への振替増加額
print(capital_dec + apic_dec)         # => 410,393,950（振替額と一致）
print(-411_913_950 - (-410_393_950))  # => -1,520,000（振替後の繰越利益剰余金と一致）
```

**Python再検算の結果、資本金減少額340,872,250円＋資本準備金減少額69,521,700円＝410,393,950円が、
