## 5. 希薄化による簿価（BPS）希薄化の機械試算

**前提（明記）**: (1) 第三者割当13,054,000株が全額払込まれると仮定する。(2) 手取金総額
（8,671,364,000円）がそのまま純資産に加算されると仮定し、他の純資産変動（当期純利益の計上等）は
無視する機械的な試算である。(3) 基準となる株式数はQ1(2027.3)期中平均株式数（54,215,385株）を
用いる。

```python
equity_q1 = 110_835_000_000       # 円、2026-06-30実績
net_proceeds = 8_671_364_000      # 円、第三者割当の手取金総額
equity_proforma = equity_q1 + net_proceeds

shares_before = 54_215_385        # Q1期中平均株式数（自己株式除く）
shares_new = 13_054_000
shares_proforma = shares_before + shares_new

bps_before = equity_q1/shares_before
bps_proforma = equity_proforma/shares_proforma
print(round(bps_before,2), round(bps_proforma,2))
# 2,044.35円  1,776.53円

print(round((bps_proforma/bps_before-1)*100,2), "%")
# -13.10 %

close = 641.0
print(round(close/bps_before,4), round(close/bps_proforma,4))
# PBR(希薄化前基準) 0.3135  →  PBR(希薄化後・株価不変仮定) 0.3608
```

**発行価格666円はQ1末BPS(2,044円)を大幅に下回るため、全額払込が完了すると1株当たり純資産（簿価）
は機械的に約13.1%低下する（2,044円→1,777円、試算）。株価が変わらないと仮定した場合、PBRは
見かけ上0.31倍→0.36倍相当まで上昇しうる。** これは「株価が上がった」からではなく「分母（簿価）が
希薄化で下がる」ことによる機械的な効果であり、**現在観測されているPBR0.31倍の一部は、今後の
希薄化により剥落しうる「一時的な低さ」である可能性がある**点を独立に記録する（判断は行わない）。
払込期日は2026年10月2日〜11月30日であり、本メモのas_of時点（2026-08-30）では未実施。

### 5-1. 株価収益率(PER)の基準の相違（第2条の慎重な扱い）
