### 11-2. σ20（20営業日の日次対数リターン標準偏差）

```python
import math, statistics
closes = [直近20営業日の終値（2026-07-09〜2026-08-14）]
rets = [math.log(closes[i]/closes[i+1]) for i in range(len(closes)-1)]
sigma_daily = statistics.pstdev(rets)          # = 0.015978 (1.598%)
sigma_annualized = sigma_daily * math.sqrt(252) # = 0.25364 (25.36%)
```
