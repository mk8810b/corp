## 5. 【最重要】機械的訂正か、裁量的な見通しの引き上げ／引き下げか

社内先例（4751 校閲JDG-O62・6862 JDG-S71 3節基準3）が確立した判定法に従い、
**H1実績が旧通期予想に対して何%の進捗率かをPythonで計算**する。

```python
h1_rev, h1_op, h1_pretax, h1_ni = 10781.239, 1477.051, 1392.438, 1001.165  # 百万円換算
fy_rev, fy_op, fy_pretax, fy_ni = 23800, 4800, 4750, 3200                  # 修正後（=修正前の利益3科目と同値）

```

実行結果: 売上進捗率**45.30%**、営業利益進捗率**30.77%**、税引前利益進捗率**29.31%**、
純利益進捗率**31.29%**（決算説明会資料の会社発表値45.3%／30.8%／31.3%と一致、自社検算済み）。

**判定: 本件は4751（Q3進捗率87.60%が旧予想を突き抜けていた）・6862（Q1進捗率136.3%で
旧予想を単独超過していた）先例のような「機械的訂正」には該当しない。** 利益3科目の
進捗率はいずれも30%台であり、旧通期予想（利益3科目）を累計実績が追い抜いた事実はない
——旧予想はまだ「突き抜けられて」いない。**したがって本件の「修正」は先例のパターンの
裏返しではなく、性質が異なる**:

- 会社は利益予想を**据え置いた**（引き上げていない）。引き上げられたのは売上収益のみ
  （+1.3%）で、かつ会社自身がその増収要因を「主にパソコンを中心とするハードウェア売上」
  「利益への寄与は限定的」と明記している——**低粗利率品目による売上のみの微修正であり、
  収益性の高いクラウド化進捗を根拠とした増収ではない**（クラウドサービス売上自体は
  前年同期比+29.7%と好調だが、通期のクラウドサービス予想15,600百万円は前回予想から
  **±0で無修正**、4-1節下記6節参照）。
- 前回メモ（08/04）の試算——「H1上振れを前期のH1/FY比率37.37%で機械的に外挿すると通期
  換算約3,952百万円となり、現行の通期予想4,800百万円を下回る」——は、**会社が実際に利益
  予想を据え置いたという結果と方向として整合する**。会社は前期同様の季節性パターンでは
  届かない水準の通期予想を据え置いており、これは経営陣が「上期の勢いをそのまま延長すれば
  足りない差分を、下期の施策（価格改定・下期からの大手部品商への導入開始等）で埋める」
  という**裁量的な計画**を維持していることを意味する（6節で下期含意を定量化する）。
- **結論**: 本件の通期予想（利益3科目）は、累計実績によって機械的に無効化されていた
  「旧予想」を後追いで追認したものではない。据え置き自体が経営陣の裁量的判断であり、
  その裁量判断が「達成可能」と言えるかは、6節で検証する下期含意の规模に依存する。

## 6. 通期予想の下期含意——Python再計算と前年同期比

決算説明会資料（`...518122.pdf`11頁）は会社自身が「下期予想＝通期予想－中間期実績」
「中間期実績比＝（下期予想－中間期実績）÷中間期実績」を開示している。本メモはこれを
そのまま転記せず、**前年同期の下期実績と比較したYoYを独自にPython再計算**した
（会社発表は中間期実績比＝H1に対する半期進行比較のみで、前年同期比は開示されていない）。

```python
# 会社発表の下期含意額（百万円、決算説明会資料11頁）
h1_rev, h1_op, h1_ni = 10781, 1477, 1001
fy_rev, fy_op, fy_ni = 23800, 4800, 3200
h2_implied_rev = fy_rev - h1_rev   # 13,019
h2_implied_op  = fy_op  - h1_op    # 3,323
h2_implied_ni  = fy_ni  - h1_ni    # 2,199
print(h2_implied_rev, h2_implied_op, h2_implied_ni)

# 前期（FY2025）のH2実績（会社発表の通期実績－中間期実績、百万円、決算短信より）
fy2025_rev, fy2025_op, fy2025_ni = 20815, 2063, 1240
h1_2025_rev, h1_2025_op, h1_2025_ni = 9819, 771, 417
h2_2025_rev = fy2025_rev - h1_2025_rev   # 10,996
h2_2025_op  = fy2025_op  - h1_2025_op    # 1,292
h2_2025_ni  = fy2025_ni  - h1_2025_ni    # 823
print(h2_2025_rev, h2_2025_op, h2_2025_ni)

# 下期含意額の前年同期（H2）比 = 本メモの独自試算
```
