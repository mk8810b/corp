## 1.【最重要】PBR 0.31倍は「構造的欠陥を伴わない割安」かの検証（結論）

D-023の複合フィルタ（低PBR × 直近本決算が最終黒字 × 自己資本比率20%以上）は、**直近本決算（2026年3月期）を基準にすれば機械的に通過する**（4節・5節）。しかし本工程が原本を精査した結果、以下の事実が判明した。

1. **直近開示（2027年3月期第1四半期、2026-08-05発表）は黒字→赤字に転落している**（6節）。
2. **2027年3月期の通期業績予想は「未定」に修正されている**。理由は業績の悪化ではなく、**2件の死亡事故**（NDP社タンク倒壊事故・死者11名、令和8年熊本地震・死者9名）による工場操業停止と影響額の算定困難である（7節）。
3. 一方で、政策保有株式（リンテック株式）の売却により約263億円の特別利益が個別決算で計上される予定であり（9節）、業績のヘッドライン数値は今後複数の一過性要因で振れやすい。

**したがって、PBR 0.31倍という水準を「市場がまだ気づいていない単なる割安」と解釈するのは危険である。** D-023の機械フィルタは「直近本決算」という過去確定値のみを見る設計であり、本件のように**直近本決算公表後に発生した重大な事後的事象**（本件では死亡事故2件・業績予想の未定化）を捕捉できない。本工程はこの限界を事実として明記し、判断（BUY/WATCH/PASS）は行わない。

## 15. D-004/D-009/D-013/D-019 各種基準との関係（機械照合の材料、判定は行わない）

```python
import re
html = open('kabutan_3863_kabuka.html', encoding='utf-8').read()
rows = re.findall(r'<tr[^>]*>(.*?)</tr>', html, re.S)
data = []
for r in rows:
    cells = [re.sub('<[^>]+>', '', c).strip()
             for c in re.findall(r'<t[dh][^>]*>(.*?)</t[dh]>', r, re.S)]
    if cells and re.match(r'^\d{2}/\d{2}/\d{2}$', cells[0]):
        data.append(cells)  # [日付, 始値, 高値, 安値, 終値, 前日比, 前日比%, 出来高]

last20 = data[:20]  # 先頭が最新（26/08/28）
vols = [int(d[7].replace(',', '')) for d in last20]
closes = [float(d[4].replace(',', '')) for d in last20]
avg_vol = sum(vols) / len(vols)
avg_amt = sum(v * c for v, c in zip(vols, closes)) / len(vols)
print(last20[0][0], closes[0])       # 26/08/28 1396.0
print(round(avg_vol, 1))             # 877690.0
print(round(avg_amt / 1e8, 4), "億円")  # 12.0258 億円
```

**SCR-O05（週次スクリーニング成果物）の記載値（20日平均出来高877,690.0株・20日平均売買代金12.026億円）と完全一致することを独立に再現確認した。**

