## 3. D-012の4基準の逐条判定

`playbooks/judgement.md`のD-012は「却下理由が一つも見つからなければBUY」という消極的判定を
明示的に禁止し、4基準のうち**最低1つ**を企業調査メモの事実に基づき具体的に満たすことを
要求する。以下、4基準を個別に照合する。**T1(i)は「BUY格上げを検討する」という検討義務を
課しているが、格上げ義務ではない（D-012の必要条件は十分条件ではない、先例
9432-20260806-event.md）。**

### 基準1: カタリスト特定済み（かつ市場にまだ十分織り込まれていないと判断できる根拠がある）

**判定: 不成立（前段は成立、後段が明確に不成立）。**

- **前段（カタリストの特定）は成立する**: 本日11:30のQ1決算・通期予想修正という具体的事象が
  一意に特定できる。
- **後段（未織り込みの根拠）は明確に立証できない、むしろ反証がある**:
  1. **当日株価は+2.4246%（前日比）、当日出来高は20日平均の1.70倍（除く窓）／1.63倍
     （含む窓）**であり、D-018の「出来高を伴って」基準（1.5倍）を明確に上回る（1節）。
  2. 当日値動き幅はσ20（2.0805%）換算で**約1.17σ**（1節Python計算）であり、統計的に
     「有意に大きい」というほどの外れ値ではないが、**方向（上昇）・出来高（急増）が同時に
     揃っている**ことは、市場がこの開示を材料として取引したことの一貫した証拠である。
  3. **先例との比較（本日の校閲JDG-O63、5269-20260810-scan.md 校閲-2）**: 同日の5269は
     「出来高1.6倍を伴うが価格はほぼ無反応（-0.87%、1σ未満）」という事実から「市場は見た
     うえで評価を変えなかった」と判定され、基準1後段（未織り込み）不成立とされた。
     **本件（8729）は価格も出来高も反応しており、5269よりもさらに「未織り込み」を主張
     しにくい事案である**。市場は当日中に反応済みであり、「まだ気づいていない」という
     主張は事実に反する可能性が高い。
  4. **カタリストの中身自体が一過性・保守的見積り由来**（T1(i)の判別、2節）であり、会社自身の
     修正純利益予想が不変であることを踏まえると、市場が「見出しの黒字転換」に反応しつつ
     「基礎的収益力は変わらない」ことも同時に織り込んでいる可能性がある（当日値動きが
     ±数%程度の緩やかな上昇に留まり、大幅な急騰ではないこととも整合的）。
- **結論**: カタリストは特定できるが、「まだ十分織り込まれていない」という後段の要件は、
  当日の価格・出来高の反応という直接的な反証によって不成立とする。基準1は不成立。

### 基準2: 同業比バリュエーション下位（かつ割安さを正当化する構造的欠陥が見当たらない）

**判定: 不成立（PBRとPERで結果が分裂し、構造的欠陥＝低ROEが確認できる）。**

```python
peers_pbr = {"8729":1.1967, "7181":0.38, "8795":1.38, "7157":1.43, "8750":1.45}
# 昇順: 7181(0.38) < 8729(1.1967) < 8795(1.38) < 7157(1.43) < 8750(1.45)
peers_per = {"8729":45.6, "7181":12.5, "8750":12.9, "7157":16.7, "8795":17.1}
# 8729のPERは比較先4社の2.7〜3.6倍で突出して最高
implied_roe = 3.4285/130.6077*100   # = 2.625%（会社予想EPS÷Python再計算BVPS）
```

- **PBR（1.1967倍、研究メモ5節・本メモ独立再計算で一致）は比較先5社中2番目に低い**
  （前回メモ2026-07-18時点では最も高い1.65倍だった。8729-T5「PBR1.42倍以下」トリガーが
  本日成立している——1節・4節）。
- しかし**PER（45.6倍）は比較先4社（12.5〜17.1倍）の約2.7〜3.6倍と突出して最も高い**。
  PBRとPERが逆方向に乖離するのは、**株価に対して会社予想利益（EPS）が極めて小さい＝
  自己資本利益率（ROE）が低い**ことを意味する（会社予想ベースの implied ROE 約2.63%、
  Python再計算）。
- **D-012基準2が要求する「割安さを正当化する構造的欠陥が見当たらない」という条件は
  満たされない**。低ROE（約2.6%）自体が、PBRの相対的な低さを正当化しうる構造的欠陥に
  該当する。PBRだけを見て「同業比割安」と判定するのは、PERが示す収益性の劣後を無視した
  一面的な判定になる。
- **結論**: PBR単独では「割安寄り」に転じたが、PERの著しい高さとその裏にある低ROEという
  構造的欠陥が確認できるため、基準2は不成立。

### 基準3: 業績進捗が会社予想を上回る

**判定: 不成立（見出し指標は線形25%を上回るが、会社自身の恒常的収益力指標では小幅超過に
留まり、かつ会社は当該指標の予想を据え置いている。後段〔市場未織り込み〕も基準1と同じ
理由で不成立）。**

**基準3の物差し（先例5269-20260810-scan.md 校閲JDG-O63、校閲-2の裁定を適用）**: 会社が
期間（半期等）予想を公表している場合は通期の線形按分ではなく会社自身の期間計画を分母に
取る。8729について、決算短信・業績予想修正PDF・決算説明会資料のいずれにも**半期（中間期）の
利益予想は公表されていない**ことを確認した（配当は中間4.0円・期末4.0円の内訳があるが、
これは配当計画であり利益の期間計画ではない。研究メモ2節・本メモ2-1節で確認済み）。
**したがって本件では先例の裁定の適用条件（会社が期間予想を公表していること）を満たさず、
通常どおり通期予想に対する線形25%を分母とする。**

```python
q1 = {"営業収益":268_033, "営業利益":15_228, "税引前利益":13_723,
      "親会社所有者帰属利益":9_160, "修正純利益":31_503}
fy = {"営業収益":1_070_000, "営業利益":29_000, "税引前利益":37_000,
      "親会社所有者帰属利益":23_000, "修正純利益":110_000}
for k in q1: print(k, q1[k]/fy[k]*100)
```
実行結果（研究メモ3-3節と一致）:
| 項目 | Q1進捗率 | 線形25%との差 |
|---|---|---|
| 営業収益 | 25.05% | +0.05pt |
| 営業利益 | 52.51% | +27.51pt |
| 税引前利益 | 37.09% | +12.09pt |
| 親会社所有者帰属利益 | 39.83% | +14.83pt |
| **修正純利益** | **28.64%** | **+3.64pt** |

- **見出し指標（営業利益52.51%・税引前利益37.09%・親会社所有者帰属利益39.83%）は線形25%を
  大幅に上回る。** しかしこれらはいずれもT1(i)で確認した一過性項目（有価証券売却損の縮小・
  持分法投資譲渡益）の影響を含む指標であり、この一過性項目こそが今回の大幅な進捗超過の
  主因である（研究メモ3-2節の調整表: 有価証券売却損益の調整額が前年同期72,263→当期25,032
  百万円〔税引後〕へ縮小したことが、前年同期赤字→当期黒字への転換の主要な駆動源）。
- **会社自身が恒常的収益力を測る指標と定義する「修正純利益」では、Q1進捗率は28.64%で
  線形25%を+3.64ptしか上回っていない。** しかも**会社は今回の業績予想修正で修正純利益の
  通期予想を1円も動かしていない**（2節）。会社自身が「Q1の進捗が通期予想を上回るペースに
  ある」という評価であれば、修正純利益の通期予想を据え置く理由に乏しい。この事実は、
  会社側が今回の進捗を「通期計画を上回る恒常的な進捗」とは捉えていないことを示唆する。
- **前年同期比較（研究メモ3-4節）**: 修正純利益の前年同期進捗率20.42% → 当期28.64%へ
  +8.2pt改善しており、ペースの改善自体は事実として存在する。ただし前年同期が異例に低い
  水準だった可能性もあり（前年同期は税引前赤字だった年度、研究メモ3-4節）、この比較単独で
  「会社予想を上回る」ことの強い根拠とするには弱い。
- **後段（市場未織り込み）**: 基準1と同じ理由（当日の価格+出来高の双方反応）で不成立。
- **結論**: 見出し指標の大幅超過は一過性項目に起因し、会社自身が定義する恒常的収益力指標では
  小幅超過に留まり、かつ会社自身がその指標の予想を据え置いている。したがって「業績進捗が
  会社予想を上回る」という基準の実質を満たすとは判定できない。基準3は不成立。

### 基準4: エッジ仮説との整合（D-012、アナリストカバレッジが薄い銘柄の当日読み込み）

**判定: 不成立（時価総額規模からカバレッジは「薄い」とは考えにくく、当日読み込み自体は
成立するが、発見事実の性質もエッジと呼ぶには弱い）。**

1. **「アナリストカバレッジが薄い銘柄」**: 時価総額約1兆582億円（Python再計算、5節）・
   ソニーグループを筆頭株主（17.39%）に持つ大型銘柄であり、東証プライムの中でも大型株に
   属する。アナリストカバレッジ数そのものの直接データは本メモの範囲では**取得不能**だが、
   時価総額規模・親会社の知名度から「カバレッジが薄い」に該当する蓋然性は低いと判断する
   （前回メモと同じ立場）。
2. **「当日中の読み込み」**: **成立**。開示は2026-08-10 11:30 JST、日次ルーチンでの検知は
   同日15:4x JST、本メモの起案完了も同日中であり、要件自体は満たす。
3. **「まだ広く認知されていない具体的な事実の発見」**: 研究メモが行った、修正純利益の
   完全不変性の指摘・自己株式取得の実質停止時期（6月末）の突合・SP.LINKS譲渡の未実行性の
   確認は、いずれも**開示原本を丁寧に読み解いた結果**であり、価値のある分析だが、
   「市場にまだ広く知られていない」ことを積極的に立証する材料（同業・指数比較データ等）は
   ない。
- **結論**: 要件2は満たすが要件1が成立せず（大型・広カバレッジの蓋然性）、要件3も限定的成立に
  留まるため、基準4は不成立。

### 4基準の総括

| 基準 | 判定 | 決め手 |
|---|---|---|
| 1. カタリスト未織り込み | **不成立** | 当日株価+2.42%・出来高1.70倍で市場は反応済み。5269より厳格 |
| 2. 同業比バリュエーション下位 | **不成立** | PBRは改善したがPERが突出して最高（低ROE約2.6%という構造的欠陥） |
| 3. 進捗が会社予想を上回る | **不成立** | 見出し指標の超過は一過性項目起因。恒常的収益力指標(修正純利益)は小幅超過のみ、かつ会社は予想据え置き |
| 4. エッジ仮説との整合 | **不成立** | 大型・広カバレッジの蓋然性が高くエッジの前提に合致しない |

**積極的採用理由: 0件。したがってBUYとしない。**

**消極法の禁止への適合確認**: 本メモが逆方向の誤り（「却下理由が見つからないからBUY」）に
陥っていないことを明記する。8729には確かに却下理由（悪材料）も存在する
（自己株式取得終了・ESR悪化継続・SP.LINKS譲渡未実行・四半期包括利益赤字）が、**本メモの
BUY見送りの論理はこれら悪材料の有無ではなく、4基準いずれについても企業調査メモの事実から
積極的な採用理由を具体的に構成できなかったこと**に基づく。同時に「却下理由が複数あるから
PASS」という逆方向の消極法にも陥らないよう、9節で個別に判定する。
