### (d) 是正しなかったが検討した論点

1. **基準2を「不成立として扱う」処理**: 起案は「成立・不成立を確定できないが、明確に割安の
   水準には届かないため不成立として扱う」とした。これは判定不能を安全側（BUYを支持しない側）へ
   倒す処理であり、消極法禁止（D-012）の裏返しとして妥当。支持し維持した。
2. **190.6億円の債権放棄を「代償」と表現すること**: 校閲者は、この債権放棄が**連結子会社ORD
   フードサービスホールディングスの債務超過を解消して吸収合併を可能にするための、グループ内
   完結の手続き**であり、放棄された債権が経済的に既に毀損していた可能性が高い（債務超過会社
   に対する債権であるため）ことを検討した。すなわち「税率改善の代償として新たな損失が生じた」
   というより「既に実質毀損していた債権を会計上認識した」という読み方も成り立つ。**ただし
   貸倒引当金の計上状況が開示されておらず（取得不能）、どちらの読み方が正しいかを断定できない**
   ため、起案の表現は変更せず、この両論をここに記録するに留めた。C5の定量化により、
   いずれの読み方でも増配の実行可能性への影響は限定的である点は確認済み。
3. **スコアを「中」へ引き上げるべきか**: C5により抑制要因が1つ弱まったが、**08/04に日経平均が
   +0.32%上昇するなかで-1.97%という明確な逆行安**（日経比-2.28pt）は、単なる無風より強い
   ネガティブシグナルであり、主力B2Cサブスクの縮小（Purple Carrot -27.5%）も構造的である。
   起案の「低」を支持し維持した。
4. **D-019による「実弾見送り」を判定に反映すべきか**: 起案は6-5節・10節2でこれを明記しつつ
   「判定そのものを左右しない」とした。D-019は**リスク管理部の照合事項**であり、投資判断部が
   これを理由に判定区分を動かすと部署の責務が混線する。起案の処理を支持し維持した。

## 3. 「08/03は無反応・08/04は逆行安」は未織り込みの証拠か——両論併記

### 3-1. 日経平均対比（研究メモ7-1節の転記）

|---|---|---|---|

| 2日累計 | -2.0258% | -0.6285% | -1.3973pt（劣後） |

### 3-2. 解釈（両論）

- **「本当に見過ごされている」説**: 08/03の-0.06%は「ほぼ無反応」であり、複数の好材料
  （純利益+13.3%・EPS最高値・増配+15.4%）が正しく評価されていない可能性がある。08/04の
  下落は無関係な需給要因（利益確定売り等）かもしれず、材料そのものへの評価とは別問題という
  解釈も可能。
- **「市場は材料と評価した上で否定的に再評価した」説**: 08/04に日経平均が上昇する中で
  明確に下落したことは、**単なる無風とは異なり、方向性を持った反応**である。(a) 事業の
  稼ぐ力（営業利益・EBITDA・売上高）は不変という「質」の問題を市場が織り込んだ可能性、
  (b) 190.6億円の親会社単体特損（一般には知られにくい情報だが機関投資家は把握しうる）を
  意識した慎重姿勢、(c) 開示原文の「当期は40%程度」という限定的な文言を、一次読解より
  正確に読んだ投資家が過度な期待を修正した可能性、のいずれか、または組み合わせが考えられる。
- **本メモの立場**: いずれの解釈が正しいかを断定する材料はない（分足データ・アナリスト
  レポート等は取得不能）。ただし、**「未織り込みで見過ごされている」と積極的に主張する
  には、08/04の明確な逆行安という反証が重すぎる**。D-012基準1の成立には至らない。

### 8-1. 190.6億円特損の増配原資への影響——校閲JDG-O52による概算（C5）

起案はこの論点を「取得不能」として定量化を断念していた。**分配可能額の厳密な算定は確かに
開示情報からは不能**だが、**配当所要額の側は開示数値から一意に概算でき、それだけでも
リスクの上限を評価できる**。校閲者がPythonで再計算した。

```python
# 発行済株式数の概算: 会社予想の親会社株主帰属当期純利益 ÷ 会社予想EPS
shares = 5210e6 / 150.00            # -> 34,733,333株
div    = 30 * shares                # 年間配当30円/株
print(round(shares), round(div))    # -> 34,733,333株 / 1,042,000,000円 ≒ 10.42億円
parent_na = 32081e6                 # 単体純資産（研究メモ、有報ベース）= 320.81億円
after     = parent_na - 19060e6     # 特損190.6億円を単純控除 -> 130.21億円
print(round(div/after*100, 3))      # -> 8.002%
```

| 項目 | 値 | 出所 |
|---|---|---|
| 発行済株式数（概算） | 約34,733千株 | 開示原本の純利益5,210百万円 ÷ EPS150.00円 |
| 年間配当所要額 | **約10.42億円** | 30円/株 × 上記株数 |
| 単体純資産 | 320.81億円 | 企業調査メモ（有報ベース） |
| 特損190.6億円の単純控除後 | **130.21億円** | 320.81 − 190.60 |
| 配当所要額 ÷ 控除後残高 | **8.00%** | — |

**評価**: 分配可能額は会社法上の算定であり単体純資産と一致しないため断定はできないが、
**「特損により増配（年間約10.42億円）が原資不足で実行不能になる」という筋書きは、
この概算の限りでは支持されない**。加えて開示原本は配当性向の目安を**20%**と明記しており、
**EPS150.00円 × 20% = 30.0円**は修正後の年間配当30円と**完全に整合**する（会社が配当性向
方針から機械的に導いた金額であり、原資の逼迫を示唆する痕跡はない）。

**したがって、起案が挙げた3つの抑制要因のうち本項の重みを引き下げ、上振れ余地スコア「低」の
論拠を残り2要因へ明示的に置き直す。** ただし本項を抑制要因から完全に外すことはしない——
**(i) 分配可能額の厳密値は依然として取得不能であり、(ii) 貸倒引当金の計上状況が不明なため
特損の実質的な純資産インパクトが190.6億円のフルなのかも確定できない**（校閲記録(d)-2）。
確認手段として3182-T5を維持する。

**総合（改訂後）**: 税率改善・B2B成長という前向きな要素はあるが、
**(1) 市場の直近反応が明確な逆行安である**（08/04に日経平均+0.32%に対し-1.97%、日経比
-2.28pt）こと、**(2) 主力B2Cサブスク事業が構造的に縮小している**こと（前期比売上-2.95%・
利益-11.71%、特にPurple Carrot -27.5%）——この**2つの重い留保要因だけでも「低」を支えるに
十分**である。9889・3673と比較しても本件は**上振れの「種」が事業モメンタムではなく税務構造
という一段細い経路に依存**しており、その経路の外側（B2Cの縮小）に不確実性が集中している。
したがって**「低」**とする（起案から変更なし）。
