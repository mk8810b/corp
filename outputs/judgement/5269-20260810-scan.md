### 校閲-2.【重要】基準3の物差しが誤っている —— 会社自身の上期計画に対してはQ1は大きく先行している

起案の基準3は、Q1実績を**通期予想に対する線形25%**と比較し「4指標中1指標のみが上回る」として
不成立と判定した。**この物差しは5269には当てはまらない。** 会社が同じ短信で公表している
**上期（第2四半期累計）予想**を分母に取ると、計画そのものが指標ごとに大きく偏っているからである
（Pythonで再計算。出典は同一の決算短信2ページ目「第２四半期(累計) 26,500 / 500 / 900 / 1,800」）。

```
会社計画の上期構成比（上期予想 ÷ 通期予想、50%が均等配分）
  売上   26,500 / 55,000 = 48.18%  ( -1.82pt)
  営業      500 /  1,900 = 26.32%  (-23.68pt)   ← 会社は営業利益を大きく下期偏重に置いている
  経常      900 /  2,400 = 37.50%  (-12.50pt)
  純利益  1,800 /  2,600 = 69.23%  (+19.23pt)   ← 特別利益19億円のQ2計上予定が織り込まれている
```

**したがって「通期の線形25%」と比べると、営業利益は体系的に過小評価され、純利益は
体系的に過大評価される。** 会社自身が置いた上期計画を分母にすると像は反転する:

```
Q1の対上期予想進捗率（線形50%が基準）
  売上   12,339 / 26,500 = 46.56%  ( -3.44pt)
  営業      313 /    500 = 62.60%  (+12.60pt)
  経常      817 /    900 = 90.78%  (+40.78pt)
  純利益    451 /  1,800 = 25.06%  (-24.94pt)
```

- **営業利益・経常利益はいずれも会社自身の上期計画を大きく上回るペースで進捗している。**
- **純利益だけが遅行しているのは、上期計画1,800百万円に特別利益19億円（2026-07-31公表・
  Q2計上予定）が含まれており、Q1にはまだ計上されていないためである**（研究メモ確認済み）。
  すなわち純利益の遅行は業績の弱さではなく、計上タイミングの問題である。

  踏まえると、この上期計画は実績に追い抜かれつつあり、上方修正の余地が具体的に存在する。

## 3. D-012の4基準の逐条判定

`playbooks/judgement.md`は「却下理由が一つも見つからなければBUY」という消極的判定を明示的に
禁止し、4基準のうち**最低1つ**を企業調査メモの事実に基づき具体的に満たすことを要求する。
以下、4基準それぞれを個別に照合する。

### 基準1: カタリスト特定済み（かつ市場にまだ十分織り込まれていないと判断できる根拠がある）

**判定: 不成立（前段は成立、後段が不成立）。**

- **前段（カタリストの特定）は成立する**: 2026-08-07 14:00の第1四半期決算短信は、営業利益の
  黒字転換（△129→313百万円）という具体的かつ構造的な事象（2-2節）として一意に特定できる。
- **後段（未織り込みの根拠）は、以下の理由から積極的に立証できない**:
  1. **反応の平坦さは「未織り込み」の確証にならない**: 終値△0.87%はσ20=1.2405%に対し1σ未満
     であり統計的にも「無反応」水準だが、これは「好材料が見落とされている」ことの証拠にも
     「好材料の実質が薄いと市場が評価した」ことの証拠にもなり得る、**両義的な事実**である
     （1節の考察）。
  2. **同種の好材料開示（2026-07-31、特別利益19億円・通期予想上方修正）も同様に商いが
     平常以下で株価がむしろ小幅下落**（343→341円、出来高104,700株＝20日平均の0.72倍、
     1-1節）しており、**単発の現象ではなく、この銘柄が好材料に対して継続的に反応が薄い
     パターンを示している**。これは「市場が気づいていない」可能性を支持する材料である
     一方、「市場は既に一連の好材料を認識した上で、様子見・懐疑的な評価を続けている」
     可能性も等しく成り立ち、両者を本メモの入力データからは判別できない（分足・同業/指数の
     同日騰落データはいずれも取得不能）。
  3. **08-07の出来高倍率1.66倍を「開示に対する反応」と断定できない**: 同銘柄は開示と無関係と
     考えられる08-03・07-29にも出来高2倍超が生じており（1-1節）、出来高変動が構造的にノイジー
     であることを示す。この特性の下では、単月・単日の出来高倍率だけで「開示に注目が集まった」
     と主張する根拠は弱い。
  4. **経常利益+154.2%という headline の質に留保がある**（2-2節）: 押し上げの主因（受取配当金・
     持分法投資利益）は縮減方針の資産が原資であり、仮に市場がこの点を正しく織り込んでいる
     のであれば、平坦な反応はむしろ合理的である。すなわち「無反応＝未織り込み」という推定
     自体が、材料の質を踏まえると弱くなる。
- **結論**: カタリストは特定できるが、「まだ十分織り込まれていない」ことを積極的に支持する
  根拠を企業調査メモ・本メモの入力データから構成できない。逆に「織り込み済みである」と
  断定する根拠もない（分足・同業同日騰落データが取得不能なため）。**本メモの主張は
  「未織り込みを立証できない」という不成立の主張であり、「織り込み済みである」という
  積極的主張ではない**（先例9889-20260803-scan.md 3節と同じ立場を取る）。基準1は不成立とする。

### 基準2: 同業比バリュエーション下位

**判定: 不成立（該当するが正当化する構造的欠陥が見当たる）。**

- **PER 7.1倍は同業3社（5290 13.7倍・5279 8.5倍・5262 15.9倍）中最低**、**PBR 0.41倍も
  最低（5279と同値）**であり、この事実自体は成立する（研究メモ9節）。
- しかし**営業利益率0.65%（26/3実績）は3社中突出して低く、27/3期会社予想3.45%でも
  なお3社中最低**（5279予想4.44%・5262予想6.37%・5290予想13.65%を下回る）。すなわち
  **今回のQ1黒字転換を織り込んだ会社自身の通期予想ですら、収益性は同業対比で構造的に
  劣後したままである**（研究メモ9節）。
- D-012基準2は「割安さを正当化する構造的な欠陥（財務悪化・成長性喪失等）が見当たらない」

  構造的な収益性の低さが確認でき、これはPER・PBRの低位を正当化しうる欠陥に該当する**。
  Q1単体の営業利益率は313/12,339=2.54%（研究メモ9節）で通期予想3.45%より低く、下期での
  更なる改善が前提として織り込まれているが、その改善が実現しても同業最低水準を脱する
  保証はない。
- したがって「割安であり、かつその割安さを正当化する構造的欠陥が見当たらない」の後段が
  満たされず、**基準2は不成立**とする。

### 基準3: 業績進捗が会社予想を上回る

- **結論: 基準3は不成立**。経常利益単独の25%超過は事実だが、その質と他3指標の未達を

### 基準4: エッジ仮説との整合（D-012、カバレッジの薄い銘柄の開示を当日中に読み込む）

**判定: 不成立（3要件のうち要件2が明確に不成立）。**

本基準は3つの要件の合成である。個別に照合する。

1. **「アナリストカバレッジが薄い銘柄」**: **判定不能（取得不能）**。時価総額198億円・
   1日売買代金83百万円（研究メモ7節）という水準は、東証プライム銘柄の中では小型・薄商いの
   部類に入るという事実は確認できるが、アナリストカバレッジそのもの（担当証券会社数・
   レーティング発行の有無）を直接示す情報源には、本メモが使用を許可されたデータソースの
   範囲内ではアクセスできなかった（研究メモ7節）。第2条に従い**取得不能**とし、推測で
   「薄い」とも「厚い」とも判定しない。
2. **「適時開示・決算短信を当日中に読み込み」**: **明確に不成立**。原開示は2026-08-07 14:00
   JST（金曜・場中）、開示検知は2026-08-10 07:51 JST（月曜）であり、**開示から検知まで
   65時間51分（土日を挟み2営業日超）が経過**している。

   ```python

   disclosure = datetime(2026,8,7,14,0)
   detection  = datetime(2026,8,10,7,51)
   td = detection - disclosure
   print(td, td.total_seconds()/3600)
   # => 2 days, 17:51:00 = 65.85時間 = 65時間51分
   ```

   **社内先例との比較**: `outputs/judgement/3673-20260804-scan.md`（開示→判断確定29時間35分）・
   `outputs/judgement/3182-20260804-scan-draft.md`（同29時間50分）は、いずれも「1営業日以上の
   経過」を理由に基準4の要件2を不成立と判定している。**本件の65時間51分は、これら2先例の
   経過時間（29〜30時間）の**2倍以上**であり、「当日中」の要件を満たさないことは先例に照らして
   一層明白である。**開示当日（08-07、金曜）はまだ約1時間（14:00〜15:00の前場引け後を除く
   実質的な取引時間）が残っていたが、その日のうちに読み込みが行われた形跡はなく、次に開示が
   検知されたのは週明け月曜の朝スキャンである。
3. **「まだ広く認知されていない具体的な事実（数値・記述）を発見できた」**: **部分的成立に
   留まる**。研究メモが行ったセグメント別損益分解（基礎事業単独+451百万円の黒字転換寄与）・
   経常利益押し上げ要因の内訳分解（受取配当金426百万円・持分法投資利益129百万円、政策保有株式
   縮減方針との関係）は、決算短信ヘッドライン数値だけでは見えない具体性を持つ。ただし
   いずれも**決算短信・適時開示という会社自身の公開原本に記載された数値**であり、「開示に
   埋もれた未認知の事実」というより「公開情報を丁寧に読み解いた結果」という性質に近い。
   「広く認知されていない」ことを立証する材料（例: 同業他社の類似分析の不在等）はない。
- **結論: 要件2が明確に不成立であるため、基準4は成立しない。** 要件1は取得不能、要件3は
  部分的成立に留まる。

採用理由の有無で判定する——を本メモは一貫して用いている（各基準の判定文がいずれも「不成立」の

## 9. 上振れ余地スコア: **中**

判定根拠（企業調査メモの事実と整合させる。機械的な数値だけでなく上振れシナリオの確度・
規模感を踏まえた定性判断——`playbooks/judgement.md`）。

**上振れを支持する要因**

- **営業利益黒字転換の構造性**: 基礎事業セグメント単独で+451百万円の黒字転換寄与があり、
  決算短信原文が「数量増（+38.9%）」「固定費吸収（製造ライン集約）」という構造要因を
  明記している（一時要因の記載なし）。これは会社側の生産体制再構築の取り組みが実を結び
  始めている実在の事実であり、下期以降も継続すれば通期営業利益予想（1,900百万円、
  進捗16.47%）の達成・上振れにつながりうる。
- **バリュエーションの絶対水準の低さ**: PER 7.1倍・PBR 0.41倍は同業3社中最低であり、
  仮に営業利益率の同業対比劣後が縮小方向に向かえば、再評価（マルチプル切り上げ）の
  余地が数値上は大きい。
- **配当利回り2.92%**（会社予想ベース）と増配基調（前期8.00円→予想10.00円）は、
  下値での需給下支えとして機能しうる（テール評価・下値耐性として別枠扱い、上振れ余地
  スコアには算入しない）。

**上振れを抑制する要因**

- **営業利益率が同業対比で構造的に劣後**: 27/3期会社予想でも3.45%と同業最低であり、
  低PER・低PBRの少なくとも一部は業容（低収益体質）を正しく織り込んだ結果である可能性が
  高い。上振れが実現するには、この構造的な収益性ギャップ自体の縮小が必要であり、
  ハードルは相応に高い。
- **経常利益の押し上げ要因の持続性に留保**: 受取配当金・持分法投資利益（504百万円の
  ギャップの約85%を占める受取配当金426百万円）は、縮減方針にあり既に目標超過見通しの
  政策保有株式が原資である。保有残高縮小が進むほど将来の同種収益は細る方向にあり、
  「経常利益+154.2%」の再現性は本業（営業利益）の伸びほど確度が高くない。
- **包括利益のマイナス（△498百万円）**: 損益計算書上の増益と裏腹に、保有する政策保有
  株式の時価評価は悪化しており、資産サイドの評価は逆方向に動いている。
- **流動性の薄さ**: 時価総額198億円・1日売買代金83百万円（研究メモ7節）という水準は、
  上振れが実現した場合でも再評価の速度・規模を制約しうる。
- **需要環境が横這い**: 決算短信原文「コンクリートパイルの全国需要は…低調であった前年
  同期と概ね横這い」「コンクリートポールの全国出荷量も前期並み」（研究メモ8節）。
  基礎事業の増収はシェア獲得によるものであり、市場全体の拡大を伴っていない。

**総合**: 営業利益の黒字転換という中核的な好材料は実在し、決算短信原文で構造要因が
明記されている点で確度は相応に高い。一方、経常利益の質（縮減方針資産への依存）、
同業対比で構造的に劣後する収益性、需要環境の横這いという複数の抑制要因が同時に存在し、
