## 3. D-012の4基準の逐条判定

### 基準1: カタリスト特定済み（かつ市場にまだ十分織り込まれていないと判断できる根拠がある）

**判定: 不成立（前段は明確に成立、後段は積極的に立証できない）。**

- **前段（カタリストの特定）は明確に成立する**: 通期業績予想の大幅上方修正・増配という
  具体的な開示であり、金額・パーセンテージも確定している（2節）。
- **後段——支持材料**: 開示が引け後（15:30）であり、本則市場はまだ一度もこの開示に対して
  取引していない（1節）。
- **後段——反証（本メモが重視する事実）**:
  1. **PTSが終値比+20.42%という明確なプラス**を示している（1-1節）。板は薄いが実際の約定
     であり、「まだ気づかれていない」のではなく「気づいた上で強く好感している」ことを
     示唆する。3964先例（PTS+18.11%→基準1不成立の反証）と同型の機能を果たす。
  2. **直近30営業日で既に+56.2%の先行上昇**があり、基準日株価自体が30営業日の終値高値
     そのものである（1節）。「割安な入り口が事前に織り込まれていない」とは言えない。
  3. **基準日（08-10）当日の出来高が20日平均の1.9〜2.1倍**（開示前の通常取引時間中の
     水準として）に達しており、開示前から既に強い商い（先行的な関心の高まり）があった
     ことを示す。
  4. 見出しの+185.7%等に対し「残り9ヶ月」含意のYoYは+27.7%等に縮小し（2節）、上方修正の
     「質」自体に一過性要因の混入が確認されている。
- **結論**: 「本則市場が未反応」という支持材料はあるが、**PTSの明確なプラス反応・30営業日で
  の顕著な先行上昇・開示前からの高出来高という3つの反証が重なっており**、「市場にまだ十分
  織り込まれていない」と積極的に主張することはできない。基準1は不成立とする。

### 基準2: 同業比バリュエーション下位（本メモが最も重点的に検討する基準）

**判定: 不成立（前段は明確に成立するが、後段——割安さを正当化する構造的な欠陥の不在——が
成立するとは言えない）。**

**前段（バリュエーションの絶対的な低さ）は明確に成立する**: 予想PER3.00倍は、同業3社
（丸文12.0倍・三信電気10.3倍・東京エレクトロンデバイス13.6倍）の**1/3〜1/4**であり、
無視できない乖離である（2節）。

**後段の検討——「シクリカルのピーク益に市場が正しく低い倍率しか与えていない」可能性**:

1. **利益構成の極端な一事業依存**: Q1連結営業利益4,771百万円のうち4,698百万円＝**98.5%**が
   デジタルデバイス（メモリ関連）セグメント単独に由来する（研究メモ4節）。他4セグメントの
   寄与は連結ベースでごく限定的であり、実質的に「メモリ市況の代理変数」に近い利益構造である。
2. **その市況自体が急騰局面のピークにある**: 会社調べの汎用メモリ（DDR5）価格推移指数は
   25年1-3月=100を基準に、26年1-3月763→直近(26年7月以降)**1,000**へ上昇している。**約1年半で
   価格指数がおよそ10倍**という水準は、循環商品としては典型的な過熱局面を示唆する（研究メモ4節）。
3. **会社自身が持続性に慎重である**: 業績予想の修正お知らせ本文（原文引用、研究メモ3節）——
   「在庫販売等については、第２四半期以降の寄与が限定的となることを見込むとともに、
   今後のメモリ市場や価格動向等の事業環境を慎重に織り込み、通期業績予想を算定しております」。
   会社自身が「見出しの水準がそのまま続く」とは言っていない。
4. **定量的な裏付け**: 見出しの通期修正率（営業利益+185.7%）に対し、「残り9ヶ月」の含意
   YoYはわずか+27.7%（2節）。修正後EPS814.69円の相当部分がQ1の一過性要因（在庫販売・
   在庫評価益）に由来する。
5. **感応度開示の不在**: メモリ市況が反転した場合の業績・在庫評価への定量的な感応度は、
   決算短信・決算説明資料のいずれにも記載がなく「取得不能」（研究メモ7節・9節）。市場が
   織り込むべきテールリスクの規模を会社自身も定量説明していない。

**本メモの判定**: 上記1〜5はいずれも研究メモが一次資料（決算短信・決算説明資料の原文・
セグメント情報）に基づき確認した事実であり、推測ではない。予想PER3.00倍という数値だけを
切り出せば「単純な出遅れ」に見えるが、**その分母（EPS814.69円）自体が、単一の商品市況が
1年半で10倍に達した局面のQ1実績に強く牽引されており、しかもその押し上げ要因の相当部分が
会社自身の言葉で「第2四半期以降は限定的」と位置づけられている**。これは一般的な意味での
「見落とされた優良企業」ではなく、**「コモディティ市況の循環的なピーク利益に対して市場が
相応に低い倍率しか与えていない」という、シクリカル株の教科書的な構図に該当する可能性が高い**。
この解釈は本メモの評価であり断定はしないが（第2条・越権禁止の範囲内での定性判断）、
**「その割安さを正当化する構造的な欠陥（財務悪化・成長性喪失等）が見当たらない」という
D-012基準2の後段要件を積極的に立証することはできない**。したがって基準2は不成立とする。

（PBR1.55倍は同業比では丸文0.84倍・三信電気0.82倍より高く、東京エレクトロンデバイス2.39倍
より低い中位水準であり、PBRの軸では「明確な下位」ですらない点も付記する。予想配当利回り
1.72%は同業3社2.98〜4.63%より低い。）

### 基準3: 業績進捗が会社予想を上回る

**判定: 不成立。**

旧通期予想（営業利益3,500百万円）はQ1実績（4,771百万円）単体で既に**136.3%**まで進捗しており、
経常・純利益も同様（149.9%・151.6%）に旧予想を上回っていた（研究メモ2節）。しかし、
**会社自身が本決算と同時に通期予想を上方修正済み**であり、市場が今後参照するのは既に
更新された新しい会社予想（営業利益10,000百万円）である。旧予想比での進捗の良さを主張しても、
市場との情報非対称性の根拠にはならない（3182・3964・4751先例と同型の理由付け）。

さらに、新予想に対する「残り9ヶ月」の含意進捗も、前年同期比+27.7%（営業利益）と控えめであり
（2節）、「会社予想を上回るペースで進捗している」という基準3が想定する前向きな構図には
当てはまらない。**むしろ本件は「四半期実績が年間ガイダンスを追い越し、機械的な訂正を
迫った」という先例4751 校閲JDG-O62（校閲-2）の論法とほぼ同型であり**、上方修正という
イベント自体が持つ新規情報量は見出しの増減率が示唆するより小さい。

### 基準4: エッジ仮説との整合（アナリストカバレッジが薄い銘柄の開示を当日中に読み込む）

**判定: 不成立（3要件のうち1要件が取得不能でAND条件を確定できない。3964先例と同型の扱い）。**

1. **「アナリストカバレッジが薄い銘柄」**: 時価総額**194億円**（研究メモ6節、kabutan.jp）、
   東証**スタンダード**市場上場であり、4751（時価総額7,602億円・日経225構成銘柄）・
   9432（NTT）のように前提を客観的に**否定する**材料はない。むしろ小型株・スタンダード
   市場という属性は「薄い」仮説と整合的な方向を示す。ただし、具体的なアナリスト数・
   レーティング分布そのものは無料公開情報の範囲では確認できず「取得不能」（研究メモ9節）。
2. **「適時開示・決算短信を当日中に読み込み」**: 開示（08-10 15:30）から判断確定
   （08-12 08:50）まで**41時間20分**が経過し、暦日では2日を跨いでいる（下記コード）。
   文言上の「当日中」は満たさない。一方、この間に東証の取引セッションは一度も開いておらず
   （08-11山の日）、**実質面（市場が本則市場で反応する機会がまだ一度もない）は支持できる**。
   ただし4751・3964と異なり、**本銘柄はPTSで実際の約定（5,000株）が成立しており**、
   「市場参加者の反応が一切ない」とまでは言えない点は差し引いて評価する。
3. **「まだ広く認知されていない具体的な事実の発見」**: 研究メモが発見した「残り9ヶ月」
   含意YoY+27.7%（見出し+185.7%との乖離）・旧予想のQ1単体超過（136.3%）・セグメント依存度
   98.5%・DDR5価格指数10倍は、いずれも決算短信・決算説明資料の精読（PDF原本の
   セグメント情報・注記本文）による独自の発見であり、この要件は相応に成立する。

```python
from datetime import datetime
disclosure = datetime(2026, 8, 10, 15, 30)
detect     = datetime(2026, 8, 12, 7, 51)
decision   = datetime(2026, 8, 12, 8, 50)
market_open = datetime(2026, 8, 12, 9, 0)

def hm(td):
    m = int(td.total_seconds() // 60)
    return f"{m // 60}時間{m % 60}分"

print("開示→検知", hm(detect - disclosure))
print("開示→判断確定", hm(decision - disclosure))
print("検知→判断確定", hm(decision - detect))
print("判断確定→寄り付き", hm(market_open - decision))
print("暦日差", (decision.date() - disclosure.date()).days)
```

実行結果: 開示→検知 **40時間21分**、開示→判断確定 **41時間20分**、検知→判断確定
**59分**、判断確定→寄り付き **10分**、暦日差 **2日**（間に休場日08-11を1日挟む）。

**結論**: 要件1（カバレッジの薄さ）が客観的に「該当を否定する」材料はないものの
「確定的に該当する」データも取得不能であり、要件2は文言上不成立（実質面は支持）、
要件3は成立。**3要件をAND条件と解する先例の枠組み（3964）に従い、要件1が確定できない
以上、基準4は成立と断定しない**。

|---|---|---|
| 1. カタリスト未織り込み | **不成立** | PTS+20.42%・30営業日+56.2%先行上昇・開示前から高出来高という3つの反証 |
| 2. 同業比バリュエーション下位 | **不成立**（前段成立・後段不成立） | 98.5%の単一セグメント依存＋DDR5価格指数約10倍のピーク局面＋会社自身の持続性への留保 |

WATCHに留め置く」という消極法の裏返しには陥っていない——むしろ独立した複数の具体的な
留保事項に基づく判断である。

### 校閲-6. WATCH と PASS の分岐 —— WATCHを追認する

#### 校閲-6-1. 判定そのもの

**WATCHを追認する。** 理由:

   希薄化条項も**ゼロ**であることが原本で裏づけられた。**先例3856でPASSを正当化した
   種類の確定的な悪材料は、本銘柄には積極的に存在しないことが確認された。**
2. **未解決の対立に、日付の定まった決着点がある。** 基準2の核心（慢性ディスカウントが

#### 校閲-6-2. D-010（WATCH上限20）の枠を消費するに足るか —— 足りる

校閲が `corp/watchlist.md` を独立に機械集計し、**起案の「ACTIVE=22銘柄」を再現確認した**

**台帳が満杯であることは、その銘柄の投資判断とは無関係な運用側の事情であり、

スコアの低い順に週次ルーチンが機械的に落とす」という設計である（`corp/watchlist.md`
運用ルール）。足切りは週次ルーチンの所管であり、投資判断部が先回りしてPASSにするのは

そのうえで、**起案の申し送り4が懸念した「本件が直ちに足切り対象になる」という事態は、

```python
# 出典: corp/watchlist.md（校閲が2026-08-12に機械集計）。ACTIVE=22銘柄、うち優先度「低」は5銘柄

print("低グループ（WATCH判定日の古い順）:", [c for c,_ in sorted(low, key=lambda x: x[1])])

```
