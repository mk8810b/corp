## 4. D-018統制語彙に基づく9434-T1（価格トリガー）の判定・σ20算出（全数値Python再計算）

`playbooks/judgement.md`のD-018定義に従い、「明確に下抜け」の閾値を **max(基準価格の2%, σ20,
呼び値1ティック)** で算出した。基準価格は前日終値224.5円とする。

```python
import statistics
# closes: 2026-05-12〜2026-08-04の60営業日分（kabutan.jp日足ページ2ページ分、curl取得）
# today_idx = 2026-08-04のインデックス
prev_close = 224.5
def pct_returns(cl):
    return [(cl[i]-cl[i-1])/cl[i-1]*100 for i in range(1,len(cl))]

# 窓A: 直近20営業日（当日除く）
window_excl = closes[today_idx-21:today_idx]
returns_excl = pct_returns(window_excl)
sigma20_excl_pop  = statistics.pstdev(returns_excl)   # 1.4440%
sigma20_excl_samp = statistics.stdev(returns_excl)    # 1.4815%

# 窓B: 直近20営業日（当日含む）
window_incl = closes[today_idx-20:today_idx+1]
returns_incl = pct_returns(window_incl)
sigma20_incl_pop  = statistics.pstdev(returns_incl)   # 1.5189%
sigma20_incl_samp = statistics.stdev(returns_incl)    # 1.5584%

two_pct = prev_close * 0.02   # 4.4900円
for label, s in [("窓A(当日除く)-母標準偏差", sigma20_excl_pop), ("窓A(当日除く)-標本標準偏差", sigma20_excl_samp),
                 ("窓B(当日含む)-母標準偏差", sigma20_incl_pop), ("窓B(当日含む)-標本標準偏差", sigma20_incl_samp)]:
    sigma_yen = prev_close * s/100
    threshold = max(two_pct, sigma_yen, 1.0)
    print(label, f"sigma20={s:.4f}% -> {sigma_yen:.4f}円, 閾値={threshold:.4f}円")
```

| 窓A（当日除く・20営業日: 07/03〜08/03）・母標準偏差 | 1.4440% | 3.2418円 | **4.4900円**（2%が支配） |
| 窓A（当日除く）・標本標準偏差 | 1.4815% | 3.3260円 | **4.4900円** |
| 窓B（当日含む・20営業日: 07/06〜08/04）・母標準偏差 | 1.5189% | 3.4099円 | **4.4900円** |
| 窓B（当日含む）・標本標準偏差 | 1.5584% | 3.4986円 | **4.4900円** |

**4系列すべてで2%成分（4.49円）が支配的であり、窓・母標本の選択に結論は依存しない**
（社内規約未確定だが裁定不要）。

## 5. D-012・4基準の正面からの再照合

`playbooks/judgement.md` D-012（BUY判定の基準）に基づき、4基準それぞれについて本決算短信の
事実に基づき積極的に当てはめる。**「却下事実が見当たらないからWATCH」という消極的な判定は
禁止されているため、各基準を具体的な数値・事実で検証する。**

### 基準1: カタリスト特定済みかつ市場が未織り込みか

- 本決算短信自体は当日15:30 JSTの開示であり、市場の当日反応（終値-1.83%、出来高倍率
  1.0037倍〔確定値ベース、3・4節参照〕）を4節の通りD-018閾値と照合した結果、**「明確な反応」と
  呼べる水準ではない**（下抜け閾値4.49円/2.00%を下回る変動、出来高も平均並みで1.5倍を大幅に
  下回る）。
- 同業NTT（-1.31%）・KDDI（-0.95%）も同日下落しており、9434固有の反応というより
  **セクター/市況要因が主因の可能性が高い**（3社とも決算発表日が近接しているわけではなく、
  同日同方向の値動きは個別の決算材料というより地合いの影響を示唆する）。
- 決算内容自体は「全セグメント増収」「通期予想・配当予想とも修正なし」「進捗率がおおむね
  前年同期並み」というin-lineな内容であり、**株価を動かす具体的なサプライズ（上振れ・下振れ
  いずれの方向でも）は本短信からは確認できない**。
- **結論: 基準1は不成立。** 新規カタリストと呼べる事象は本日確認されず、市場も明確な反応を
  示していない（「未織り込み」を主張する前提となる材料自体が存在しない）。

### 基準2: 同業比バリュエーション下位かつ構造的欠陥なしか

- PBRは前回判定時（2026-07-09）の3.90〜3.92倍から**4.00倍へさらに上昇**（Python差分:
  `4.00-3.92=0.08`、`4.00-3.90=0.10`）。PERも18.36〜18.8倍から**19.1倍へ上昇**。
- 同業比較（本日時点）: NTT PBR1.26倍・KDDI PBR2.10倍に対し、9434は4.00倍で**依然として
  3社中最も割高、かつその格差は前回より拡大**。
- **結論: 基準2は明確に不成立。** 「同業比バリュエーション下位」の要件を満たさないどころか、
  前回WATCH判定の根拠だったバリュエーション懸念が悪化方向に進行している。

### 基準3: 業績進捗が会社予想を上回るか

- 1-2節のPython再計算の通り、通期予想に対する進捗率は売上収益24.20%・営業利益27.48%・
  純利益26.80%。前年同期の自社ペース（23.56%/27.89%/26.38%）との差分は+0.64pt/▲0.41pt/
  +0.42ptといずれも1pt未満。
- **結論: 基準3は不成立。** 「会社予想を明確に上回る進捗」と評価できるほどの乖離はなく、
  前年同期並みのin-lineな進捗である。

### 基準4: エッジ仮説（未認知の具体的事実の発見）

- 一次資料（決算短信PDF）を当日中に直接読み込んだ結果として新たに把握した事実:
  (i) 自己資本比率が16.0%→15.1%へさらに低下（1-5節）、
  (ii) 営業CFが前年同期比で約半減しFCF赤字が拡大（1-6節、前回メモには未記載の新規事実）、
  (iii) メディア・EC事業の減益は前年同期の企業結合再測定益の剥落という会計要因であり、
  前回メモが把握していた「アスクル障害由来」とは別の一過性要因（1-4節）。
- これらは事実として「市場でまだ広く認知されていない」とまでは言えない（開示当日の一次資料の
  範囲内での事実整理であり、既存の懸念〔財務レバレッジ〕を補強する追加データという性質が強い）。
  かつ、いずれも**ポジティブ方向の未認知事実ではなく、既存のネガティブ材料を補強する事実**である。
- **結論: 基準4は不成立。** 発見した具体的事実（自己資本比率低下・CF悪化）はBUYの積極的採用理由
  たり得ず、むしろ前回WATCH判定の慎重姿勢を裏付ける方向に働く。

### 5-5. 総合判定

**D-012の4基準はいずれも不成立。** 積極的なBUY採用理由が一つも存在しないため、BUY判定は
行わない（この点はD-012の「却下理由がないからBUYの禁止」の裏側として自明に導かれる）。

一方、PASS（見送り確定）へ格下げすべき事由も見当たらない: (i) 事業は全セグメント増収を継続し
壊滅的な悪材料はない、(ii) D-015テール脆弱性フラグは4項目とも非該当、(iii) 通期予想・配当予想とも
修正なしで会社側の中期見通しに変化はない。**「ネガティブ材料が悪化方向に進行している」ことと
「即座にPASSへ格下げすべき決定的な悪材料が出た」ことは別であり、本決算は前者に該当するが後者には
該当しない**（進行方向の悪化はあるが、水準として壊滅的ではない）。

したがって、**本稿はWATCH継続を、消極的な据置きとしてではなく、D-012の4基準を実際に当てはめた
結果として能動的に結論する**。バリュエーション懸念（基準2で確認したPBR上昇）・財務レバレッジ懸念
（自己資本比率低下・CF悪化）はいずれも前回メモの主要な留保事項であり、本決算はこれらを解消する
どころか強化する内容であった。
