## 3. 不動産売却余地の概算（Python、前提を明記した粗い試算）

出典: RSH-S77 5節（決算短信・半期報告書の連結貸借対照表）。

```python
re_2025_end = 6869   # 2025.12期末 土地+建物純額（百万円）
re_2026_h1  = 5447   # 2026年6月末
book_decline = re_2025_end - re_2026_h1
print("半年での不動産簿価の減少額:", book_decline, "百万円")

op_h1_2026 = -1090   # 2026.12期H1営業損益
remaining_book = re_2026_h1
periods_upper = remaining_book / abs(op_h1_2026)
print("[過大評価な上限参考値] 残存簿価5,447百万円を仮に全額が実現可能な含み益と仮定した場合、")
print("直近の半期営業赤字ペース(-1,090百万円)で除すと約", round(periods_upper, 1), "半期分（約",
      round(periods_upper/2, 1), "年分）に相当")
```

出力: 半年での簿価減少額1,422百万円、**過大評価な上限参考値として約5.0半期分（約2.5年分）**。

**この試算の前提と限界（第2条に従い明記）**:

- これは**残存する不動産の簿価そのものを、仮に全額が売却益（含み益）として実現できると仮定した
  場合の理論上限**であり、実際にはあり得ない過大評価である。売却益は「売却対価－簿価」であり、
  簿価と売却益は別概念。実際の含み益率（時価と簿価の差）は決算短信・有価証券報告書に開示が
  なく、**取得不能**（RSH-S77 5-1節・12節と同様の結論）。
- より保守的な参考値として、これまで実現した売却益（大阪本社7,054百万円・千葉CC1,251百万円、
  合計8,305百万円）が資産側の簿価減少額（1,422百万円、2025.12末→2026.6末）に対しどの程度の
  倍率で実現したかを算出しようとしたが、**個々の物件の取得原価・含み益率が開示されていないため
  算出不能（取得不能）**。
- 営業赤字のペース自体も、H2の実績次第で変動しうる（4節参照）。
- **結論**: 「あと何期分の売却余地が残っているか」について確度の高い数値は出せないが、
  **粗い上限として2.5年程度、それより短い可能性が高い**という方向性は示せる。不動産（土地＋建物）
  は総資産に占める比率も2025.12期末26.2%→2026年6月末22.6%へ既に圧縮されており、**同型の
  特別利益を反復して計上できる余地は限定的になりつつある**（RSH-S77 5-1節の評価を、本メモは
  独自の概算計算で数値的に補強する）。

## 4. 赤字縮小トレンドの読み方——再建進捗か、縮小しているだけで未黒字化か

### 4-1. 売上高・営業利益率の推移（切り分け試算）

```python
sales = [58915, 49226, 45859, 42071, 41000]
op    = [-8139, -5557, -3459, -2588, -1200]
sales_pct = [round((sales[i+1]-sales[i])/sales[i]*100, 2) for i in range(len(sales)-1)]
margin    = [round(op[i]/sales[i]*100, 2) for i in range(len(op))]
print("売上高前年比(%):", sales_pct)
print("営業利益率(対売上高、%):", margin)
```

出力:

| 決算期 | 売上高前年比 | 営業利益率 |
|---|---:|---:|
| 2022.12 | － | △13.81% |
| 2023.12 | △16.45% | △11.29% |
| 2024.12 | △6.84% | △7.54% |
| 2025.12 | △8.26% | △6.15% |
| 2026.12（予想） | △2.55% | △2.93% |

### 4-2. 解釈——切り分け可能な部分と不能な部分を分ける

- **売上高の減少率は単調に縮小していない**（△16.45%→△6.84%→△8.26%→△2.55%と、2025.12期に
  一度悪化してから再び縮小に転じている）。「毎期きれいに減速している」わけではない。
- 一方、**営業利益率（対売上高）は5期にわたり単調に改善している**（△13.81%→△11.29%→
  △7.54%→△6.15%→△2.93%予想）。売上高の減少率が一定でない中でも利益率が一貫して改善して
  いることは、**売上減少に単純比例した固定費の自然減だけでは説明しにくく、固定費削減等の
  構造改革の要素が一定程度寄与している可能性を示唆する**。
- **ただし、この示唆は公開情報の範囲で確度の高い切り分けには至らない。** 店舗閉鎖数・人員削減数・
  物流拠点の統廃合等、固定費削減の具体的な内訳（何をどれだけ減らしたか）は決算短信・有価証券
  報告書に定量的な開示がなく、本メモの取得範囲では**取得不能**である。RSH-S77 3-3節が示す
  セグメント別内訳（通信販売事業単独で△3,082百万円の営業赤字、他3セグメント合計+491百万円）
  からも、主力の通信販売事業がなお大幅な赤字であることは分かるが、その赤字縮小が店舗網・
  物流費の構造的な削減によるものか、単に売上規模が小さくなったことに伴う変動費の減少に過ぎ
  ないかを厳密に切り分けるデータはない。
- **結論: 「構造改革か自然減か」は切り分け不能と明記する。** 営業利益率の一貫した改善という
  傍証は「単なる縮小均衡ではない」方向を示すが、これを積極的なBUY理由（D-012基準3「業績進捗が
  会社予想を上回る」）として採用するには材料として弱い——**進捗率90.8%（RSH-S77 4-1節）は
  「会社予想どおりに進んでいる」ことを示すに過ぎず、「予想を上回るペース」ではない**。
- **判定への含意**: 切り分け不能であることは、楽観・悲観いずれの方向にも断定を許さない。
  本メモはこれを**中立的な事実**として扱い、単独ではWATCH継続の積極的理由にもPASSの理由にも
  用いない（9節・10節の判定はこの点に依拠していない）。

  一過性・営業赤字は継続」という構造が市場に認識され再評価された可能性を示唆する**。

## 10.【最重要論点3】検証経路の設計——「営業黒字化」は使えるか、PASS発火条件の設計

### 10-1. JDG-O76の3要件への当てはめ

先例（4073、校閲JDG-O76）が確立した規範4「唯一の検証経路を失うことがPASSを阻却しうるのは、
次の3要件をすべて満たす場合に限る」（(i)中核性・(ii)期日確定性・(iii)判定連結性）を、本件の
「営業黒字化を待つ」という発想に厳密に適用する。

| 要件 | 「営業黒字化（期日を定めない一般論として）」への当てはめ | 判定 |
|---|---|---|
| (i) 中核性 | 本WATCHの中核仮説（D-023フィルタが「収益力に対する割安」を意味するか）に直接答える | **充足** |
| (ii) 期日確定性 | **「いつか営業黒字化する」という一般的な期待には確定した予定日・明示の期限がない。** 会社の「再生計画（2025〜2027年）」は目標年度を掲げるが、2026-08-07修正後の会社予想自体が2026.12期はなお営業赤字（△1,200百万円）を見込んでおり、「期日の定まらない待ち」に留まる | **単独では不充足** |
| (iii) 判定連結性 | 営業損益の黒字化・赤字継続は、D-012基準2（構造的欠陥の有無）・基準3（業績進捗）双方の成否を動かしうる | **充足** |

**結論: 「営業黒字化そのもの」を漠然とした検証経路として使うことはできない（期日確定性を欠く）。**
タスク指示が求めるとおり、これを理由にWATCHを無期限に継続することを本メモは禁止する。

### 10-2. 期日を確定させた形での検証経路の再設計

期日確定性の欠落は、**確定した開示日程に紐づけることで解消できる**。本メモは以下の設計を採る:

- 2025.12期決算は2026-02-13に公表された。**次回本決算（2026.12期本決算）の正確な公表予定日は
  本メモの取得範囲では確認できず、取得不能と明記する。** 前期の公表パターンから**2027年2月中旬
  頃**と推定されるが、これは推定であり確定日ではない。
- **backstop期日を2027-02-28と設定する。** この日までに本決算開示が確認されない場合も、
  同日をもって「検証未了・要確認」として次回の判断メモで扱う（無期限の据え置きにしない）。
- この形（次回本決算という確定した開示イベントに紐づけ）であれば、(ii)期日確定性も充足し、
  3要件すべてを満たす検証経路として機能する。

### 10-3.【PASS発火条件（T3）の設計】立証責任の転換と無限後退の終端

先例3673-T11・5074-T7・4052-T12/T13に倣い、以下の条件を`corp/watchlist.md`転記用の条文として
設ける（10-4節でトリガー一覧に整理）:

> **8165-T3（決算・既定PASS引き金）**: 次回本決算（2026.12期本決算、公表予定日は取得不能。
> 前期実績から2027年2月中旬頃と推定、**backstop期日2027-02-28**）において、
> **(a)** 営業損益が5期連続の赤字で確定し、**かつ (b)** その赤字を相殺する新たな特別要因
> （不動産等資産売却益等）なしには最終損益も黒字化しない、または黒字であっても主として
> 一過性要因に依存する場合、**PASSへの格下げを既定路線として積極的に検討する（立証責任の
> 転換: WATCH継続を選ぶ場合は継続を正当化する新規事実を新しい判断メモに明記することを要する）**。
> **「材料が未定量であることはPASSを回避する理由にならない」（3863-T5先例）。**
> **本トリガーの処理をもって、「営業黒字化がいつか実現するかもしれない」という期日の定まらない
> 期待を、以後WATCH継続の理由に用いることを禁止する（無限後退の終端）。** 同型の後継トリガー
> （「その次の決算を待つ」式の機械的な繰り返し）の新設は行わない。

これにより、10-1節で「使えない」と判定した「営業黒字化を待つ」という漠然とした理由付けを、
確定日程に紐づけた一回限りの検証経路へ転換し、かつ**その検証が不成立に終わった場合の
無限後退（次も待つ、その次も待つ）を条文自体で禁止する**。

## 11. 株価帯・D-009下限との近接性・単元・プロベーション比率

### 11-1. D-009下限（100円）との近接性


**この近接性が意味すること**: D-009はスクリーニング段階のフロア条件（呼び値1ティックの変動が

境界線上にあるという特殊性を持つ**。本メモはこの事実を記録し、将来のBUY判断メモ起案時に
再検討を要する論点として申し送る（14節）。

### 11-2. 単元・プロベーション比率（参考値、WATCH判定のため実弾投入なし）

## 12.【D-018統制語彙】再評価トリガーの設定

判定基準日2026-08-14、確定終値110.0円を基準に`max(2%, σ20, 呼び値1ティック)`を計算する。
**σ20はRSH-S77 11-2節で機械計算済み（1.598%、20営業日日次リターン標準偏差）であり取得不能

```python
import math
close = 110.0
sigma20_pct = 1.598
pct2 = close*0.02
sigma_yen = close*sigma20_pct/100
tick = 1.0
tick_pct = tick/close*100
gate = max(pct2, sigma_yen, tick)
print("2%成分:", round(pct2, 4), "円")
print("σ20成分:", round(sigma_yen, 4), "円 (σ20=1.598%)")
print("呼び値1ティック:", tick, "円 (株価比", round(tick_pct, 4), "%)")
print("gate:", round(gate, 4), "円 → 2%成分が支配")
upper = math.ceil(close+gate)
lower = math.floor(close-gate)
print("上抜け閾値:", upper, "円以上　下抜け閾値:", lower, "円以下")
avg_vol20 = 140125.0
print("出来高1.5倍水準:", avg_vol20*1.5, "株")
```

σ20成分（1.7578円）・呼び値1ティック（1.0円）のいずれよりも大きく、gateを支配する。** これは
タスク指示のとおり「呼び値1ティックが株価比0.909%に相当し、2%（2.2円）の方が大きい」ことを
明示的に確認したものである。上抜け閾値113円以上、下抜け閾値107円以下。出来高1.5倍水準
