## 1. BUY判定4基準（D-012）の検討

## 2. 「開示は本日中でまだ十分織り込まれていないか」の正面からの検討

- **事実関係の整理**（研究メモ0・6節から）: 本日15:30、TDnet掲載と当日の高値=終値=引け値の
  時刻が完全に一致している。すなわち、本日の通常取引時間中の値動き（始値2,839.0円→
  終値2,864.0円、+2.51%）は本開示が出る**前**の値動きであり、開示に対する市場の反応を
  一切含んでいない可能性が高い（少なくとも開示後の反応時間は実質ゼロ）。
- **引け後のPTS（20:27時点）**: 2,875.5円（東証終値比+0.4%）、出来高わずか200株。この出来高は
  同銘柄の通常の日中出来高（166万株超）の0.012%に過ぎず、値付けとして意味を持つ水準ではない。
  したがって「PTSが小幅上昇＝材料は限定的と織り込まれた」と解釈することも、「PTSが薄く
  まだ気づかれていない」と解釈することも、どちらも統計的な根拠を持たない。研究メモ自身が
  「判断材料として不十分」と明記している通りである。
- **本メモの評価**: 上記を踏まえると、「本日終値+2.51%は開示を十分に織り込んだ結果である」
  という解釈も、「開示はまだ全く織り込まれていない」という解釈も、**どちらも積極的に立証
  できない**というのが正直な評価である。これは基準1（カタリスト特定済み・未織り込み）を
  「積極的に成立」と判定することを妨げる直接の理由になっている（1節参照）。
  翌営業日（2026-07-30予定、休場でなければ）の寄り付き以降の値動き・出来高こそが、本開示への
  市場の実際の反応を測る最初の機会であり、これをWATCHトリガーの中心に据える（6節）。
- **PBRが同業比で高めである点の評価**: 研究メモ6節の通り、4613のPBR1.68倍は同業4社中最も
  高い水準にある。これは「同業比バリュエーション下位」という基準2に該当しないだけでなく、
  「本開示が本当に大きな価値創造を伴うなら、市場は既にある程度のプレミアムを織り込んで
  値付けしている可能性がある」という見方とも整合的である。すなわち、バリュエーション面からは
  「未織り込みの割安株」という積極的なBUYストーリーを描きにくい状況にあると評価する。

## 3. 出来高・σ20の再計算（Python、D-018トリガー設計の前提）

企業調査メモの出来高比較節（6節）に加え、σ20（直近20営業日の日次終値変動率の標準偏差）は
企業調査メモに未掲載のため、本メモで追加取得・算出する。

- 出典: `https://kabutan.jp/stock/kabuka?code=4613&ashi=day&page=1`（curl取得、
  取得日時2026-07-29T23:23:45Z）。日足終値・出来高データを取得し、Pythonで再計算した
  （企業文化2章-5準拠）。

```python
# 直近20営業日（2026-06-30〜2026-07-28、当日2026-07-29を除く。研究メモ6節と同一窓）
window20_close = [2794.0, 2739.0, 2661.5, 2701.0, 2673.0, 2680.5, 2666.0, 2655.5,
                   2679.0, 2686.0, 2661.5, 2675.5, 2708.0, 2770.0, 2791.0, 2798.5,
                   2756.5, 2698.5, 2642.5, 2648.5]   # 07/28→06/30の順
window20_vol   = [1521000,1156700,619400,572700,696700,1206800,618700,478000,
                   556400,685300,687800,889900,926000,719000,1000500,918000,
                   1293000,944700,1125700,663200]

avg_vol20 = sum(window20_vol)/20
# => 863,975株（研究メモ6節の「≈863,975株」と整合）

# 日次終値変動率（各日について前営業日終値比）を同じ20日窓で算出
returns_pct = [2.008, 2.912, -1.462, 1.048, -0.28, 0.544, 0.395, -0.877, -0.261,
               0.921, -0.523, -1.2, -2.238, -0.752, -0.268, 1.524, 2.149, 2.119,
               -0.227, -0.824]  # %

import statistics
sigma20_pop = statistics.pstdev(returns_pct)   # 母標準偏差（n=20）
# => 1.3487%
sigma20_samp = statistics.stdev(returns_pct)   # 標本標準偏差（n-1=19）
# => 1.3837%
```

**実行結果**:
- 直近20営業日平均出来高 = **863,975株**（研究メモ6節と一致）
- 本日出来高1,662,200株 ÷ 863,975株 = **1.924倍**（研究メモ6節の「約1.92倍」と整合）
- σ20（母標準偏差、n=20） = **1.3487%**（絶対額換算: 2,864.0円×1.3487% ≈ 38.63円）
- σ20（標本標準偏差、n-1=19） = **1.3837%**（参考値、絶対額換算 ≈ 39.63円）
- **2%（57.28円）＞ σ20（38.63〜39.63円）** のため、D-018のmax()判定では**2%が拘束的**
  （9432・9434と同型のパターン。研究メモ・D-018検証メモの他銘柄と整合的な結果）。
- 呼び値: 本銘柄の日足データ（安値2,800.5円・始値2,839.0円等）は`.0`または`.5`で終わって
  おり、実測ベースでは呼び値0.5円相当とみられる（JPXの呼値区分の会社別適用〔TOPIX500構成
  銘柄か否か等〕は本メモの調査範囲では**取得不能**）。ただし2%（57.28円）が呼び値の桁を
  大きく上回るため、呼び値の厳密な確定は本トリガーの成立判定には影響しない。

  (b)段階取得差益の金額自体が不明で規模感を積極的に見積もれない、(c)PBRが既に同業最高水準
  にあり再評価余地（バリュエーション面でのアップサイド）は他銘柄と比べて相対的に薄い、
  (d)トルコ競争法承認・Marmara Holding株主総会承認という実行条件が2026年10月頃まで
  未確定（研究メモ8節）、(e)トルコの高インフレ・リラ安・地政学リスクという構造的な下振れ
  要因も並存する。
- 以上を踏まえ、上振れの種はあるが規模・確度ともに「高」と評価するには材料不足であり、
  かつ明確に「低」と切り捨てるほど材料が乏しいわけでもないため、**「中」**とする
  （台帳容量20銘柄上限に対する足切り優先度の基準として使用）。
