### 2-1. トリガー成立の独立検算（Python再計算、第2条準拠）

タスク指示に従い、σ20=7.451円（既存判断メモ`7201-20260729-event.md` 9章記載の確定値。

算術を独立に再計算した。

```python
import math

base_price = 358.2       # 円、2026-07-29確定終値（基準高値。既存判断メモ9章の確定値）
two_pct = base_price * 0.02
sigma20_amt = 7.451       # 円（既存判断メモ確定値。標本標準偏差2.080%ベース、本メモでは再算出しない）
tick = 0.1

gate = max(two_pct, sigma20_amt, tick)
gate_ceil = math.ceil(gate * 10) / 10
t7_threshold = base_price - gate_ceil

close_0731 = 336.2        # 円、0-4章で3ソース収束確認済みの確定値

print(f"2%成分: {two_pct:.3f}円")
print(f"σ20成分: {sigma20_amt}円")
print(f"呼び値: {tick}円")
print(f"gate = max(...) = {gate:.3f}円 -> 切り上げ {gate_ceil}円")
print(f"T7閾値 = {base_price} - {gate_ceil} = {t7_threshold}円")
print(f"07/31確定終値 {close_0731}円 <= {t7_threshold}円 ? {close_0731 <= t7_threshold}")
print(f"下抜け幅: {base_price - close_0731:.1f}円 ({(base_price-close_0731)/base_price*100:.2f}%)")
```

**実行結果**:
