## 1. D-012 BUY判定4基準の検討

`playbooks/judgement.md`は「却下理由が一つも見つからなければBUY」という消極的判定を明示的に
禁止し、以下4基準のうち最低1つを企業調査メモの事実に基づき具体的に満たすことを要求する。

### 基準1: カタリスト特定済み（かつ市場に未織り込み）

- カタリスト自体は明確に特定できる: 通期業績予想の上方修正（営業利益+8.3%・経常利益+13.9%・
  純利益+12.5%）と増配（+3円）、2026-07-30 15:00 TDnet開示（企業調査メモ2節）。
- しかし「市場にまだ十分織り込まれていない」と積極的に判定するための根拠は、**2章の反応データの
  訂正により弱まっている**。企業調査メモが独自再取得した確定終値ベースの前日比は+3.29%であり、
  日次ルーチンが「未反応」と判定した閾値±3%を超過している。さらに開示直後の場中高値は寄付き比
  +9.97%に達しており、開示に対する強い初期反応があったことは明白である（その後押し戻されて
  いる点は2章で評価する）。
- 出来高面でも、本日出来高493,300株は独自再計算した直近20営業日平均365,675株の**1.35倍**に
  とどまり、D-018の「出来高を伴って」基準（1.5倍以上）に未達（4節）。価格は反応済み、出来高は
  基準未達という状態であり、「未織り込み」を積極的に主張する材料としては弱い。
- **結論**: カタリストの「特定」はできるが、「市場に未織り込み」を積極的な確信として明記できる
  だけの根拠が2章の分析により失われている。基準1は**不成立**。

### 基準2: 同業比バリュエーション下位

- 企業調査メモ7節の比較表: 愛三工業のPER10.3倍・PBR0.96倍は、デンソー（PER14.4倍・PBR1.00倍）
  比ではやや割安、豊田合成（PER10.8倍・PBR1.08倍）比ではほぼ同水準。一方、直接競合のミクニ
  （PER7.3倍・PBR0.31倍）比では明確に割高。
- `playbooks/judgement.md`が要求するのは「明確な割安」であり、かつ「その割安さを正当化する
  構造的な欠陥が見当たらない」ことである。本銘柄は大手2社に対しては「やや割安〜同水準」という
  限定的な割安さにとどまり、直接競合との比較では逆方向（割高）の結果が出ている以上、**「明確に
  割安」とは言えない**。
- **結論**: **不成立**。同業比較の結果が比較対象によって符号が変わる（大手同業比ではやや割安、
  直接競合比では割高）ため、積極的なBUY理由として採用できるだけの明確性がない。

### 基準3: 業績進捗が会社予想を上回る

Python再計算（企業調査メモ2-1節・5-4節の数値を使用）:

```python
guide_rev = {"売上高":335000, "営業利益":19500, "経常利益":20500, "純利益":13500}  # 修正後通期予想
guide_ini = {"売上高":335000, "営業利益":18000, "経常利益":18000, "純利益":12000}  # 期初予想
q1        = {"売上高":83927,  "営業利益":5604,  "経常利益":6246,  "純利益":4353}   # Q1実績
for k in guide_rev:
    print(k, "Q1/修正後予想=%.2f%%" % (q1[k]/guide_rev[k]*100),
             "Q1/期初予想=%.2f%%" % (q1[k]/guide_ini[k]*100))
```

実行結果:
```
売上高 Q1/修正後予想=25.05% Q1/期初予想=25.05%
営業利益 Q1/修正後予想=28.74% Q1/期初予想=31.13%
経常利益 Q1/修正後予想=30.47% Q1/期初予想=34.70%
純利益 Q1/修正後予想=32.24% Q1/期初予想=36.28%
```

- Q1実績は期初予想に対しては明確に好進捗（各利益項目とも31〜36%の進捗率で線形按分25%を上回る）
  だが、**この期初予想は本日修正済みであり、判定対象とすべき「現在の会社予想」は修正後の値である**。
  修正後予想に対する進捗率（28.7〜32.2%）も線形按分をやや上回るが、**これは会社が本日、まさに
  このQ1実績を織り込んだ上で設定した予想に対する進捗率であり、「予想を上回るペースで進捗して
  いる」という新規の上振れ情報ではない**（設問の前提通り、今回の上方修正自体が会社予想であり、
  今回の修正がさらに上回っているわけではない）。
- さらに重要な点として、企業調査メモ2-4節・9節の通り、会社は同日公表のQ1決算短信補足資料で
  「稼ぐ力の強化の取り組みの成果が、２Ｑ以降に見込めるため、上方修正」と明記している。すなわち
  **上方修正の中核理由（稼ぐ力強化）はQ1時点で実現済みの効果ではなく、2Q以降に実現を見込んで
  先取りした計画的な修正**という性格が強く、その実現可否は未確定の将来情報である。
- Q1の増益の中身も、米州セグメント（+139.1%）に集中しており、うち為替影響（14円の円安）を
  含む一方、アジア（-8.8%）・欧州（-62.9%、フランス子会社売却の影響）はむしろ減益（企業調査
  メモ5-4節・9節）。全社一律の構造改善ではなく、地域・為替に偏った改善である。
- **結論**: **不成立**。「会社予想を上回る進捗」を積極的に主張する材料は、今回の上方修正それ
  自体との比較では成立せず、むしろ上方修正の実現根拠（稼ぐ力強化）自体がQ1時点で未実現・
  今後（2Q以降）の実現に依存する将来予測情報である点を、基準3の判定においては慎重に扱う
  必要がある。

## 2. 「開示は本日中でまだ十分織り込まれていないか」の正面からの検討（反応データの訂正を含む）

### 2-1. 発掘経路の前提（+2.48%「未反応」）と確定データ（+3.29%）の食い違い

本件がD-024の優先度キューに投入された直接の根拠は、日次ルーチンの場中反応突合が算出した
「9:00-15:30の株価変動+2.48%」が閾値±3%以内の「未反応」に該当したことである（企業調査メモ1節・
front-matter）。しかし、企業調査部が独自にkabutan.jpから再取得した確定終値ベースの前日比は
**+3.29%**（終値2,416円、前日2,339円比+77円）であり、みんかぶでも収束確認済みとされている
（企業調査メモ0節・4-1節）。この2つの数値は一致しない。

- **+3.29%は、D-024自体が定める「未反応」判定の閾値±3%を上回っている。** 日次ルーチン側の
  +2.48%がどの時点間の比較か（例えば場中の特定時刻同士の比較か、寄り付き基準か）は企業調査
  メモの範囲では特定できず「取得不能」（企業調査メモ1節）だが、少なくとも確定終値ベースの
  最終的な反応は「未反応」の基準を超えていた可能性が高い。
- さらに、本日の高値2,527円は開示時刻15:00の直後（15:04）に付けられており、寄付き2,298円比
  **+9.97%**（Python再計算、企業調査メモ1節）に達した後、終値にかけて2,416円まで押し戻されて
  いる。これは開示に対して**強い初期反応があった**ことを直接示す事実であり、「未反応」という
  当初の評価とは整合しない。

### 2-2. この訂正が投資判断に持つ含意

**率直な評価として、本件が優先度キューに投入された前提（「未反応」）自体が、後から見ると崩れて
いた可能性が高い。** これは以下の2点を意味する:

1. **基準1（カタリスト特定済み・未織り込み）の成立を積極的に主張する根拠が失われる。** 「未反応
   だからこそ市場が気づいていない」という発掘経路の暗黙の前提が、確定データでは支持されない
   （終値+3.29%は閾値超過、場中高値+9.97%は明確な反応）。
2. **開示直後の場中高値からの押し戻し（+9.97%→+3.29%）は「材料の一部が短期的に売られた」
   パターンとも解釈できる。** 会社の上方修正が「稼ぐ力強化の効果は2Q以降に見込める」という
   未実現の将来情報に依存していること（1章基準3参照）を踏まえると、市場が寄り付き直後の勢いを
   その後の取引時間で幾分か修正した（過度な期待を後退させた）可能性も排除できない。ただし
   この解釈も断定はできず、複数の解釈が併存しうる状況であることを明記する（第2条: 推測で
   一本化しない）。

いずれの解釈を採るにせよ、「開示はまだ十分に織り込まれていない」と積極的に主張できる根拠は
見出せない。**当初「未反応」と判定されて優先度キューに投入された経緯自体に疑義がある**ことは、
本メモの範囲を超える運用上の論点（日次ルーチンの反応突合ロジックの検証）として8章でリスク
管理部・記録部へ申し送る。
