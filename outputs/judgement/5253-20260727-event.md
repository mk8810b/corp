## 2. トリガー5253-T2成立の数値再検証（Python再計算、第2条準拠）

企業調査メモ（`outputs/research/5253-20260727-event.md` 1節）の数値を、投資判断部として
独自にPython再計算した。

```python
# 価格条件
base = 1350                      # 2026-07-24確定終値（基準価格）
today_close = 1650               # 2026-07-27確定終値
rally_pct = (today_close - base) / base * 100
# -> +22.2222%

import statistics as st
closes = [1218,1357,1371,1344,1458,1548,1616,1625,1618,1632,1612,1641,1694,1697,1677,
          1640,1633,1692,1545,1350,1650]   # 06/26〜07/27（21終値・20リターン、判定当日を含む窓）
rets = [(closes[i]/closes[i-1]-1)*100 for i in range(1,len(closes))]
sigma20 = st.stdev(rets)
# -> 7.1344%（corp/watchlist.md記載のσ20=7.134%と一致）
threshold_component = base * sigma20 / 100
threshold = base + max(base*0.02, threshold_component, 1)
# -> 1350 + max(27.0, 96.31, 1) = 1446.31 -> 呼び値1円切り上げで1,447円

# 出来高条件
vols20 = [1474200,2234400,1483900,880400,1463500,2033800,2174600,1556000,1793500,1762900,
          913300,1044300,1105000,888800,1091600,1180600,2019600,2059500,7130600,4733900]
avg_vol = sum(vols20) / len(vols20)
today_vol = 6_613_400
ratio = today_vol / avg_vol
# -> 平均1,951,220株、倍率3.3894倍

# 値幅制限（ストップ高）の確認
# JPX「値幅制限」表: 基準値段1,000円以上1,500円未満の制限値幅は300円
limit_up = base + 300
# -> 1,650円（本日高値・終値と完全一致 = ストップ高で寄り付き引け）

# 時価総額
shares = 65_650_100
mktcap = shares * today_close
# -> 108,322,665,000円 = 1,083.23億円（kabutan表示1,083億円と整合）
```

**実行結果**: 上抜け閾値**1,447円** ≤ 本日終値**1,650円**（価格条件成立）、出来高倍率
**3.389倍** ≥ 1.5倍（出来高条件成立）、値幅制限上限**1,650円**＝本日高値・終値と完全一致
（本日はストップ高で寄り付き、そのまま引けたことをPythonでも確認）。企業調査メモの数値・
`corp/watchlist.md`の記載値と完全に一致した。**トリガー成立自体に数値上の疑義はない。**
（校閲注記: 校閲者が上記コードを独立に再実行し、全出力値の一致を確認済み。校閲記録参照。）

なお、σ20（7.134%）は判定当日（07/27）自身のリターン（+22.22%）を20日窓に含めて算出された
値であり、07/24を窓の終端とした場合の別計算（標本標準偏差5.33%・母標準偏差5.20%）とは一致
しない（企業調査メモ1-3節）。日次ルーチンの実際の判定方式（判定当日を含む窓）に沿って
再計算した結果は記録値と一致しており、**計算方式そのものへの疑義はない**が、「トリガー成立を
判定するその日自身の急騰がσ20を押し上げ、結果的に自分自身の成立を判定しやすくする」という
自己参照的な性質がある点は、統制語彙の設計上の特性として申し送りに記録する（12章）。

## 3. D-012基準への当てはめ（BUY不採用の理由・07/25判定からの更新）

playbookの指示（本メモの起案依頼事項）に基づき、トリガーC（バリュエーション水準到達トリガー、
5253-T3）とは別に、トリガーB（本日成立の5253-T2）成立時点でも基準2の再判定を行う。

### 基準1: カタリスト特定済み → **不成立（07/25判定から変更なし）**

企業調査メモ2節の通り、本日の反発の手掛かりとして報道されているのは「hololive Dreams」の
App Store・Google Playセールスランキング1位という**報道ベースの情報**（会社発の適時開示では
ない、当社独自未検証）であり、D-012が要求する「市場にまだ十分織り込まれていない」という
条件には当てはまらない。むしろ本日の株価は**値幅制限の上限（ストップ高）まで買われており、
その日の取引時間内で表現しうる最大限の上昇をすでに記録した**（2章）。「まだ織り込まれていない
好材料」どころか、その日のうちに理論上可能な最大限の織り込みが行われた状態であり、基準1の
要件（未織り込み）とは正反対の状態にある。次回四半期決算（2026/08/12予定）は引き続き取得不能
（企業調査メモ4節、進捗データ未発表）であり、この基準は成立しない。

### 基準2: 同業比バリュエーション下位 → **不成立（07/25判定よりも一段と遠のいた）**

企業調査メモ3節の最新データ（07/27時点）を用いて再判定する。

- **カバーの指標は本日の株価上昇分だけ単純に切り上がった**: PER 17.6倍→**21.5倍**、
  PBR 4.31倍→**5.27倍**（EDINET1株純資産304.08円基準では4.44倍→**5.43倍**）。分母（会社
  予想EPS・純資産）に変化はなく（EDINET新規提出なし、企業調査メモ2-1節・4節）、株価の
  +22.22%上昇がそのまま倍率に反映された（Python検算: 17.6×1.2222=21.51倍、
  4.31×1.2222=5.268倍で実測値と整合）。
- **直接の同業ANYCOLOR比較は引き続き指標間で方向が逆の混在シグナルだが、PERの乖離幅は拡大**:
  PBRはカバー5.27倍＜ANYCOLOR5.86倍で引き続き下位（差0.59倍、07/24時点の差1.19倍〔4.31 vs
  5.50〕からむしろ縮小）だが、PERはカバー21.5倍＞ANYCOLOR12.1倍で上位（比率1.78倍、07/24
  時点の1.54倍〔17.6/11.4〕から**乖離が拡大**）。ANYCOLOR自身の指標も同期間でわずかに上昇
  （PER11.4→12.1倍、PBR5.50→5.86倍）しているが、カバーの上昇幅（+22.2%相当）には遠く及ばない。
  なおPBRの差が縮小（1.19倍→0.59倍）したこと自体は、カバーのPBRディスカウント（ANYCOLOR比の
  割安幅）が本日の上昇で目減りしたことを意味しており、PERの乖離拡大と同じ方向（＝「明確に
  割安」からより遠のく方向）の変化である。
- **広義の同業（コンテンツ・エンタメ）比較では、カバーのPBRが一段と突出**: エイベックス1.08倍・
  KADOKAWA2.10倍・東映アニメ3.43倍のいずれよりも高く、07/24時点（4.31倍で東映アニメ3.23倍を
  上回る程度）から**差が拡大**した（5.27倍と東映アニメ3.43倍の差は1.84倍で、07/24時点の
  1.08倍から拡大）。PERも88.8倍のKADOKAWAを除けば依然として上位グループにある。
- **結論**: 07/25判定時点で既に「明確に割安」の前段が成立していなかったが（07/25メモ2章）、
  本日の株価上昇により**割高方向の乖離はむしろ拡大した**。基準2は不成立であり、その不成立の
  程度は07/25判定時よりも強まっている。

**構造的要因の論点**: 07/25メモ校閲記録が整理した通り、タレント依存リスクはANYCOLORと共通の
リスクであるため両社間の指標差の説明には使えない、という論点は本日も変わらない。前段（明確に
割安）がさらに不成立の方向に動いた以上、後段（構造的欠陥の不在）の検討はやはり前提を欠く。

### 基準3: 業績進捗が会社予想を上回る → **不成立（検証不能、変更なし）**

企業調査メモ3-2節の通り、2027年3月期第1四半期決算は本日も未発表（次回発表予定2026/08/12、
変更なし）であり、会社予想（売上51,350百万円・純利益4,900百万円、変更なし）に対する進捗率は
引き続き**取得不能**。この基準は立証しようがなく不成立とする。

### 基準4: エッジ仮説との整合 → **不成立**

D-012のエッジ仮説は「アナリストカバレッジが薄い銘柄の適時開示・決算短信を当日中に読み込み、
まだ広く認知されていない具体的な事実を発見すること」を要求する。本日の材料はEDINET・法定開示を
一切伴わず（企業調査メモ2-1節）、逆に株探・みんかぶという広く読まれる媒体で当日中に速報された
情報（セールスランキング1位・買い予想数上昇）であり、**むしろ広く認知された結果としてストップ高
