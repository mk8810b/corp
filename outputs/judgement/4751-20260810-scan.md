```python
detect     = datetime(2026,8,10,7,51)
market_open= datetime(2026,8,10,9,0)
d1 = decision - disclosure
d2 = decision - detect
d3 = market_open - decision
print(d1.days*24 + d1.seconds//3600, (d1.seconds%3600)//60)  # 開示→判断確定

```

実行結果: **開示→判断確定 65時間15分（間に土日を挟む）**。**検知→判断確定 54分**。

### 基準3: 業績進捗が会社予想を上回る

**判定: 不成立（進捗率の高さは既に会社自身の同時上方修正に反映済みであり、「市場が未認識の

## 3. 基準1「未織り込み」の秤——支持材料と反証の対照（タスク指示の必須事項）

### 3-1. 事実の整理

| 指標 | 値 | 出典 |
|---|---|---|
| 本則市場の取引状況 | 開示後一度も取引成立せず | 1節 |

### 3-2. 解釈（両論）

- **「本則市場はまだ未反応」説（未織り込みを支持）**: 開示が大引けと同時刻であるため、
  本則市場での再評価はまだこれから始まる段階である。PTSは出来高56,000株（本則市場の約1%）
  に過ぎず、参考値の域を出ない。
- **「市場は既に慎重に評価し始めている」説（未織り込みを否定、本メモが重視）**: PTSは
  板が薄いとはいえ開示後最初に観測できた市場参加者の反応であり、それが**-5.20%という
  明確なマイナス**であることは、「市場がまだ気づいていない」のではなく「気づいた上で
  Q4含意額の弱さ等を織り込んで慎重に評価している」ことを示唆しうる。加えて、開示前6週間で
  既に+13.12%上昇していたという事実は、好材料の一部（少なくとも業績改善の観測）が
  **開示前から既に部分的に価格へ反映されていた可能性**を示す。この上昇の要因は本メモの
  調査範囲では特定できず「取得不能」だが、「事前に何も織り込まれていなかった」という
  前提には立てない。
- **本メモの立場**: 3964先例はPTSが**プラス**であり「未織り込みではなく気づいた上で好感
  している」という反証だった。**本件はPTSが明確にマイナスであり、「未織り込みで上振れ
  余地がある」という仮説を積極的に支持する材料にはならないだけでなく、むしろ「上方修正の
  質そのものに市場が疑義を持っている」可能性を示唆する、3964よりも重い反証である**。
  「立証できない」という消極的な結論をもってBUYを否定するには十分である（この論理は
  BUYを否定する方向にのみ用い、WATCH自体の積極的な根拠には用いていない）。
- **本件が3964先例と異なる点**: 3964はPTSが+18.11%と強く好感的で「割安な入り口が失われる
  リスク」が上振れ抑制要因だったのに対し、本件はPTSが-5.20%と弱含みで「本則市場の寄り付きが
  PTSの弱さを追認するリスク」が下振れ要因になりうる。両者は同じ「本則市場未反応」という
  構造でありながら、PTSが示す方向は正反対であり、**先例をそのまま適用せず本件固有の事実
  として評価する**（先例準拠の形式主義に陥らないための明記）。

## 4. σ20・出来高のPython再計算（D-018トリガー設計の前提）

タスク指示の機械計算済み入力値（出典: kabutan日足 `https://kabutan.jp/stock/kabuka?code=4751&ashi=day&page=1`、`corp/tools/tdnet_scan.py` の `_parse_kabuka_history()` で解析、
2026-08-10T00:0xZ取得）を、D-018の統制語彙（`max(2%, σ20, 呼び値1ティック)` を呼び値へ
切り上げ）に従い自社Pythonで検算・補正する。

```python
import math
ceil_tick = lambda x,t=1: math.ceil(round(x/t,9))*t

close = 1499.0
sigma20_excl = 0.024107   # 基準日を除く（タスク指示の主値）
sigma20_incl = 0.023857   # 基準日を含む（タスク指示の参考値）
pct2 = 0.02

# D-018の規約（3964・3182等の先例が実装した方法）: max()の生値をとった後に呼び値へ切り上げる
gate_excl_raw = max(close*pct2, close*sigma20_excl, 1)
gate_incl_raw = max(close*pct2, close*sigma20_incl, 1)
gate_excl = ceil_tick(gate_excl_raw)
gate_incl = ceil_tick(gate_incl_raw)
print(round(close*pct2,2), round(close*sigma20_excl,4), round(close*sigma20_incl,4))
print(gate_excl, close+gate_excl, close-gate_excl)
print(gate_incl, close+gate_incl, close-gate_incl)

vol20_incl = 3948370
vol20_excl = 3869365
print(vol20_incl*1.5, math.ceil(vol20_excl*1.5))
```

実行結果:

| 成分 | 値（円） |
|---|---|
| 2%成分 | 29.98 |
| σ20換算（基準日を除く、タスク指示の主値） | 36.14 |

### 1. D-010容量チェック（最優先の申し送り）

**本メモの起案者自身が`corp/watchlist.md`をPythonで機械集計した**（`ACTIVE` の判定は各行の

```python
lines = open('corp/watchlist.md', encoding='utf-8').read().splitlines()
active_codes = []
for l in lines:
    if l.startswith('| ') and l.count('|') >= 7:
        parts = [p.strip() for p in l.split('|')]
        code = parts[1]
        if code in ('コード', '') or set(code) <= set('-'):

print(len(active_codes))
```
