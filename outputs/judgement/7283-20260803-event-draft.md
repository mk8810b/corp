### 1-2. 7283-T2 閾値2,327円の再現（σ20の独立再算出）

台帳（`corp/watchlist.md` 7283-T2）の閾値2,327円を、投資判断部として**新規に取得した日足系列**
から独立に再現した。入力は kabutan.jp の日足時系列（`kabuka?code=7283&ashi=day&page=1〜3`、
curl・UA指定、2026-08-03T07:36〜07:37Z取得。26/03/24〜26/08/03の90営業日）である。

```python
import json, statistics, math
def ceil_tick(x, t=1): return math.ceil(round(x / t, 9)) * t

ser = sorted(json.load(open('7283_series.json')).items())   # (日付, (終値, 出来高)) の90行
dates  = [d for d, _ in ser]
closes = [v[0] for _, v in ser]

# σ20の窓 = 直近20営業日の日次終値変動率（判定日の前営業日=2026-07-31で終わるローリング窓）
j = dates.index('26/07/31')
rets = [(closes[k]/closes[k-1]-1)*100 for k in range(j-19, j+1)]
sigma_pop  = statistics.pstdev(rets)     # 母標準偏差 (n=20)
sigma_samp = statistics.stdev(rets)      # 標本標準偏差 (n-1=19)

base = 2416.0                            # 7283-T2の基準値＝2026-07-30確定終値（既存メモ6節）
two    = base * 0.02
sigma  = base * sigma_samp / 100
gate   = max(two, sigma, 1)              # D-018: max(2%, σ20, 呼び値1ティック)
thresh = base - ceil_tick(gate)
```

**実行結果**:
```
σ20（標本標準偏差、n-1=19、採用値） = 3.649365%   → σ成分 = 2,416円 × 3.649365% = 88.1686円
σ20（母標準偏差、n=20、参考値）     = 3.556961%   → σ成分 = 85.9362円
2%成分 = 2,416円 × 0.02 = 48.32円
→ max()判定: σ成分88.1686円 > 2%成分48.32円 > 1円 なので【σ20が拘束的】
ゲート = 88.1686 → 呼び値1円で切り上げ 89円
下抜け閾値 = 2,416 - 89 = 2,327円   ← 台帳記載値と完全一致
本日終値 2,310円 ≦ 2,327円 → 【成立】  余裕 = (2,310-2,327)/2,327 = -0.7306%
基準終値(2,416円)比 = -4.3874%   前営業日(2,404円)比 = -3.9101%
20日平均出来高（〜07/31のローリング窓）= 379,255.0株
本日出来高 359,600株 ÷ 379,255株 = 0.9482倍（20日平均を下回る）
```
