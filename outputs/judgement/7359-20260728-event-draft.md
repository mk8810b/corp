### 0-4. トリガー7359-T4の成否判定への影響（Python再計算、σ20の独立検算を含む）

σ20（直近20営業日の日次終値変動率の標準偏差）を、kabutan.jp確定終値ページの07/28時点の
過去データ（06/16〜07/27、取得日時2026-07-28、上記と同一取得）から独立に再計算した。

```python
import statistics as st, math

closes = [217,234,222,223,220,213,215,212,214,212,214,212,225,222,218,
          219,221,220,222,224,227,229,228,236,225,220,226,223,225]
# 06/16 ... 07/27（07/28は含めず、07/27終値225円までの20日窓で判定日07/28時点のσ20とする）

rets = [(closes[i]-closes[i-1])/closes[i-1]*100 for i in range(1, len(closes))]
sigma20_all = rets[-20:]
sigma_pop = st.pstdev(sigma20_all)
sigma_sample = st.stdev(sigma20_all)
# = 2.2178%（母標準偏差）/ 2.2754%（標本標準偏差）

base = 228  # 07/16終値（開示前水準）
two_pct = base * 0.02                      # = 4.56円
sigma_amt = base * sigma_pop / 100         # = 5.0566円
gate = max(two_pct, sigma_amt, 1)          # = 5.0566円（σ20が拘束的）
threshold = base - math.ceil(gate)         # = 228 - 6 = 222円
```

**独立再計算結果**: σ20（母標準偏差）=2.2178%、σ20（標本標準偏差）=2.2754%。
`corp/watchlist.md` 記載の2.307%と完全一致はしないが（データ取得の再取得タイミング差・

拘束的である点も一致）。

**結論（重要）**: 本メモが独立に再取得・確認した最新値（223円、5回一致・2ソース一致）を
