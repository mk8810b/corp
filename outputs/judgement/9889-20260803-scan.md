### 基準3: 業績進捗が会社予想を上回る

**判定: 不成立（厳密判定）。**

本基準は「直近の決算・開示が**会社側の計画を上回るペース**で進捗しており、かつ市場の反応が

|---|---|---|---|---|

| 営業利益 | 2,156 | 8,745 | **24.65%** | **-0.35pt** |
| 経常利益 | 2,201 | 8,845 | **24.88%** | **-0.12pt** |

  「計画どおり達成できる確度が上がった」**という趣旨である（原文と字句一致を研究メモが確認）。
- 【本基準を成立とみなしうる反対解釈と、それを採らない理由】: 純利益の進捗22.85%は
  SOLNET本社移転に伴う土地減損のスケジューリング不能による税効果要因であり、前年同期並みの

### 6-5. D-019 プロベーション適用比率（**本節が本銘柄の最重要の制約**）

主検定（D-021、BUY限定SPRT）は本メモ校閲時点で**n=0・未結論**であり、D-019のプロベーション期
サイジングが有効である。D-019は確信度によらず**現在資金残高の2%**を投入目標とし、
1単元が2%を超える場合は**3%まで切り上げ可**、**1単元が3%を超える銘柄は「実弾見送り
（シャドー追跡のみ）」**と定める。

```python
cash = 3_000_000
target_2pct = cash * 0.02   # =  60,000円（投入目標）
cap_3pct    = cash * 0.03   # =  90,000円（切り上げ上限）
unit        = 1616 * 100    # = 161,600円
unit > cap_3pct             # => True
cap_3pct / 100              # => 900.0円（実弾見送りが解消する株価上限）
```

| 項目 | 値 | 判定 |
|---|---|---|
| プロベーション投入目標（2%） | 60,000円 | 1単元161,600円 = **目標の2.69倍**、超過 |
| プロベーション切り上げ上限（3%） | 90,000円 | 1単元161,600円 = **上限の1.796倍**、**超過** |
| **D-019による帰結** | — | **「実弾見送り（シャドー追跡のみ）」** |

- **したがって本銘柄は、仮にBUY判定であったとしてもリスク管理部でREJECTされ、実弾投入は
  できない**（`playbooks/judgement.md`: 「1単元が3%を超える銘柄は『実弾見送り（シャドー追跡のみ）』
  と明記する（この場合リスク管理部でREJECTされる）」）。
- **実弾見送りが解消する条件**: 株価が**900円以下**（＝1単元90,000円以下）へ低下するか、
  資金残高が**5,386,667円以上**（＝161,600 ÷ 0.03）へ増加するか、あるいはプロベーション期が
  終了（D-019卒業の決定ID発行）してD-011比率（高10%＝300,000円）が適用されるかのいずれか。
  現行株価1,616円から900円は**-44.3%**であり、実務的にはプロベーション卒業または資金増加が
  現実的な解消経路である。
- **【重要】D-019「実弾見送り」とD-013「構造的除外」の混同を避ける**（先例
  `outputs/judgement/3696-20260730-scan.md`校閲メモE-11と同型の注意）: 9889は
  (i) 株価1,616円がD-013の株価上限3,000円**以内**、(ii) 1単元161,600円がD-002の1銘柄上限10%
  ＝300,000円**以内**であり、**5803・9984・285A型の構造的除外（`corp/watchlist.md`のCLOSED化）には
  該当しない**。制約はプロベーション期D-019の3%＝90,000円上限のみであり、WATCH台帳への
  登録・監視継続は通常どおり行う。
