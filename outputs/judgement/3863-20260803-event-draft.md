## 2. 【本メモの中核その1】σ20解釈の裁定 — 3863-T4 は不成立

### 2-1. 裁定（結論）

**3863-T4 の閾値を 1,348円 → 1,339円 に是正し、これを条文として確定する。本日の確定終値
1,345円は 1,339円を上回るため、3863-T4 は「不成立」と裁定する。**
台帳の 3863-T4 は `TRIGGERED` から **`OPEN` に戻し**、閾値を改訂する
（`corp/watchlist.md` 冒頭「本台帳と判断メモに食い違いがある場合は判断メモを正とし、本台帳を
修正する」に基づく）。

適用した一般則は、同日の 4549 メモ（JDG-S39）1章と**同一**である。再掲する。

> **【裁定A: 固定値主義】** トリガーの価格閾値は、当該トリガーを設定した判断メモの基準日時点で
> 算出した値に固定する。日次ルーチンは判定日ごとに閾値を再計算しない（ローリング再算出を行わない）。
>
> **【裁定B: 留保付き条文の一度限りの是正】** 条文自身が入力値の欠落・暫定を明記している場合に
> 限り、当該入力が取得可能になった最初の判定日に**一度だけ**条文を改訂して固定し直す。改訂は
> **その条文の基準日時点の窓**で行い、判定日時点の窓では行わない。改訂後は裁定Aに戻る。
>
> **【裁定C: 窓規約が未確定の間の暫定則】** 窓（基準日を含むか）・母/標本が未確定である間は、
> 採りうる系列すべてを算出し、ゲートが最大となる**保守側**を採用する。

### 2-2. なぜ 4549 は固定値（成立）で、3863 は是正（不成立）なのか

**両件を分けたのは「どちらの結論が望ましいか」ではなく、条文が自らの入力の欠落を明記して
いるか否かという、事前に検証可能な形式要件である。**

| | 4549-T2 | 3863-T4 |
|---|---|---|
| 条文のσ20の扱い | **算出済み**。「σ20（母1.5964%／標本1.6378%）はいずれも2%成分43.02円を下回り非拘束」と明記 | **未算出**。基準を共有する3863-T3が「σ20〔**本メモ時点で取得不能につき暫定不使用**〕」と明記 |
| 条文の固定宣言 | 「以下の閾値は本メモ確定時点で固定し、**以後の日次ルーチンで再計算しない**」と明記 | 固定宣言なし。代わりに「暫定」という留保あり |
| D-018の式の適用状況 | max(2%, σ20, 1ティック) を**完全に適用済み** | σ20項を**欠いたまま**適用（1章の実測により、σ20は当時すでに拘束的だったことが確認できる） |
| 裁定 | 裁定A → 固定値2,107円で判定 → **成立** | 裁定B → 一度限りの是正で1,339円に確定 → **不成立** |

3863-T4 の条文（「T3と同基準」）が参照する 3863-T3 の**「暫定不使用」という文言は、
「σ20が取得できたら使う」ことを条文自身が予定していたと読むのが自然**である。「暫定」は
恒久的な不使用を意味しない。したがって、σ20が取得可能になった最初の判定日（＝本日）に
条文を是正するのは、条文の意図の実現であって、条文の書き換えではない。

さらに補強すべき事実として、**この「取得不能」は実際には取得不能ではなかった**。
08/01確定メモ1-1章は σ20・20日平均出来高を「取得不能（企業調査メモに時系列データの記載なし）」と
記録しているが、本日 kabutan.jp の日足時系列ページから当時分を含めて問題なく取得できている
（1-1章）。すなわち「上流の企業調査メモに載っていなかった」という**工程内の欠落**が
「取得不能」と記録され、それがトリガー閾値の誤設定に直結した。この経路そのものを10章で申し送る。

### 2-3. 是正値の決め方（裁定B・裁定Cの適用手順）

1. **是正の基準日は、条文の基準日 2026-07-31**（本日08/03ではない）。条文が固定しようとした
   時点の値を復元するのが目的であり、判定日時点の窓を使えばそれは裁定A（固定値主義）に
   反するローリング再算出になる。
2. 基準日07/31時点で採りうる系列は 窓A（07/02〜07/30）・窓B（07/03〜07/31）× 母/標本の4系列。
   ゲートは 32 / 33 / 36 / **37**円。
3. 裁定Cにより**ゲート最大の保守側 37円**（窓B・標本 σ20=2.629105%、σ20成分36.1765円）を採用。
   下抜け閾値 = 1,376 − 37 = **1,339円**、上抜け閾値 = 1,376 + 37 = **1,413円**。
4. 保守側を採ることの意味: 下抜け条件では閾値が**下がる**ため、格下げ（PASS検討）が起きにくく
   なる。上抜け条件では閾値が**上がる**ため、BUY再検討が起きにくくなる。**どちらの向きでも
   誤発火を抑える側**に働くため、結論に都合よく選んだ選択ではない。
5. **是正は一度限り**。以後 3863-T3/T4 は 1,413円 / 1,339円 の固定値で運用し、日次ルーチンは
   再算出しない。

### 2-4. 本裁定が「不成立」に倒れることのリスク管理上の扱い

本裁定により、日次ルーチンが保守側で「成立」と判定したものを投資判断部が「不成立」に覆す形に
なる。この向きの覆しは**取りこぼし（下振れの見逃し）リスク**を生むため、以下で担保する。

- **本メモは 3863-T4 が不成立であることを理由に検討を打ち切っていない**。むしろ論点2（熊本地震）に
  より、独立の根拠でイベント駆動の再評価を当日中に完結させている（4章以降）。
- **2営業日後（2026-08-05）に 3863-T1／3863-T5（既定PASS引き金）の判定期日が到来する**。
  下振れの最終確認はそこで確実に行われる（6章）。
- 是正後の閾値1,339円は本日終値からわずか **-0.4459%** 下であり、実質的な監視の緩みは生じない。
