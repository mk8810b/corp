## 1. 判定

「材料が見つからないから危険」という消極的判断ではなく、D-012の4つの積極的採用理由（カタリスト
特定済み／同業比バリュエーション下位／業績進捗が会社予想を上回る／エッジ仮説との整合）を

上で、WATCH継続に見合う上振れ余地の根拠も具体的に組み立てられないためPASSとする（理由は下記

   できない。さらに、その割安さ（仮に成立するとしても）を正当化しうる構造的な欠陥（3期連続
   営業・経常・純損失、直近四半期の赤字拡大、剰余金の継続的な悪化）が現に存在するため、
   D-012基準2の「かつその割安さを正当化する構造的な欠陥が見当たらない」という条件も満たさない。

3. **業績進捗が会社予想を上回る: 不成立（むしろ逆行）。**
   会社側の2026年12月期通期予想は売上高858百万円（前期比▲12.4%、Python再計算では▲12.45%〔下記
   4節〕）・各利益「赤字縮小」方向だが、直近開示済みの2026年1-3月期（1Q）実績は売上高133百万円
   （前年同期比▲68.0%、Python再計算▲67.95%）・営業損益△143百万円/経常損益△140百万円/最終損益
   △144百万円と、いずれも**赤字拡大**で着地している（企業調査メモ5-2節）。会社予想の「赤字縮小」
   という方向性と直近四半期実績の「赤字拡大」というトレンドは逆行しており、業績進捗が会社予想を
   上回っているとは到底言えない。次回の2Q決算（2026/08/14予定）は本メモ時点で未発表であり、
   現時点の直近開示ベースでは基準を満たせない。

4. **エッジ仮説との整合: 不成立。**
   D-012のエッジ仮説は「アナリストカバレッジが薄い銘柄の適時開示・決算短信を当日中に読み込み、
   まだ広く認知されていない具体的事実を発見できたか」を要求するが、企業調査メモが確認した通り
   直近の適時開示・決算短信自体が約2ヶ月以上前（2026-05-15の1Q決算短信）であり、07-24当日に

**結論**: D-012の4基準のいずれも企業調査メモの事実に基づいて積極的に満たすことができない。
「却下理由が一つもない」わけではなく、むしろ2〜4の基準はいずれも構造的な欠陥（赤字拡大・
会社予想逆行・バリュエーション中位）と正面から抵触しており、BUY不採用の結論は消極的判定
ではなく積極的な根拠に基づく。

## 3. WATCH不採用（PASSとする理由）

precedent（`outputs/judgement/5240-20260711.md`、8918との比較を参照）は、WATCH化するには
「監視継続のコストに見合う上振れ根拠」が必要であるとした。本銘柄について以下を検討した結果、
その根拠を具体的に組み立てられないため、前回同様WATCHではなくPASSとする。

1. **材料不明の急騰が2週間で2回目という反復性**: 07-10ストップ高（180円）→07-17信用規制発表・
   大幅続落→07-23まで調整（163円）→07-24再ストップ高（213円、07-10高値を上回る新高値）という
   値動きは、単発の思惑買いというより、材料の裏付けなしに投機資金が反復的に出入りしている
   パターンを示唆する（企業調査メモ4-4節）。信用規制という需給面の抑制策が発動された直後に
   再び同規模の急騰が起きたことは、実需に基づく評価訂正というより値動き自体を追う投機的な
   物色が続いている可能性を積極的に示す事実であり、上振れ根拠としては採用しにくい。
2. **財務トレンドの継続的悪化**: 剰余金は2025年12月期末△336百万円→2026年3月末△480百万円へ
   さらに悪化（Python再計算で悪化額144百万円、1Q純損失とほぼ整合、下記4節）。3期連続赤字に
   加えて直近四半期も赤字拡大しており、前回PASS判定時からファンダメンタルズ面の好転は
   確認できていない。
3. **D-015テール脆弱性フラグ(a)が継続して該当**（下記5節）。フラグ該当自体はWATCH不採用の
   直接理由ではないが、仮にBUYを将来検討する場合でも確信度「高」は提案できない構造的制約が
   維持されていることを付記する。
4. **precedent（8918、WATCH）との対比**: 8918がWATCHとされた決め手は、カタリスト不明という点は
   共通しつつも、会社側の増収増益予想という前向きな材料が残っていたことだった
   （`outputs/judgement/5240-20260711.md`6節参照）。本銘柄も会社側は「赤字縮小」という前向きな
   方向性を予想してはいるが、直近四半期実績が既にその予想と逆行（赤字拡大）しており、
   予想の説得力自体が実績によって裏切られている点で8918とは状況が異なる。
5. **同業比較材料も上振れ根拠にならない**: 本節2で確認した通りPBRは中位水準であり、「バリュ
   エーションの歪みが是正される」形の上振れシナリオも具体的な数値根拠をもって描けない。

以上より、上振れ余地スコアを定性的に見ても「監視を継続する積極的な理由」を企業調査メモの事実
から具体的に示すことができないため、WATCHではなくPASSとする。次回2Q決算（2026/08/14予定）で
赤字拡大トレンドに反転が見られる、または急騰要因が事後的に判明する等の状況変化があれば、
企業調査部による再調査を経て改めて判断する（`corp/watchlist.md`への正式登録は行わないため、
本節の記載はWATCH台帳への転記対象外の参考情報である）。

## 6. 数値の再計算（Python、第2条）

企業調査メモに記載された比率のうち、本判断根拠で引用した数値をPythonで独立に再計算し、転記
ミスがないことを確認した。

```python
# 1. 2026-07-24 ストップ高の変化率
prev_close = 163
stop_high = 213
pct_change = (stop_high - prev_close) / prev_close * 100  # -> 30.6748...

# 2. PTSの東証終値比（07/25 01:58時点）
pts = 218
pct_pts = (pts - stop_high) / stop_high * 100  # -> 2.3474...

# 3. 2026年1-3月期(1Q)売上高の前年同期比
q1_2026 = 133   # 百万円
q1_2025 = 415   # 百万円（前年同期実績）
yoy = (q1_2026 - q1_2025) / q1_2025 * 100  # -> -67.9518...（≒-68.0%）

# 4. 通期会社予想売上高の前期比（企業調査メモ記載の百万円単位丸め値ベース）
fy_forecast = 858     # 百万円
prior_actual = 980    # 百万円（第13期実績、百万円単位丸め）
fy_pct = (fy_forecast - prior_actual) / prior_actual * 100  # -> -12.4490...（≒-12.4%）

# 5. 剰余金の悪化額（2025年12月期末→2026年3月末）
deficit_2025 = -336   # 百万円
deficit_2026q1 = -480 # 百万円
deficit_change = deficit_2026q1 - deficit_2025  # -> -144（1Q純損失144百万円とほぼ整合）

# 6. PBR順位（比較対象4社中、昇順＝割安順）

    "3698 CRIミドルウェア": 1.48,
    "6182 メタリアル": 2.41,
    "5240 monoAI(本銘柄)": 2.42,
    "3976 シャノン": 2.88,

ranked = sorted(pbr.items(), key=lambda x: x[1])  # 5240は4社中3番目（中位）

# 7. 07-24高値213円の07-10ストップ高値180円対比
```

- PTS東証終値比 +2.3474%（企業調査メモ記載の+2.35%と一致）

- 通期予想売上高前期比 ▲12.4490%（企業調査メモの丸め表記▲12.4%と一致。百万円単位丸め値
  980を分母に使用。前回07-11メモは千円単位原本値980,881を分母に使い▲12.53%だったが、丸め方法の
  違いであり実質的な差異ではない）
- 剰余金の悪化額 ▲144百万円（企業調査メモ6節の「1Qの純損失144百万円計上が主因と推定」という

  「3社中では中位」という記載と整合

投入額の円換算は本稿では発生しない（PASSのため新規投入を提案しないため、現在資金残高
