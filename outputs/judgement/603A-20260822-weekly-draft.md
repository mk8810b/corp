   **「アナリスト：対象外」**という表示を企業調査メモが機械確認済み（HTTP 200、取得
   2026-08-22T00:41:10Z）。アナリスト専用ページはHTTP 404で存在しない。これは「取得不能」
   ではなく、**minkabu自身が『対象外』（データなし）と判定している肯定的証拠**である
   （先例JDG-O65が7593で確立した扱いと同型）。IFIS株予報は技術的制約（JS必須SPA）で
   取得不能。**2026年7月29日上場・基準日時点で上場17営業日という新規性の高さも、
   カバレッジが実際に未形成であることと整合する客観的背景事実である。**
2. **「適時開示・決算短信を当日中に読み込み」（成立）**: 企業調査メモは基準日引け後
   （17:00・19:00）に公表された第三者割当増資・決算説明会FAQの2件の開示本体をTDnet原本から
   直接取得・読解し（`pdftotext -layout`）、翌朝（08-22 00:30〜00:46 UTC＝09:30〜09:46 JST）
   までに本メモの一次資料として確定させている。EDINETの大量保有報告書（提出日08-18、公表を
   基準日に検知）も原本を取得・読解した。暦日基準では開示日と読解完了日にまたがりはあるが、
   休場を挟まない翌朝の作業であり、実質面（市場に先んじて読む）は支持できる。
3. **「まだ広く認知されていない具体的な事実の発見」（成立）**: 研究メモが発見した
   (i) 第三者割当増資が新株予約権（ワラント）ではなく普通株式の直接発行であり行使価額修正
   条項が存在しないこと（原本の「行使価額」「修正条項」検索で0件ヒットを確認）、
   (ii) 決算説明会FAQのQ6「オンサイトソーラー契約済容量239MW・468件」が決算短信本文の
   「421MW・1,549施設（稼働ベース）」とは異なる集計範囲の指標であること（両者を同一視する
   誤読リスクを明示的に排除）、(iii) TLC VPP合同会社への依存度が13.7%→16.5%→21.6%へ
   急拡大していること、はいずれも開示原本の精読による独自の発見であり、見出しの読解だけでは
   得られない。

**結論: 3要素すべて成立。D-012の必要条件（最低1つ以上の積極的採用理由）を満たす。**

## 2.【最重要】+11.59%の上昇が出来高0.97倍（平均並み）で起きたことの評価、および上場17営業日という制約

### 2-1. D-018「出来高を伴う」への該当性

avg_vol_incl, avg_vol_excl = 990256.2, 991813.0

値幅の上昇（σ20の約2.06倍、企業調査メモ8-4節）が、出来高の裏付けを伴わずに生じている。

### 2-3.【最重要・必ず明記】上場17営業日という技術的制約——「20日平均」自体が真の20日平均ではない

企業調査メモ8-1節が確認したとおり、603Aは2026-07-29上場で基準日（08-21）は**上場後17営業日目**
であり、過去に遡れる取引履歴は17営業日分のみである。`corp/tools/tdnet_scan.py`の
`_parse_kabuka_history()`は上場初日（前日比欄が「－」）を自動除外するため、**「20日平均」と
称する数値は実際には16営業日（基準日を含む）または15営業日（除く）分のみの平均である。**

```python
from datetime import date, timedelta
d = date(2026,8,21)
cur, added, count = d, [], 0
while count < 4:
    cur = cur + timedelta(days=1)
    if cur.weekday() < 5:
        count += 1
        added.append(cur)
print(added)
```

実行結果: **2026-08-24・25・26・27**（土日のみを除いた単純カウント。日本の祝日カレンダーは
本メモでは参照していないため祝日を挟めばさらに後ろ倒しになりうる点に留意——「取得不能」では
なく「未検証」と明記する）。すなわち、あと4営業日（08-27頃、祝日次第でさらに後ろ倒しの
可能性あり）を経なければ、上場初日を除く真の20営業日窓は成立しない。**本メモが用いるσ20・
20日平均出来高・D-018トリガー閾値は、この技術的制約のもとで算出された暫定値であり、
真の20営業日窓が成立するまでは統計的信頼性が本来の設計（D-018検証メモが前提とした150営業日
規模の実測）より低いことを明記する。**

さらに、企業調査メモ8-2節が示すとおり、**出来高の水準そのものが上場直後から構造的に減衰する
局面にある**（上場3営業日で158万〜1,231万株という極めて高い水準から、直近5営業日は41万〜
107万株のレンジへ収斂）。「20日平均」の母集団に上場直後の突出した出来高が混入している場合、
平均自体が上振れて算出され、結果として「倍率」が過小評価される可能性がある。逆に、この
突出分が既に窓から外れている場合（本件は上場初日が`_parse_kabuka_history()`により機械的に
除外されているため、実質的にこの懸念は一定程度緩和されている）は、平均が実勢に近づく。
**いずれの方向にも作用しうる不確実性であり、断定はしない**が、D-018のトリガー設計（D-018検証
メモが前提とした「平常運転の銘柄における150営業日規模の安定した窓」）が、この銘柄には
本来の設計どおりには当てはまらないという限界を、10節のトリガー条文に明記する。

## 3. 財務の脆弱性——自己資本比率19.3%とPPA型成長投資の構造

**D-015の恒久的却下事実（4項目）にはいずれも該当しない**（5節で再確認）。しかし、D-015の

  ものではない（既存株主から借り入れた株式の返却が目的であり、新規の資本増強ではない）。
- **総括**: **成長投資が先行する薄い自己資本という構造は、この銘柄の事業モデル（PPA型
