### 2-2. なぜ 4549 は固定値（成立）で、3863 は是正（不成立）なのか

**両件を分けたのは「どちらの結論が望ましいか」ではなく、条文が自らの入力の欠落を明記して
いるか否かという、事前に検証可能な形式要件である。**

| | 4549-T2 | 3863-T4 |
|---|---|---|
| 条文のσ20の扱い | **算出済み**。「σ20（母1.5964%／標本1.6378%）はいずれも2%成分43.02円を下回り非拘束」と明記 | **未算出**。基準を共有する3863-T3が「σ20〔**本メモ時点で取得不能につき暫定不使用**〕」と明記 |
| 条文の固定宣言 | 「以下の閾値は本メモ確定時点で固定し、**以後の日次ルーチンで再計算しない**」と明記 | 固定宣言なし。代わりに「暫定」という留保あり |

**(a) 文言解釈: 「暫定不使用」は「取得可能になったら使う」を含意するか — 含意する。**

1. **D-018 は σ20 を必須入力として定めている**。判定幅は `max(対象価格の2%, σ20, 呼び値1ティック)`
   であり、σ20 は選択項ではない。「暫定不使用」は**代替ルールの採用ではなく、定められた式の
   不完全適用の自認**である。「暫定」という語は、恒久的な不使用と両立しない。
2. **同じメモの同じ段落構造が、欠落した入力の後日補完を明示的に設計している（校閲が追加した
   決定的根拠）**。3863-T3 の条文は出来高側について、
   > 「なお**直近20営業日平均出来高は本メモ時点で未取得（取得不能）**であり、実際の倍率判定は
   > 日次イベント検知ルーチン（D-006）が**判定日時点の20営業日窓から算出する**」
   と書いている。すなわち**当該条文自身が「本メモ時点で取得できなかった入力は、後に取得可能に
   なった側が補って初めて条文が完成する」という設計を、条文内に明示している**。σ20 の
   「暫定不使用」を、同一条文中の出来高の扱いと切り離して「恒久的不使用」と読むのは、
   条文の内部整合を破壊する解釈である。したがって「取得可能になった時点で補う」と読むのが
   条文の自然な解釈であり、裁定Bの文言解釈上の根拠はこれで足りる。
3. **憲法第2条との整合**。第2条は「データが取得できなかった場合は『取得不能』と明記し、推測で
   埋めない」と定めるが、**取得可能になった後も実測値ではなく欠落を維持せよ、とは定めていない**。
   むしろ実測値が得られた時点でそれを使うことが第2条（数値実在原則）の趣旨に適う。
4. **さらに補強すべき事実として、この「取得不能」は実際には取得不能ではなかった**。
   08/01確定メモ1-1章は σ20・20日平均出来高を「取得不能（企業調査メモに時系列データの記載なし）」と
   記録しているが、本日 kabutan.jp の日足時系列ページから**当時分を含む92営業日分
   （2026-03-24〜08-03）が問題なく取得できる**ことを起案・校閲の双方で実測した。すなわち
   「上流の企業調査メモに載っていなかった」という**工程内の欠落**が「取得不能」と記録され、
   それがトリガー閾値の誤設定に直結した。**事実に反する取得不能宣言に由来する閾値の訂正は、
   条文の書き換えではなく誤りの是正である。** この経路そのものを10章2で申し送り、
   インシデント（INC-004）として記録する。

**(b) 「結論先にありき」の使い分けではないことの検証（校閲が追加）**

裁定Bは「発火したトリガーを当日に不発化する」装置になりうるため、濫用の疑いを晴らす必要がある。
以下3点で検証した。

1. **形式要件は価格を知る前にテキストのみで判定可能**。「条文本文に入力の欠落・暫定の明記が
   あるか」は、当日の終値を見なくても、台帳と参照元メモを読むだけで一意に決まる。4549-T2 は
   σ20 を算出済みかつ「以後再計算しない」と固定を宣言し、3863-T3 は「暫定不使用」と留保を
   自認している。**テキストの差は実在し、事後的に作られたものではない。**
2. **方向テスト（裁定Bは常に「不成立」に倒れる装置か）— 否**。σ20 が拘束的なとき、裁定Bは
   上抜け条件では閾値を**上げ**（BUY再検討を起きにくくし）、下抜け条件では閾値を**下げる**
   （格下げを起きにくくする）。すなわち双方向でトリガーを鳴りにくくするが、これは
   D-018 が σ20 を**ノイズ下限ガード**として導入した設計意図そのものであって、起案者の恣意では
   ない。加えて本件で仮に本日終値が 1,335円 であったなら、是正後の 1,339円 でも**成立**する。
   裁定Bは結論を一方向に固定する装置ではない。
3. **頑健性テスト（本件の結論は裁定Cに依存するか）— 依存しない。これが決定的である**。
   基準日07/31時点で採りうる4系列すべて（窓A/B × 母/標本）で下抜け閾値は 1,339〜1,344円であり、
   **そのすべてが本日終値1,345円を下回る**。もし「保守側を選んだ結果だけが不成立を生む」構造で
   あれば、校閲は本裁定を差し戻していた。**系列選択の自由度をすべて潰しても結論が変わらない**
   ことが、本裁定を結論先にありきの使い分けから区別する最も強い証拠である。

### 2-3. 是正値の決め方（裁定B・裁定Cの適用手順）

1. **是正の基準日は、条文の基準日 2026-07-31**（本日08/03ではない）。条文が固定しようとした
   時点の値を復元するのが目的であり、判定日時点の窓を使えばそれは裁定A（固定値主義）に
   反するローリング再算出になる。
2. 基準日07/31時点で採りうる系列は 窓A（07/02〜07/30）・窓B（07/03〜07/31）× 母/標本の4系列。
   ゲートは 32 / 33 / 36 / **37**円。
3. 裁定Cにより**ゲート最大の保守側 37円**（窓B・標本 σ20=2.629105%、σ20成分36.1765円）を採用。
   下抜け閾値 = 1,376 − 37 = **1,339円**、上抜け閾値 = 1,376 + 37 = **1,413円**。
4. 保守側を採ることの意味: 下抜け条件では閾値が**下がる**ため、格下げ（PASS検討）が起きにくく

   誤発火を抑える側**に働くため、結論に都合よく選んだ選択ではない。
