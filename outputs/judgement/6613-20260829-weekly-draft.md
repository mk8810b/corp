## 7.【最重要】D-012 4基準の逐条判定 —— BUYの可否

**D-012は「却下理由が一つも見つからなければBUY」という消極的判定を禁じ、最低1つ以上の
積極的採用理由の明記を必須とする。以下、4基準を逐条で照合する。**

### 7-1. 基準1: カタリスト特定済み・かつ市場に未織り込み — **不成立**

**候補カタリストは2件あるが、いずれも「未織り込み」の要件を満たさない。**

**(a) TDKとの事業協力契約・特許権譲渡（約5億円の特別利益）**

- **カタリスト自体は具体的に特定できる**（前段は充足）: 契約締結2026-06-01、対価約5億円、
  業績予想修正も同日公表（3-2節）。
- **しかし、これは2026-06-01に会社自身が適時開示し、同日に通期業績予想の修正まで公表済みの
  情報である。** 判定基準日2026-08-28まで**88日**が経過している。**「公開情報の中でもまだ
  広く認知されていない」という要件を積極的に支持する根拠が存在しない。**
- さらに、IFIS株予報のアナリスト予想経常利益（3百万円）は会社予想（3百万円）と一致しており、
  **セルサイドも会社予想を織り込んだうえで目標株価650円・レーティング「中立」を提示している**
  （RSH-S91 13-1節）。市場が本件を見落としていると主張する根拠はない。
- **未計上であること（3-3節）を「未織り込み」と読み替えることはできない。** 計上の時期が
  未確定であることは会計処理上の不確定性であって、市場が事象そのものを知らないことを意味
  しない。

**(b) 2026-08-28の△9.12%の値動き**

- **材料が特定できておらず non-probative（2節）。** カタリストとして扱うこと自体ができない。

**(c) その他**: 台湾ITRI・東京大学荒川研究室との共同研究開発（2026年3月開始）、受注残高
+54.48%（RSH-S91 11節・12節）はいずれも既開示情報であり、未織り込みを支持する根拠はない。

**結論: 基準1は不成立。**

## 8.【最重要】WATCHとPASSの判別 —— JDG-O72①に依拠しない

### 8-1. PASSの定式（JDG-O81）への当てはめ

JDG-O81が確立したPASSの定式は「**積極的採用理由が0件であり、かつそれが成立へ転じる経路が
存在しないこと**」である。

- **前段（0件）は満たす**（7-5節）。
- **後段は満たさない。** 以下8-3節の検査により、**D-012基準3が成立へ転じうる、銘柄固有・
  金額特定済み・期日が会計期間末で確定した離散イベントが未解消のまま実在する**ことが確認
  された。したがって**PASSの定式を満たさない → PASSとしない。**

### 8-2. WATCHを選ぶ根拠の構成（JDG-O78の(α)(β)(γ)のみに依拠する）

**(α) 実額の大きな改善が実在する**（値動きではなく、開示原本の実額）:

**(β) 離散的・非普遍的・情報産出的な解消イベントが実在する**:

- **情報産出的**: 判明の結果は二方向に分岐する——計上され通期予想が維持/上方修正されれば
  基準3の再照合に実質的な材料が生じ、計上されない/通期予想が下方修正されればPASSへの

**(γ) 無限後退の終端を条文として置く**: **6613-T6（PASS発火・ファンダメンタルチャネル）**と

**結論: 識別力を持つ軸は「基準2（PASS方向）」と「基準3＋離散イベント（WATCH方向）」の2つで

## 9. D-018統制語彙のゲート計算（本起案が独自データでPython再計算）

### 9-1. 入力データと計算

**出典**: kabutan日足（1-2節と同一取得。`https://kabutan.jp/stock/kabuka?code=6613&ashi=day&page=1`・
`&page=2`、curl・ブラウザ相当UA、**取得日時 2026-08-30T23:28:27Z**、2026-06-04〜2026-08-28の
61営業日・欠落なし）。**σ20・出来高平均・基準率はすべて本起案がこの系列からPythonで再計算した**
（絶対制約第2条・憲法第2章-5）。

**公式窓の定義**: `playbooks/judgement.md` は「σ20＝当該銘柄の直近20営業日の日次終値変動率の
標準偏差（**出来高20日平均と同じ窓**の時系列から算出）」と定める。したがって
**窓A＝判定基準日を含む直近20営業日の終値（2026-07-31〜2026-08-28、日次リターン19本）**を
**公式窓**とする（先例3863-20260829-weekly-draft と同型）。

```python
import json, math, statistics as st
rows = json.load(open('rows.json'))          # kabutan日足を本起案がパースしたもの（新しい順）
num = lambda s: float(s.replace(',', ''))
closes = [num(r[4]) for r in rows]; vols = [num(r[7]) for r in rows]

cl, vo = closes[:20], vols[:20]              # 窓A（26/07/31〜26/08/28）
avg_vol = sum(vo)/20
avg_amt = sum(v*c for v, c in zip(vo, cl))/20

def sigma(cl):
    ch = list(reversed(cl))
    simp = [ch[i]/ch[i-1]-1 for i in range(1, len(ch))]
    logr = [math.log(ch[i]/ch[i-1]) for i in range(1, len(ch))]
    return {'pstdev_simple': st.pstdev(simp)*100, 'stdev_simple': st.stdev(simp)*100,
            'pstdev_log':    st.pstdev(logr)*100, 'stdev_log':    st.stdev(logr)*100}

sA = sigma(cl)
close = 2203.0
two_pct   = close*0.02
sigma_yen = close*max(sA.values())/100
tick      = 1.0
gate      = math.ceil(max(two_pct, sigma_yen, tick))
print("avg_vol_20:", round(avg_vol,1), " avg_amt_20(億円):", round(avg_amt/1e8,4))
print("sigma20(窓A):", {k: round(v,4) for k,v in sA.items()})
print("2%成分:", round(two_pct,2), " σ20成分:", round(sigma_yen,2), " tick:", tick)
print("GATE:", gate, " 上抜け:", close+gate, " 下抜け:", close-gate)
print("出来高1.5倍閾値:", math.ceil(avg_vol*1.5))
```

### 10-3.【重要】「押し目を形成し出来高が落ち着く」条項を設定しない理由

D-018の統制語彙は3つ目の条項として「押し目を形成し出来高が落ち着く」（基準高値からの下落率が
終値ベースで5〜15%かつ当日出来高が20日平均以下の日が2営業日連続）を用意している。
**本メモはこの条項を意図的に設定しない。** 理由:

```python
hi20 = 2452.0   # 窓A 終値高値（2026-08-25）
close = 2203.0
print("現在の下落率:", round((close/hi20-1)*100, 2), "%")     # -10.15
print("5〜15%帯の価格域:", round(hi20*0.95,1), "〜", round(hi20*0.85,1))  # 2329.4 〜 2084.2
```

- **判定基準日終値2,203円は、窓A終値高値2,452円（2026-08-25）から-10.15%であり、
  D-018が定める5〜15%帯（2,329.4円〜2,084.2円）に起案時点で既に入っている。**
- したがってこの条項を置くと、**発火は出来高側の条件（20日平均以下が2営業日連続）にのみ依存
  する**。本起案が窓を1日ずつずらしてローリング20日平均と比較したところ、**「20日平均以下が
  2営業日連続」は直近24判定日で5回成立（約21%）**していた。
- **これは、7532・3076・150Aで検出された「起案時点で既に充足済みの条文」および
  9692-T3旧(b)型の「内容にかかわらずほぼ必ず発火する条文」に接近する。** 条項を置けば
  数営業日以内にTRIGGEREDとなり、**新しい情報を何ら産出しないままイベント駆動ルーチンを
  1回消費する**可能性が高い。
- **代替**: 基準高値を窓外の61営業日高値3,255円（2026-06-25）に取ると下落率は-32.3%となり、
