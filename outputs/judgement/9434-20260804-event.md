## 4. D-018統制語彙に基づく9434-T1（価格トリガー）の判定・σ20算出（全数値Python再計算）

`playbooks/judgement.md`のD-018定義に従い、「明確に下抜け」の閾値を **max(基準価格の2%, σ20,
呼び値1ティック)** で算出した。基準価格は前日終値224.5円とする。

```python
import statistics
# closes: 2026-05-12〜2026-08-04の60営業日分（kabutan.jp日足ページ2ページ分、curl取得）
# today_idx = 2026-08-04のインデックス
prev_close = 224.5
def pct_returns(cl):
    return [(cl[i]-cl[i-1])/cl[i-1]*100 for i in range(1,len(cl))]

# 窓A: 直近20営業日（当日除く）
window_excl = closes[today_idx-21:today_idx]
returns_excl = pct_returns(window_excl)
sigma20_excl_pop  = statistics.pstdev(returns_excl)   # 1.4440%
sigma20_excl_samp = statistics.stdev(returns_excl)    # 1.4815%

# 窓B: 直近20営業日（当日含む）
window_incl = closes[today_idx-20:today_idx+1]
returns_incl = pct_returns(window_incl)
sigma20_incl_pop  = statistics.pstdev(returns_incl)   # 1.5189%
sigma20_incl_samp = statistics.stdev(returns_incl)    # 1.5584%

two_pct = prev_close * 0.02   # 4.4900円
for label, s in [("窓A(当日除く)-母標準偏差", sigma20_excl_pop), ("窓A(当日除く)-標本標準偏差", sigma20_excl_samp),
                 ("窓B(当日含む)-母標準偏差", sigma20_incl_pop), ("窓B(当日含む)-標本標準偏差", sigma20_incl_samp)]:
    sigma_yen = prev_close * s/100
    threshold = max(two_pct, sigma_yen, 1.0)
    print(label, f"sigma20={s:.4f}% -> {sigma_yen:.4f}円, 閾値={threshold:.4f}円")
```
