### (c) 是正した点（1件）

**(c)-1 D-012 基準4（エッジ仮説）を「成立」→「不成立」へ是正した。**

起案は「持分法投資損益の倍増が税引前利益の伸びの真因であるという発見」をもって基準4成立と
した。これは次の2点で成立しない。

1. **決定的な理由 — エッジ仮説の前提条件（銘柄側）を満たさない。** `playbooks/judgement.md`
   の基準4は「**アナリストカバレッジが薄い銘柄の**適時開示・決算短信を当日中に読み込み、
   公開情報の中でもまだ広く認知されていない具体的な事実を発見できた」と定める。9432は
   **TOPIXコア30構成銘柄**（起案自身が0節・4節で確認）であり、日本市場で最もカバレッジが
   厚い銘柄群に属する。**「カバレッジが薄い」という前提が構造的に成立しない以上、
   本銘柄について基準4が成立する余地は原理的にない。**
2. **発見の性質も基準を満たさない。** 持分法による投資損益（12,239→23,544）は、決算短信の
   **要約四半期連結損益計算書に印刷された1行**であり（原本265行目。さらにセグメント情報601行目・
   キャッシュ・フロー計算書401行目にも再掲）、損益計算書を読む者なら誰でも目にする数値である。
   起案は「タスク前提の仮説を訂正した」ことを発見の根拠としているが、それが訂正したのは
   **起案指示文の作業仮説**であって市場の認知ではない。**指示文の誤りを正したことは、市場が
   その事実を認知していないことの証明にならない。** 基準4が想定する水準は、先例
   `outputs/judgement/3182-20260804-scan.md` の「TDnet開示本文に一切記載がなく、EDINET臨時報告書を
   別途取得して初めて判明した親会社単体190.6億円の債権放棄損」のような、**一次資料の横断が
   なければ到達できない事実**である。

**ただし発見それ自体の分析的価値は否定しない。** 「見た目の大きい金融収益+20,206に注目すると
対をなす金融費用+21,825を見落とす」という指摘は、利益の質を評価するうえで有用であり、
1-3節の分析はそのまま残す。**是正したのは「これはD-012基準4に該当する」というラベリングだけ**
である。

### 1-3. 利益の質: 税引前利益の伸びが営業利益を上回った理由（Python分解）

営業利益YoY+4.93%に対し税引前YoY+7.57%・当期利益YoY+5.82%と、下段の利益ほど伸び率が高い。
タスク前提は「金融収益+20,206／金融費用+21,825の急増」を候補として挙げていたが、これを
Pythonで分解すると**金融収支単体はむしろ悪化方向**であり、伸びの主因は別にあることが分かった。

```python
op_cur, op_prev = 425149, 405193
pretax_cur, pretax_prev = 421411, 391769
fin_income_cur, fin_income_prev = 43824, 23618
fin_cost_cur, fin_cost_prev = 71106, 49281
equity_method_cur, equity_method_prev = 23544, 12239  # 持分法による投資損益

fin_net_cur = fin_income_cur - fin_cost_cur
fin_net_prev = fin_income_prev - fin_cost_prev
fin_net_delta = fin_net_cur - fin_net_prev
equity_delta = equity_method_cur - equity_method_prev
op_delta = op_cur - op_prev
pretax_delta = pretax_cur - pretax_prev

print(f"金融収支(収益-費用): 前年{fin_net_prev:,} -> 当期{fin_net_cur:,} (差分{fin_net_delta:,})")
print(f"持分法投資損益: 前年{equity_method_prev:,} -> 当期{equity_method_cur:,} "
      f"({(equity_method_cur/equity_method_prev-1)*100:+.2f}%, 差分+{equity_delta:,})")
print(f"税引前増減{pretax_delta:,} = 営業利益増減{op_delta:,}({op_delta/pretax_delta*100:.1f}%) "
      f"+ 金融収支差分{fin_net_delta:,}({fin_net_delta/pretax_delta*100:.1f}%) "
      f"+ 持分法損益差分{equity_delta:,}({equity_delta/pretax_delta*100:.1f}%)")
# => 金融収支: 前年-25,663 -> 当期-27,282 (差分-1,619、悪化)
# => 持分法投資損益: 前年12,239 -> 当期23,544 (+92.37%, 差分+11,305)
# => 税引前増減29,642 = 営業利益増減19,956(67.3%) + 金融収支差分-1,619(-5.5%) + 持分法損益差分11,305(38.1%)
```

|---|---|---|---|
| 金融収益 | 23,618 | 43,824 | +20,206 |
| 金融費用 | 49,281 | 71,106 | +21,825 |
| **金融収支（収益-費用）** | **△25,663** | **△27,282** | **△1,619（悪化）** |
| 持分法による投資損益 | 12,239 | 23,544 | **+11,305（+92.37%）** |

**結論（タスク前提の訂正）**: 金融収益・金融費用はともに急増しているが、両者の差引（金融収支）は
**△1,619百万円とむしろ悪化**しており、税引前利益の押し上げ要因ではない（金融費用の増加額
21,825が金融収益の増加額20,206をわずかに上回る）。税引前利益の増加分29,642百万円のうち、
**67.3%は営業利益の増加（19,956百万円）で説明でき、残り38.1%（11,305百万円）は持分法による
投資損益がほぼ倍増（+92.37%）したことで説明できる**（金融収支の悪化-5.5%を差し引いて合計
100%）。すなわち「税引前の伸びが営業利益を上回った」現象は**金融収支では説明できず、持分法適用
会社（関連会社・共同支配企業）の業績改善が主因**である。短信は持分法投資損益の投資先別内訳を
開示しておらず、**個別の牽引先企業は取得不能**（0節）。この事実（金融収支の見た目の急増が

## 4. D-018統制語彙に基づくσ20算出（全数値Python再計算、9432-T4新設トリガーの基礎）

`playbooks/judgement.md` D-018定義に従い、σ20（当該銘柄の直近20営業日の日次終値変動率の
標準偏差）を4系列（窓の基準日包含/非包含 × 母標準偏差/標本標準偏差）で算出した。

```python
import statistics
# closes: 2026-05-14〜2026-08-06の60営業日分（kabutan.jp日足ページ2ページ分、curl取得）
def pct_returns(cl):
    return [(cl[i]-cl[i-1])/cl[i-1]*100 for i in range(1,len(cl))]

window_excl = closes[-22:-1]   # 直近20営業日（当日除く、07/09〜08/05終値の21点から20リターン）
window_incl = closes[-21:]     # 直近20営業日（当日含む、07/10〜08/06終値の21点から20リターン）
ret_excl = pct_returns(window_excl)
ret_incl = pct_returns(window_incl)

sigma20_excl_pop  = statistics.pstdev(ret_excl)   # 1.4023%
sigma20_excl_samp = statistics.stdev(ret_excl)    # 1.4387%
sigma20_incl_pop  = statistics.pstdev(ret_incl)   # 1.4714%
sigma20_incl_samp = statistics.stdev(ret_incl)    # 1.5096%

base = 154.5   # 2026-08-06確定終値。新設トリガーの基準価格として採用（今後の値動きの起点）
two_pct = base * 0.02   # => 3.0900円
for label, s in [("窓A(当日除く)-母標準偏差", sigma20_excl_pop), ("窓A(当日除く)-標本標準偏差", sigma20_excl_samp),
                 ("窓B(当日含む)-母標準偏差", sigma20_incl_pop), ("窓B(当日含む)-標本標準偏差", sigma20_incl_samp)]:
    sigma_yen = base * s/100
    for tick in (0.1, 1.0):
        gate = max(two_pct, sigma_yen, tick)
        print(label, tick, f"sigma20={s:.4f}% -> {sigma_yen:.4f}円, ゲート={gate:.4f}円")
```

|---|---|---|---|
| 窓A（当日除く・07/09〜08/05終値の20リターン）・母標準偏差 | 1.4023% | 2.1666円 | **3.0900円**（2%が支配） |

| 窓B（当日含む）・標本標準偏差 | 1.5096% | 2.3324円 | **3.0900円** |

### 基準1: カタリスト特定済みかつ市場が未織り込みか

- **結論: 基準1は不成立**（校閲JDG-O55で表現を整理。統制語彙は成立／不成立の2値であり
  「部分的成立」は語彙外）。**理由**: 前半要件（カタリストの特定）は満たす——増収増益・進捗率の
  前年超過・持分法投資損益の急伸として具体的に特定できる。しかし**後半要件（市場がまだ十分
  織り込んでいない）を充足できない**。決算は大引けの2時間前（13:30 JST）に開示され、株価は
  当日中に既に+2.32%（日次σ1.40〜1.51%の1.5〜1.7倍相当）反応している。出来高が1.5倍閾値に
  届いていない点は「反応が不完全である可能性」を示唆するにとどまり、未織り込みを**積極的に
  主張する**根拠にはならない。D-012が禁じたのは消極的判定（欠点がないからBUY）であり、
  「未織り込みを否定しきれないから成立」という論法はその裏返しにあたるため採らない。

### 基準2: 同業比バリュエーション下位かつ構造的欠陥なしか

- PBRは前回判定時（2026-07-09）の1.25倍から**1.27倍へわずかに上昇**（Python: `1.27-1.25=0.02`）。

- **結論: 基準2は成立。** 前回判定時からバリュエーションはわずかに上昇したが、依然として
  同業2社を明確に下回る水準を維持している。この割安さを正当化する構造的な欠陥（財務悪化・
