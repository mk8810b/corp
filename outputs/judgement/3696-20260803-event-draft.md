def ceil_tick(x, t=1): return math.ceil(round(x / t, 9)) * t

closes = [v[0] for _, v in ser]

base   = 2173.0                       # 3696-T2の基準値＝2026-07-30確定終値（既存メモ5節）

## 5. 上振れ余地スコア（D-010）: **中 → 低**（引き下げ）

**引き下げる。** 既存メモ6節が「中」とした根拠は、要約すれば次の2本の柱であった:

> (柱1) モッピー・SQUIZという事業面の増益ドライバーは実態を伴い、5期連続増収・Q1実績の強い
> 伸長とも整合的。ビットバンク株式売却が実行されれば収益の質が改善する可能性がある。
> (柱2) 出来高急増に対し価格反応が鈍く、市場評価の方向性が定まっていない（＝未織り込みの
> 可能性が残る）。

**本日までの事実により、柱2が崩れた。**

1. **柱2の消滅（本メモの主たる引き下げ根拠）**: 既存メモが「翌営業日以降の値動き・出来高の推移
   こそが実際の市場評価を測る材料」と明記して判定を委ねた結果、07/31に**日経平均+4.03%の全面高の
   中で-2.76%・出来高3.09倍の逆行安**という回答が出た（2-2・2-3節）。市場評価の方向性は
   「定まっていない」のではなく、**ネガティブ方向に定まった**。これは価格の下落そのものではなく、
   **既存メモが自ら設計した判定手続きが出した結論**である。
2. **柱1は維持されている**（事業ドライバー・ビットバンク売却）。したがって「低」より下
   （＝PASS）には至らない。
3. **バリュエーション面の変化は軽微**: PBR1.90→**1.86倍**、予想配当利回りは4.24%。PERは4.1倍
   だが特別利益込みの見かけの数値であり、引き上げ材料としては使わない（3節基準2）。

**結論**: 上振れの種（モッピー・SQUIZの事業成長、ビットバンク売却による収益の質改善）は残るが、
その種が市場に評価される見通しが実際の取引で否定されたため、**「中」の根拠の半分が失われた**。
**「低」**とする。

> **注記（D-010の趣旨遵守）**: 既存メモ6節の校閲注記は「足切り回避を意図した引き上げは行って
> いない」と明記していた。本メモも同様に、**足切りを誘発する意図でも回避する意図でもなく**、
> 上記の事実に即してスコアを決定した。台帳容量への帰結は9節2に事実として提示する。
