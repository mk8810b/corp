## 3.【最重要①】自社株買い上限17.65%の実質規模——金額上限が先に頭打ちになる

### 3-1. 実質取得可能比率の再計算（本メモ独自のPython計算）

会社開示: 上限1,000,000株（発行済株式（自己株式除く）5,666,100株の**17.65%**）・上限
**500,000,000円**・取得期間2026-08-14〜2027-08-13・市場買付（RSH-S83 2-2節、原本確認済み）。

```python
import math
close = 746.0
shares_out = 5_666_100
cap_shares = 1_000_000
cap_yen = 500_000_000

pct_by_shares = cap_shares/shares_out*100
shares_by_yen = math.floor(cap_yen/close)          # 746円で5億円を使い切った場合の取得可能株数
pct_by_yen = shares_by_yen/shares_out*100
breakeven_price = cap_yen/cap_shares                # 株数上限と金額上限が一致する株価
amt_for_full_shares = cap_shares*close              # 100万株全部買うのに必要な金額(746円時)

print("上限株数ベース比率:", round(pct_by_shares,2), "%")
print("746円で5億円使い切った場合の取得可能株数:", shares_by_yen, "株")
print("その場合の発行済比率:", round(pct_by_yen,2), "%")
print("差:", round(pct_by_shares-pct_by_yen,2), "pt")
print("株数上限=金額上限となる株価(損益分岐):", breakeven_price, "円")
print("100万株全部買うために必要な金額(746円時):", amt_for_full_shares, "円 =",
      round(amt_for_full_shares/cap_yen*100,1), "% of 上限5億円")
```

実行結果:

| 項目 | 値 |
|---|---:|
| 上限株数ベース比率（会社開示・見出し数値） | **17.65%** |
| 746円で5億円を使い切った場合の取得可能株数 | **670,241株** |
| その場合の発行済株式に対する比率 | **11.83%** |
| 見出し数値との差 | **△5.82pt** |
| 株数上限と金額上限が一致する損益分岐株価 | **500円** |
| 100万株全部を取得するために必要な金額（746円時） | 746,000,000円（上限5億円の**149.2%**、金額上限を大幅に超過） |

**現在の株価水準（746円）では、金額上限（5億円）が株数上限（100万株）より先に頭打ちになる。**
株価が500円を下回らない限り、実際に取得できる株式数は発行済の17.65%ではなく、**5億円÷株価
で決まる。** 746円を基準にすれば実質**11.83%**であり、会社が公表する「17.65%」という見出し
数値と実際の取得可能比率には**5.82ptの乖離**がある。これは会社の開示に誤りがあるという意味
ではなく（開示自体は正しく株数ベースの上限を示している）、**投資判断上「17.65%」を需給

**本件（150A）にこの規律を適用する。** 08-17〜08-20の累積+20.6%上昇に対応する開示は存在

基準1後半要件・未織り込みの成立方向）と読むことも、「既知の08-13材料が出尽くした後の
過熱・バブル的な上昇」（基準1不成立方向）と読むことも、**いずれも当社が識別できる情報の
範囲を超えている。** この値動きはBUY方向・PASS方向いずれの根拠としても用いない。

### 4-3.【本件固有の追加論点】材料のない上昇の後の下落を「押し目」と呼べるか

D-018が「押し目を形成し出来高が落ち着く」というトリガー文言を制定した際の立法趣旨
（`corp/board.md` D-018）は、**急騰・高値形成が判断メモに記録された銘柄の沈静化確認**という
文脈での運用であり、その前提となる急騰は暗黙に「材料を伴う上昇」を想定していた（実際の
既存WATCH銘柄の運用例——3673・4073等——はいずれも決算・受注等の具体的開示を起点とする上昇に
対する押し目判定だった）。

**本件はこの前提を欠く。** 08-17〜08-20の上昇そのものがnon-probative（4-2節）である以上、
08-21の△6.87%を「材料を伴う健全な上昇の後の調整＝押し目」と積極的に性格づけることは
できない。**この下落もまた、上昇と対称に、no­n-probativeな値動きの一部として扱うのが
整合的である**——「材料なく上がったものが材料なく下がった」という記述以上の実質的な意味を
本メモは読み取らない。

**したがって本メモは、この下落を「D-018の押し目条件に近い形状が観測された」という**手続的な
事実（12節のD-018トリガー設計の基礎）**としては記録するが、「健全な調整が起きているので
BUYに有利」あるいは逆に「材料なき上昇の反動なのでBUYに不利」という**実質判断の根拠には
一切用いない**。D-018の機械的トリガー定義（基準高値801円の固定・帯5〜15%等）は、今後の
値動きを客観的に検知するための**手続**であり、それ自体が「今回の下落が押し目である」という
**実質認定**を意味するものではないことを、本メモは明示的に区別する。
