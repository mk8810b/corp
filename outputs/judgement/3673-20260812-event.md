## 4. 下期含意 +157.2%——両論併記（先例4751・7593との違い）

企業調査メモ6節のPython再計算を独自に検算した。

```python
h1_op, fy_op = 1477, 4800
h1_ni, fy_ni = 1001, 3200
h2_op_implied = fy_op - h1_op          # 3,323百万円
h2_ni_implied = fy_ni - h1_ni          # 2,199百万円
h2_2025_op, h2_2025_ni = 1292, 823     # 前年同期(H2 2025)実績
print(round((h2_op_implied/h2_2025_op-1)*100, 2))   # +157.2%
print(round((h2_ni_implied/h2_2025_ni-1)*100, 2))   # +167.19%
```

| 科目 | H2 2025実績 | H2 2026含意額 | 前年同期比 |
|---|---|---|---|
| 営業利益 | 1,292百万円 | 3,323百万円 | **+157.20%**（自社再検算で一致） |
| 親会社帰属当期利益 | 823百万円 | 2,199百万円 | **+167.19%**（自社再検算で一致） |

**先例4751（含意Q4 -58.3%）・7593（含意Q2 -41.6%）はいずれも含意が減益であり、
「進捗率の高さは分母の低さの帰結」と判定された。本件は逆に含意が大幅増益であり、先例の
判定ロジックをそのまま転用できない。**以下、両論を同じ厳しさで検討する。

**強気の読み（「経営陣が強気の計画を維持している」）:**
- 会社は8/3のH1速報公表・8/12の中間期決算という2度の機会でこの計画を修正しなかった。
  会社が最も情報を持つ主体であり、その会社が慎重な下方修正をしなかったことは、経営陣が
  下期の実現可能性を引き続き信じていることの表れとも解釈できる。
- 会社側の定性説明（大手部品商・整備事業者向けの下期からの導入拡大、必要リソース確保済み、
  「現時点で下期のクラウド導入計画に影響する大きな事象は顕在化していない」）は具体性がある。
- H1自体が既に営業利益+91.5%という高成長であり、事業の勢い自体は本物（増収の質7節）。

**弱気の読み（「据え置き自体が保守的とも強気とも解釈できる、保証はない」）:**
- +157.2%という加速幅は、既に高水準だったH1の伸び率（+91.5%）をさらに上回る要求であり、
  会社の定性説明はこの定量的な加速幅を裏付けるだけの具体性を持たない（企業調査メモ6節が
  明記する取得不能事項）。
- 会社は「対通期予想進捗率は参考値、通期達成の判断にはクラウド導入の進捗が重要」と自ら
  注記しており、**会社自身も下期の不確実性を認めている**——これは強気の裏付けというより
  留保に近い。
