### 3-2. 解釈（両論）

  市場参加者の反応であり、それが+18.11%という大幅なプラスであることは、**「市場がまだ
  気づいていない」のではなく「気づいた上で強く評価している」ことを示す直接的な証拠**である。
  もしこの水準が寄り付きにある程度反映されれば、1,326円という基準値自体が既に「入り口」
  ではなくなる。
- **本メモの立場**: いずれの解釈が正しいかは、本則市場が実際に取引を再開するまで確定
  できない。ただし、**基準1の成立には「未織り込みを積極的に立証できる」ことが必要**であり、

- **本件が先例と異なる点**: 3182・3673では本則市場が実際に開示当日〜翌日と取引を行い、
  その反応（逆行安・低出来高の反発）が確定した事実として「未織り込み説」を否定した。

## 4. σ20・出来高のPython再計算（D-018トリガー設計の前提）

企業調査メモ14節が示した20日分の終値・出来高系列（新しい順、2026-08-04を含む20営業日）を
用いて、σ20（直近20営業日の日次終値変動率の標準偏差）を自社で再計算する。

```python
import math

# 研究メモ14節の系列（新しい順: 08/04が先頭）を時系列順（古い→新しい）へ並べ替え
closes_recent_first = [1326,1340,1340,1335,1380,1395,1409,1394,1401,1420,1416,1403,1429,
                        1419,1413,1380,1393,1410,1432,1443]
vols_recent_first = [373500,286500,197000,600900,153100,152800,114000,112300,104900,192600,
                      167000,159600,76700,64500,89900,88400,111200,91400,122600,124300]

closes_chrono = list(reversed(closes_recent_first))
# 【校閲で是正】起案時は窓開始日の前日終値（21個目）が取得不能でn=19としていたが、校閲者が
# kabutan確定終値ページから2026-07-06終値=1,415円を取得したため、n=20で再計算する。
prev_close = 1415   # 2026-07-06確定終値（kabutan.jp、校閲者取得 2026-08-04T23:43Z）
closes_chrono = [prev_close] + closes_chrono
rets = [(closes_chrono[i]-closes_chrono[i-1])/closes_chrono[i-1] for i in range(1,len(closes_chrono))]
n = len(rets)
mean_r = sum(rets)/n
pop_sd = (sum((r-mean_r)**2 for r in rets)/n)**0.5
samp_sd = (sum((r-mean_r)**2 for r in rets)/(n-1))**0.5
print(n, pop_sd*100, samp_sd*100)      # -> 20  1.283392%  1.316732%

basis = 1326
print(basis*0.02, pop_sd*basis, samp_sd*basis)  # -> 26.52  17.0178  17.4599

ceil_tick = lambda x,t=1: math.ceil(round(x/t,9))*t
gate = ceil_tick(max(basis*0.02, samp_sd*basis, 1))
print(gate, basis+gate, basis-gate)    # -> 27  1353  1299

vol_avg20 = sum(vols_recent_first)/len(vols_recent_first)
print(vol_avg20, vol_avg20*1.5, math.ceil(vol_avg20*1.5))  # -> 169160.0  253740.0  253740

basis_high = max(closes_chrono)
print(basis_high)                       # -> 1443（2026-07-07確定終値、研究メモ6-2節と一致）
low = basis_high*0.85
high = basis_high*0.95
print(math.ceil(round(low,9)), math.floor(round(high,9)))   # -> 1227  1370
```

実行結果:
- **σ20（20本の日次リターンから算出、母1.2834%／標本1.3167%）はいずれも2%を下回るため、
  2%成分（26.52円）が拘束的**。呼び値1円で切り上げ**27円**。**上抜け1,353円・下抜け1,299円**。
  （起案はn=19で母1.2461%／標本1.2802%としていたが、校閲でn=20に是正。**2%成分が拘束的である
  結論・ゲート27円・上抜け下抜けの水準はいずれも不変**。）
- **20日平均出来高（08/04を含む20営業日、研究メモ12節の値をそのまま採用）169,160株**。
  1.5倍＝253,740株。
- **直近20営業日の終値最高値は1,443円（2026-07-07）**。押し目帯（5〜15%下落）は
  **1,227円〜1,370円**。

**計算上の窓の定義の明記（第2条）**: 上記σ20はn=20の日次リターン（2026-07-06終値を起点、
2026-08-04終値を終点）から算出した。20日平均出来高の窓は判定日08/04自体を含む（先例の

  限定的。

- **開示後最初の市場反応（PTS）が大幅なプラス**であり、08/05の寄り付きで本則市場の反応が
  確認できる近さにある（数時間以内に基準1・T1/T2の判定材料が揃う）。

**上振れを抑制する要因**
- **同業比較でPER・PBRとも5社中2番目に高く、「割安」の外形自体を満たさない**（基準2
  明確に不成立）。

- **PTS（+18.11%）が示唆する強い初期反応が正しければ、実際のエントリー可能価格は
  1,326円から大きく上振れする可能性が高く**、割安な入り口という前提が成立しない
  リスクがある。

- **創業家資産管理会社3社で議決権54.24%の支配株主構造**、**中間期数値は監査法人の

**総合**: 好材料の質・量そのものは本メモが調査した中でも高い部類だが、**既に相応に
高いバリュエーション**（同業2位）と**PTSが示唆する強い初期反応（既に評価され始めている
可能性）**が上振れの「効き」を削いでいる。一方で、3182・3673のように本則市場での
確定的な悪い反応（逆行安等）はまだ観測されておらず、**「未確定」という保留の性質**は
先例より前向きに評価できる。数時間以内に08/05の寄り付き反応という決定的な確認材料が
得られる近さにあることも踏まえ、**「中」**とする。
