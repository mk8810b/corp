## 1. BUY判定4基準（D-012）の検討

`playbooks/judgement.md`は「却下理由が一つも見つからなければBUY」という消極的判定を明示的に

### 基準1: カタリスト特定済み（かつ市場に未織り込み）

  1. 出来高は2.91倍と明確に増加した一方、株価変動幅（+1.45%）は限定的であり、年初来高値
     2,234円（2026-07-02）を上回っていない（研究メモ8-2節）。出来高の増加ほどには価格が

     反応が乏しく、市場は既に相応の情報を織り込んでいた」とも解釈でき、どちらか一方を
     積極的に立証する根拠にならない（2節で詳述）。
  2. 7/12付株探特集記事「上方修正“先回り”候補37社」に3696が選出されていた事実（研究メモ11節）

     逆方向に働く材料である。
  3. 当期純利益＋1.7%という開示された最終値そのものは、市場が最も注目する指標の一つであり
     大きなポジティブサプライズとは言えない。仮に市場が「営業利益ベースの大幅増益」ではなく

     むしろ合理的な市場行動として説明がつき、「未織り込み」の根拠は一段と弱まる。
- **結論**: カタリストの「特定」はできるが、「市場に未織り込み」を積極的な確信として明記

## 2. 「開示はまだ十分織り込まれていないか」の正面からの検討

- **事実関係**（研究メモ8節）: 本日終値2,173円（+1.45%）、出来高395,900株（直近20営業日平均
  136,130株の**2.91倍**、本メモ3節でPython再検算し一致確認済み）。売買代金854百万円・約定回数
  1,738回。年初来高値2,234円（2026-07-02、本開示より前）は上回っていない。
- **「出来高の増加ほどには価格が大きく動いていない」（研究メモ8-2節）という事実をどう解釈するか**:
  1. **未織り込み仮説**: 出来高が平常時（6-7万〜30万株台）を大きく超えて急増しているにも
     かかわらず株価が+1.45%にとどまっていることは、多くの売買が「様子見」的なポジション
     調整（既存保有者の一部利確・新規参入者の打診買い等）にとどまり、開示内容（特に営業利益
     +32.1%という大幅増益）の本格的な評価はこれから、という解釈が可能。
  2. **織り込み済み仮説**: 7/12の株探特集記事「上方修正“先回り”候補」への選出（研究メモ11節）、
     アストリス社レポート（2026-04-08、「修正は時間の問題」との評価、研究メモ5-3節）という
     独立した先行材料が複数存在し、市場の一部参加者は本日の上方修正をある程度織り込んで
     ポジションを構築していた可能性がある。また、当期純利益+1.7%という最終値の伸びの小ささ
     （基準1・3で述べた通り）を市場が正しく評価した結果、大幅な株価反応に至らなかったという
     解釈も成り立つ。7/23のアセットマネジメントOne・7/7のInvescoの保有割合減少報告
     （研究メモ11-2節）という、方向としては売り圧力に働きうる独立材料も直近に存在する。
- **本メモの評価**: 研究メモの調査範囲では、本日の株価変動幅のうちどの程度が本開示に起因し
  どの程度が無関係な要因（機関投資家の需給調整等）によるものかを分離する情報がなく、
  **未織り込み仮説・織り込み済み仮説のいずれか一方を積極的に立証することはできない**。
  これは1節の基準1判定（「部分該当だが確信を持てる根拠がない」）を直接裏付ける。翌営業日
  以降の値動き・出来高の推移こそが実際の市場評価を測る材料であり、これをWATCHトリガーの
  中心に据える（4節）。

## 3. σ20・出来高の再計算（Python、D-018トリガー設計の前提）

企業調査メモ8-2節は直近20営業日平均出来高（136,130株）と本日出来高比（2.91倍）を算出済みだが、
σ20（直近20営業日の日次終値変動率の標準偏差）は未掲載のため、本メモが追加で再取得・算出する。

- 出典: `https://kabutan.jp/stock/kabuka?code=3696&ashi=day&page=1`（curl取得、User-Agent指定、
  取得日時2026-07-30T23:27:xxZ、`3696_kabuka.html`として保存）。日足終値・出来高データを
  抽出しPythonで再計算した（企業文化2章-5準拠）。

```python
import statistics

# 直近20営業日（2026-07-01〜2026-07-29、研究メモ8-2節と同一窓。前営業日終値は06/30の2,091円）
window20 = [
    ("2026-07-01",2112,307300), ("2026-07-02",2186,309000), ("2026-07-03",2096,186900),
    ("2026-07-06",2101,133000), ("2026-07-07",2129,138400), ("2026-07-08",2144,288200),
    ("2026-07-09",2134,141500), ("2026-07-10",2156,98500),  ("2026-07-13",2133,75900),
    ("2026-07-14",2160,95300), ("2026-07-15",2158,71700),  ("2026-07-16",2145,69700),
    ("2026-07-17",2108,112900),("2026-07-21",2132,66500),  ("2026-07-22",2138,69800),
    ("2026-07-23",2112,94200), ("2026-07-24",2063,115900), ("2026-07-27",2105,95200),
    ("2026-07-28",2120,93600), ("2026-07-29",2142,159100),
]
prev_close = 2091  # 2026-06-30終値

avg_vol20 = sum(v for _, _, v in window20) / 20
# => 136,130株（研究メモ8-2節の値と完全一致することを確認）

closes = [prev_close] + [c for _, c, _ in window20]
returns_pct = [(closes[i] / closes[i-1] - 1) * 100 for i in range(1, len(closes))]

sigma20_pop  = statistics.pstdev(returns_pct)   # 母標準偏差（n=20）
sigma20_samp = statistics.stdev(returns_pct)    # 標本標準偏差（n-1=19）

today_close, today_vol = 2173, 395900
vol_ratio = today_vol / avg_vol20
```

**実行結果**:
- 直近20営業日平均出来高 = **136,130株**（研究メモ8-2節の値とPython再計算で完全一致することを

## 5. 上振れ余地スコア（D-010）: **中**

判定根拠:
- ポジティブ要因: モッピー（金融案件広告需要）・SQUIZ（オンライン診療ユーザー数積み上がり）
  という事業面の増益ドライバーは実態を伴い、5期連続増収・Q1実績の強い伸長（研究メモ7節）とも

  (b) 当期純利益増分の相当部分（225〜275百万円、仮説）が未解明のまま残っており進捗の質を
  積極的に評価できない（1節基準3）、(c) SQUIZのれんの未公表・財務コベナンツ抵触リスク、

  構造的な逆風が複数残る（研究メモ10節）、(d) 出来高急増に対し価格反応が鈍く、市場評価の
