## 3.【最重要】PASSへの格下げを検討する——4751先例（校閲JDG-O67）の4基準テストを適用

3673-T7の条文は「上振れ余地スコアのさらなる引き下げ・**PASSへの格下げを検討する**」ことを

### 3-1. 基準①: 観測標本は「状態」の認定に足りるか

```python
from datetime import date
print((date(2026,8,13)-date(2026,8,12)).days)   # -> 1（暦日。間に休場日なし）
```

**3673-T7は本日（2026-08-13）の大引けで成立した。これは「急落そのものの日」であり、
成立後の追加確認観測は現時点でゼロ営業日である。**

4751の先例では、T2が2026-08-10（急落当日）に成立し、その後08-11（山の日で休場）を
挟んで08-12の1営業日だけ観測した上で「反発の兆候がない」という論拠でPASSが提案され、
校閲はこれを「D-018の統制語彙が状態の認定に最低2営業日連続を要求しているのに対し、
1営業日はそれに満たない」として**不足と裁定した**。

**本件はそれよりもさらに薄い。** 3673-T7の成立日である本日をもって直ちにPASSを検討する
ことは、4751で「不足」と裁定された1営業日の観測にすら達していない、**ゼロ営業日の
観測**でPASSを判定することに相当する。**4751の先例が確立した基準にa fortiori（一層
強く）該当し、標本としてPASSを支えない。**

なお本件の日次σ20は2.578%（5節）であり、本日の変動幅-8.10%は約3.14σに相当する
（4751の0.027σとは異なり、統計的に有意な動き自体ではある）。しかし「統計的に有意な
単日の値動き」であることと、「その状態が継続するかどうかを2営業日以上かけて確認した」
こととは別の問題である——D-018が「押し目を形成し出来高が落ち着く」を2営業日連続で
定義しているのは、単日の動きが翌日以降も継続するかを機械的に確認する規律のためであり、
この規律を「悪い方向の動き」にだけ適用しないのは非対称である。

### 3-2. 基準②: D-015の恒久的却下事実は存在するか

**株価が-8.10%下落したという事実のみでは、D-015の恒久的却下事実には当たらない。**

### 3-4. 基準④: T9の検証経路は保全されるべきか

3673-T9（次回の決算に係る適時開示——第3四半期決算短信または通期決算短信のいずれか
