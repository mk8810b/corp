### 3-3.【重要】先例（4751・7593）との構造的な違いを明示する

先例4751は含意Q4進捗-58.3%、7593は含意Q2進捗-41.6%と判定し、いずれも「進捗率の高さは
分母（会社予想）の低さの帰結であり、実質的な悪化を隠している」という構図だった。**本件は
これらと構造が異なる**:

- 4751・7593は**期中の進捗率**（実績の一部が会社予想に対してどう進んでいるか）を問題に
  した事例であり、通期実績は未確定だった。
- 本件は**通期実績が既に確定し、しかもその実績が会社の直近予想を全項目で上回って着地した
  うえで、初めて開示された来期（2027.06期）予想が減益**という、時系列上まったく異なる
  局面である。「進捗率の高さが分母の低さの結果に過ぎない」という4751・7593型の批判は、
  **通期実績が出揃った後の来期予想には適用できない**（分母〔今期実績〕は既に確定した実数
  であり、来期予想の分子〔減益幅〕を予想側の会社自身が開示している）。
- したがって本件の論点は「進捗の見かけ」ではなく、**「今期の大幅な業績改善が、来期には
  反転・鈍化するという会社自身の予想をどう評価するか」**である。会社は減益要因を研究開発・

## 4.【要注意】費用計上区分の組替——どちらの基準で評価すべきか

企業調査メモ5節の実測: バイオマス燃料事業の費用計上区分を販管費→売上原価へ組替。

| | 2027.06期計画 | 2030.06期計画 |
|---|---:|---:|
| 売上総利益（組替前） | 132億円 | 215億円 |
| 売上総利益（組替後） | **110億円** | **187億円** |
| 営業利益（組替の影響なし） | 64億円 | 134億円 |

**2026.06期実績には組替は不適用**（会計方針の変更「無」、決算短信注記で確認済み）。したがって
3節の通期実績・前年比自体はこの論点の影響を受けない。

**論点は「2027.06期予想 対 中期経営計画目標」という進捗評価にのみ生じる**:

```python
gross_2027_forecast = 10450          # 百万円
mid_term_post = 11000                # 組替後（110億円）
mid_term_pre = 13200                 # 組替前（132億円）
print((gross_2027_forecast-mid_term_post)/mid_term_post*100)   # -> -5.0%
print((gross_2027_forecast-mid_term_pre)/mid_term_pre*100)     # -> -20.83%
```

決算説明資料は「ほぼ計画線」（△5.0%）という評価を**組替後基準のみ**で提示しており、
組替前（中期経営計画が公表された時点の原基準）での評価は開示本文に一切ない。

**どちらの基準で評価すべきか（本メモの判定）**: 中期経営計画（2024-08-14公表）は組替前の
132億円という数値を前提に市場・当社の初回調査（`outputs/research/5074-20260725.md`）が
形成されたものである。**進捗を評価する基準は、目標が設定された時点の原基準（組替前132億円）
であるべきであり、事後的に組替を行った基準（110億円）で「ほぼ計画線」と評価するのは、
目標線自体を引き下げてから達成率を測るのと同義であり、進捗評価としての意味を失わせる。**
本メモは**組替前基準（△20.8%の未達）を実質的な進捗として採用する**。

ただし、以下の点で先例3182（車両運行サービス事業売却による比較基準の変更）とは温度差が
ある点も明記する: **営業利益レベルの中計対比未達（4,700百万円 対 中計目標6,400百万円、
△26.6%）は、決算説明資料のブリッジ図で会社自身が明示的に開示しており、隠蔽されていない**
（3-2節）。組替による見かけの改善が生じているのは**売上総利益という中間科目に限られ**、
最終的な収益性の指標である営業利益では会社は既に大きな未達を透明に開示している。**したがって
本件は3182型（比較基準の変更により全体の未達が見えにくくなる事例）と完全に同型ではなく、
中間科目（売上総利益）の表示のみに影響する、相対的に軽度な事例と評価する。** ただし
中間科目であっても「ほぼ計画線」という定性評価を組替後基準のみで提示し、組替前基準を
併記していないことは、開示の透明性という観点で留意事項として記録する。
