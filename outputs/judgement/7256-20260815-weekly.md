## 4. 出来高11.65倍・日中値幅30.86%・終値+4.64% の一次データ

### 4-1. 校閲による独立再取得と再計算

  ある**（有報(11)）。これは希薄化にとどまらない**上場維持そのものへのテールリスク**である。
- 日産自動車の議決権比率は **13.05%**（58,272 ÷ 446,557 = 13.0492%、有報記載13.05%）。
  **企業調査メモ・起案の「13.04%」は切り捨てによる誤り**であり、確定版では13.05%に訂正する。
- 日産自動車から取締役2名が派遣されており、投資契約により**当社の重要事項について日産自動車の
  事前の承諾を要する**（有報(12)）。
- **年率7.0%・複利・累積型の優先配当条項**（有報(13)）。7256は無配であり、この配当も支払われて
  いないため累積が続く。金銭対価取得請求が2028年4月以降に行使されれば、払込金額相当額＋累積
  未払配当の一括支払いが必要となり、財政状態・キャッシュフローに影響しうる（会社自ら明記）。

### 6-3. 三重関係の構造としてのリスク

日産自動車は単独で、**(a) 最大の販売先（FY2026売上の52.58%）**、**(b) 議決権13.05%の筆頭株主**、
**(c) A種優先株式の全量保有者＝希薄化条項の発動権者** の三役を兼ねている。ここから生じる
具体的なリスクを記録する:

1. **価格交渉力の非対称性**: 通常のOEM–サプライヤー関係以上に、日産自動車は7256の資本構成に
   直接の利害を持つ。7256が独立した立場で価格交渉を行えるかという構造的懸念がある。
2. **「支援」の実質**: 5-3節のとおり会社自身がQ1の増収要因として「販売先OEMからの支援を
   はじめとした価格是正等」を明記している。**Q1の業績改善が、市場一般が想定する「独立した事業の
   収益力回復」とは異なる性質（資本関係に紐づいた支援）を帯びる可能性**があり、日産自動車の
   方針が変化した場合に持続しない可能性がある。5-4節の切り分け不能と同根の問題である。
3. **希薄化の発動キーを最大の取引先が握る**: 転換請求は既に行使可能（6-2節(2)）であり、
   その意思決定を行う主体は日産自動車である。既存普通株主にとって最大の希薄化リスク（希薄化率
   261.00%・持分低下74.68%）の発動権を、最大の取引先かつ筆頭株主が単独で握っている。

**校閲の判断**: この構造は7256の株式評価にとって中立ではない。「Q1業績の改善」を評価する際は、
常に**「どこまでが自律的改善で、どこまでが大株主兼販売先による支援か」という留保**を伴わせる。

### 6-4.【判定】D-015フラグ(c)「MSワラント等の大規模希薄化条項が未行使残存」

企業調査メモ10-3節は「MSワラントの定義には形式的に該当しないため機械的な該当判定は避ける。
D-015フラグ(c)の該当性判断は投資判断部・リスク管理部に委ねる」として判定を委任している。
**校閲がこれを確定する。**

**判定: 該当（フラグ(c)は成立する）。**

**「等」の範囲に含まれるかという条文解釈**（本論点は明示的に論じる必要がある）:

- **D-015(c) の文言は「MSワラント（行使価額修正条項付新株予約権）"等"の大規模希薄化条項が
  未行使残存」である。** 条文は「行使価額修正条項付新株予約権」を**例示**として掲げ、「等」を
  付すことで、**それと機能的に類似する大規模希薄化手段を包摂する構造**になっている。
  もし「行使価額修正条項付新株予約権」に厳密限定する趣旨であれば「等」は不要である。
- **D-015 が(c)を置いた立法趣旨は、決定本文が明示するとおり「損切り-10%が約定しない壊滅的
  ギャップ（上場廃止等の-100%）の資金全体への影響を5%以下に抑える」ことにある。** すなわち
  保護法益は「希薄化の規模が資本構成を破壊しうること」であって、「行使価額が修正される機構」
  そのものではない。
- **本件のA種優先株式は、この保護法益に正面から当たる**: 希薄化率261.00%（既存株主の持分低下
  74.68%）、**転換請求は既に行使可能**、未行使のまま残存、しかも**全転換は東証スタンダードの
  流通株式比率25%基準への抵触＝上場維持リスクを会社自ら開示している**（6-2節(3)）。
  規模・未行使性・テールへの接続のいずれもD-015(c)の想定する類型そのものである。
- **「等」による包摂を制限的に運用すべき先例（5074案件）との区別**: 5074で非該当とされた
  「解除条項付き大口受注」は、D-015の4文言（継続企業注記／監査意見／MSワラント等／債務超過）の
  いずれとも**機能的に一致しない別種のリスク（カウンターパーティ集中）**だった。対して本件の
  A種優先株式は**「未行使の大規模希薄化条項」という(c)の文言が指す機能そのもの**を備える。
  したがって本件は拡張解釈ではなく、**条文の文言（「等」）の通常の適用範囲内**である。

**他方で、古典的MSワラントとの相違点も明記する（判定は変えないが性質は異なる）**:

- 校閲は有報の**【行使価額修正条項付新株予約権付社債券等の行使状況等】欄が「該当事項はありません」**
  であることを原本で確認した。**形式上、本件はMSCB／MSワラントとして分類される商品ではない。**
- 取得価額の調整条項（有報「(4) 取得価額の調整」）を全文読んだ結果、①株式分割 ②株式併合
  ③取得価額を下回る払込金額での新株発行・自己株処分 ④同種の株式発行 という**希薄化防止型の
  標準的アンチダイリューション条項のみ**であり、**株価に連動して転換比率が定期的に不利化する
  「行使価額修正（リセット）条項」は存在しない**。したがって**「株価下落 → 転換株数増加 →
  さらなる下落」というデス・スパイラル機構は本件には無い。**
- **ただし**、年率7.0%・複利・累積型の優先配当が未払で積み上がることにより、**転換交付株式数は
  時間の経過とともに単調に増加する**（116,550,116株 → FY2026時点で128,320,066株）。
  株価連動ではないが**時間連動の希薄化エスカレーター**が作動している点は記録に値する。

**帰結**: 本銘柄について将来BUYを検討する場合、**確信度「高」（10%枠）は提案できず、上限は
「中」（5%）となる**（D-015、`playbooks/judgement.md`）。本メモの判定はWATCHのため直接の適用
対象ではないが、将来の判断メモへ引き継ぐ。

## 7. D-015フラグ(a) — 継続企業の前提に関する注記または重要事象（校閲が原本で自ら確認）

### 7-1. 校閲による原本の独立確認（INC-009／INC-010の教訓）

INC-009・INC-010は、**「継続企業の前提に関する注記」という見出し文字列への一致だけでフラグ(a)を
該当と判定した偽陽性**が繰り返し発生した事故である（見出しは全短信の目次と本文にほぼ必ず存在
するため、文字列一致は常に真になる）。**校閲は見出しではなく本文まで自ら読んだ。**

```
$ pdftotext -layout q1.pdf q1.txt ; grep -n "継続企業" q1.txt
113: （４）継続企業の前提に関する重要事象等 …………………………５        ← 目次
121:  （継続企業の前提に関する注記） ……………………………………11        ← 目次
216: （４）継続企業の前提に関する重要事象等                              ← 定性的情報の本文見出し
225: 然として継続企業の前提に重要な疑義を生じさせるような事象又は状況が存在しているものと認識しております。
275: 成可能性が順調に高まっていると考えております。このため、継続企業の前提に重要な疑義を生じさせる事象は存在
276: するものの、継続企業の前提に関する重要な不確実性は認められないものと判断しております。

475:   該当事項はありません。
```

**確認結果（2種類の記載を厳密に区別する）**:

- **正式な会計注記**「継続企業の前提に関する注記」（474〜475行目、四半期連結財務諸表の注記事項）:
  → **「該当事項はありません。」**（＝正式注記は付いていない）
- **定性的情報の「（４）継続企業の前提に関する重要事象等」**（216〜226行目、財務諸表注記とは

  又は状況が存在しているものと認識しております。」**（全文は5-3節に引用）
- 275〜276行目: 「継続企業の前提に重要な疑義を生じさせる事象は存在するものの、継続企業の前提に
  関する重要な不確実性は認められないものと判断しております。」

背景として、有価証券報告書（第95期）には「(14) 継続企業の前提に関する重要事象等」の項があり、
**前期は財務制限条項抵触・有価証券報告書の法定期限内提出不能により正式な「継続企業の前提に
関する注記」を記載していたが、当期（FY2026）に当該注記を解消した**旨が記載されている
（校閲が原本1010行目以降で確認）。**すなわち「正式注記は解消されたが、疑義を生じさせる事象・
状況の存在は会社自身が認識・記載を継続している」という状態である。**

### 7-2. 判定 — 条文への当てはめ

**D-015条文（`corp/board.md` D-015-2、`playbooks/judgement.md`）は
「(a) 継続企業の前提に関する注記**または**重要事象の記載がある」と定めている。**

本件は、前段（注記）は「該当事項はありません」だが、**後段（重要事象の記載）は明確に存在する** —
セクション名がまさに「継続企業の前提に関する**重要事象等**」であり、その本文に会社自身の
「重要な疑義を生じさせるような事象又は状況が存在している」という認識が記載されている。
**条文が選言（「または」）で書かれている以上、後段のみの充足で該当が成立する。**

**判定: 該当。** 校閲が原本本文を自ら読んだ上での確定判定である。

**INC-009／INC-010との関係（重要）**: 両インシデントは「見出しだけで**該当あり**とした偽陽性」で
あり、その是正は「本文を読み、『該当事項はありません』なら**非該当**とする」ことだった。
**本件はその逆で、見出し（正式注記欄）だけを見れば『該当事項はありません』＝非該当と誤読する

**結論（校閲）**: **「KMEX問題の延長である」という論証は成立しない（別系統）。しかし「内部統制

### 13-1.【校閲による訂正】σ20の算出窓の統一とゲート値の再計算

```python
# 21終値 → 日次リターン20件 の標本標準偏差
# 窓A（当日08/14を含む）: 終値窓 26/07/15〜26/08/14 → σ20 = 3.2330 %   ← 企業調査メモ記載値と一致

```

**採用する窓: 窓B（判定日2026-08-14を除く直近20営業日）。** 理由は3点:
(1) 起案が出来高20日平均に窓Bの値（161,925株）を採っており、D-018の**同一窓要件**を満たすには

(3) 当日出来高（4,284,600株＝除く窓平均の26.46倍）を自らの比較基準に含めると、**極端な1日が
自分自身の閾値を押し上げる循環**が生じ、D-018が明示する「見逃し回避側に閾値を置く」方針に反する
（窓Aを採ると出来高ゲートは551,640株となり、窓Bの242,888株の2.27倍に跳ね上がる）。

**確定ゲートの計算**:

```python
close = 451.0 ; sigma20 = 3.1015   # %（窓B、校閲がPythonで算出）
two_pct   = close*0.02        # ->  9.0200 円
sigma_amt = close*sigma20/100 # -> 13.9878 円
tick      = 1.0               # 呼び値1ティック（JPX: 3,000円以下は1円）
gate = max(two_pct, sigma_amt, tick)   # -> 13.9878 円（= 終値比 3.102%、σ20が支配項）
math.ceil (close+gate)   # -> 465  上抜け閾値

math.ceil (close*0.85), math.floor(close*0.95)   # -> 384, 428  押し目帯（5〜15%、内側丸め）
round(close*0.90,2), round(close*1.25,2)         # -> 405.9, 563.75  損切/利確参考値
```

**D-018ゲート = 13.9878円（σ20支配、終値比3.102%）。上抜け閾値 465円以上／下抜け閾値 437円以下。**
