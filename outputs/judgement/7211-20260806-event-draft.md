## 4. 出来高沈静化の意味 — 「当日の薄商い」と「20日平均の上昇」は矛盾しない

2節の表が示す通り、**当日出来高そのもの**は08-03の13.39M株から08-06の8.72M株へ一貫して減少
傾向にある一方、**20営業日平均出来高**は16,061,890株→17,071,400株へ**+6.285%上昇している**
（Python再計算、以下）。

```python
avgs = [16_061_890, 16_396_965, 16_800_190, 17_071_400]
for i in range(1, len(avgs)):
    d = avgs[i]-avgs[i-1]
    print(f"{d:+,} ({d/avgs[i-1]*100:+.3f}%)")
# => +335,075 (+2.086%) / +403,225 (+2.459%) / +271,210 (+1.614%)
total = avgs[-1]-avgs[0]
print(total, total/avgs[0]*100)
# => +1,009,510 (+6.285%)
```

**この2つの事実は矛盾しない。区別すべきは「当日の絶対出来高」と「比較対象である20日平均自体の
水準」である。**

- **当日の絶対出来高は明確に細っている**: 08-06の8,720,900株は観測4日間で最少であり、直近の
  20日平均（17,071,400株）の**51.08%**に過ぎない（2節）。これは「今日、この銘柄への関心が
  実際に薄れている」という一次的な事実を示す。
- **一方で比較対象の20日平均は上昇基調にある。** 7211は2026-07-09にHighlanders提携報道を受けて
  出来高63,040,900株の急騰を記録している（`outputs/judgement/7211-20260711.md`1-2節・1-3節、
  出典kabutan.jp、取得2026-07-11）。この一事象が20営業日の移動平均窓の中でどの位置にあるかを
  概算する:

```python
from datetime import date, timedelta
def business_days(start, end):
    d = start; out = []
    while d <= end:
        if d.weekday() < 5: out.append(d)
        d += timedelta(days=1)
    return out
bd = business_days(date(2026,7,10), date(2026,8,5))
print(len(bd))  # => 19（祝日カレンダー未確認の概算。海の日2026-07-20等の休場を考慮すると実質18程度）
```

08-06時点の「当日を除く」20営業日平均は概ね07-09〜08-05の20営業日に相当し、**Highlanders発表日
（07-09、出来高63,040,900株）は当該20日窓の最古端付近（またはその近傍）に位置する**（祝日
カレンダーは未確認のため厳密な出入りの日は特定できず「取得不能」と明記する。日次の詳細な
出来高系列を再取得すれば厳密な特定は可能だが、本稿はタスク前提により株価・出来高データの
再取得を行わないため、この決定論的な裏取りは行わない）。

**含意**: 20日平均が上昇している最も自然な説明は、07-09の突出した出来高（平常の約4倍規模）と
それに続く発表後数日間の高水準出来高が、この20日移動窓の中で相対的に静かだった発表前の日々を
順次置き換えていく過程にあることである。すなわち**20日平均自体が「急騰イベントの余韻」に
よって押し上げられたままの水準**にあり、それ自体は市場の継続的な関心の高まりを意味しない
（イベント平均の窓内残存という技術的な理由による）。

この読み方の下では、**「当日出来高が、急騰の余韻でなお押し上げられている平均を下回る」という
08-06時点の条件充足は、平均が平常水準まで落ち着いた後に同じ条件を満たすよりもむしろ意味が強い**
——沈静化の判定基準自体が甘くなっていないにもかかわらず、当日の薄商いがそれを下回ったという
ことだからである。したがって、本稿は7211-T2の成立を「出来高条件が緩んだことによる形式的な
成立」ではなく、**「急騰の余韻がなお残る比較的高い基準に対してもなお需要が細っている」という
実質を伴った沈静化のシグナル**と評価する。ただし、この20日平均の日次内訳（07-09が正確に窓の
何営業日目に位置するか、平均を押し上げている具体的な日）はPythonで厳密に再現できておらず、
上記は状況証拠に基づく合理的な推論である旨を明記する（第2条）。
