## 2.【最重要・論点1】一過性利益と通期予想の不整合——3つの仮説の切り分け

### 2-1. 事実（企業調査メモ4節より引き継ぎ、Pythonで再検算）

```python
gain_consolidated = 3300  # 連結固定資産売却益（概算）、百万円

h1_sales, h1_op, h1_ord, h1_np = 108512, -21, 1738, 1349
fc_sales = 200000
for label, h1v, fcv in [("売上高", h1_sales, fc_sales), ("営業損益", h1_op, fc_op),
                          ("経常利益", h1_ord, fc_ord), ("純利益", h1_np, fc_np)]:
    print(label, round(h1v/fcv*100, 1))

再現した（企業調査メモの数値と一致）。**通期経常利益予想2,700百万円に対し一過性売却益は122.2%、
通期純利益予想500百万円に対しては660.0%に達する。それでもなお会社は2026-02-13公表の予想を
据え置いている**（理由: 「米国の関税政策の変更や中東情勢の変化など…現時点で合理的に見積もることが
困難」、決算短信原文）。

### 2-2.【裁定】3つの仮説の切り分け——本メモの入力範囲では切り分け不能と明記する

会社が本件（33億円の一過性売却益、H2計上予定）を織り込んだ上でなお通期予想を据え置いている
という事実は、論理的に次の3仮説のいずれかと整合する:

| 仮説 | 内容 | 支持する事実 | 反する事実 |
|---|---|---|---|
| (i) 上方修正余地の温存 | 会社は保守的に予想を据え置いているだけで、実際には上振れの蓋然性が高い | 一過性売却益だけで通期純利益予想の6.6倍に達する規模。会社が「合理的に見積もることが困難」という理由は下方修正ではなく判断保留を示唆するとも読める | 会社は「業績予想への影響について慎重に精査を進めている」と述べるのみで、上方修正を示唆する文言は原本のどこにも存在しない |
| (ii) H2に相当規模の損失を織り込み | 米国関税・中東情勢による下期の追加悪化（原価高・需要減等）を織り込んでおり、売却益と相殺してなお現行予想500百万円に着地する computation を会社は内部的に持っている | H1営業損益進捗2.1%（通期予想△1,000百万円に対しH1実績△21百万円のみ）であり、**H2だけで通期予想の残り約979百万円の営業損失を織り込む計算が予想の構造そのものに既に存在する**（4-3節で詳述）。会社が名指しした不確実性（米国関税・中東情勢）は自動車部品業界に直接影響しうる外生要因である | 会社は「精査が困難」と述べるのみで、具体的な損失見込みへの言及はない |
| (iii) 単純な精査未了 | 33億円という規模の一過性事象の反映作業が単に完了していない（決算・開示実務上の時間差） | 08-17開示（契約締結）から本メモ基準日（08-18）までわずか1営業日であり、通期業績予想の精査完了には物理的に時間を要するのは自然である。決算短信自体も「精査を進めております」という進行形の表現を用いている | 会社は08-07（不動産譲渡決定の当初開示）の時点から既に11日が経過しており、売却額80億円・売却益33億円という規模は08-07時点で既に確定していた。単純な事務処理の遅延だけで11日以上未反映というのはやや説明力が弱い |

**いずれの仮説についても、本メモが確認した一次資料（臨時報告書・TDnet開示・決算短信）の記載
だけでは、単一の仮説に絞り込む根拠が存在しない。したがって本メモは(i)(ii)(iii)を「切り分け不能」
と明記し、いずれか一つを断定しない**（絶対制約第2条）。

**ただし、(ii)の可能性を積極的に示唆する構造的事実が一つある**——4-3節で示すとおり、通期予想
（据置き前から存在する予想。33億円計上前の水準）自体が既に「H2に上期改善幅の相当な積み増しを
必要とする」という高いハードルを内包している。この事実は仮説(ii)が「33億円計上後もなお現行の
低い予想を維持できる」ためのバッファとして機能しうることを示すが、**これは会社が実際にそのような
織り込みを行っているという証拠ではなく、あくまで論理的な整合性の指摘にとどまる**。

### 2-3. H2の要求水準（Pythonで再計算、企業調査メモの数値を検算）

## 3.【最重要・論点2】賃料取得不能の帰結——正味の経済効果は評価不能

$ grep -n "15年\|１５年" S100YXBD.txt
81:   ※なお、本件はセール・アンド・リースバック方式によるものであり、譲渡後も当社は15年間の定期建物
```

**賃貸借期間15年は原本で確認できるが、賃料そのものは金額・算定方法とも一切開示がなく、
中途解約条項・違約金条項の有無も不明である。**

### 3-1.【裁定】評価できないことの意味

セール・アンド・リースバックの経済的構造は次のとおりである:

```
正味の経済効果 = (売却対価80億円 − 帳簿価額44億円の差益33億円の運用益／有利子負債削減効果)
                  − (将来15年間の賃料支払いの現在価値)
```

**賃料（減算項）が不明である以上、この式は計算不能である。** 売却益33億円という一時金だけを見て
「財務にプラス」と評価するのは、**将来15年間のキャッシュアウトを無視した片手落ちの評価**であり、
本メモはこれを行わない。逆に、「賃料が不明だから警戒すべき」として一方的にマイナスと決めつける
根拠もない（賃料が市場実勢並みであれば、資産の流動化としては合理的でありうる）。

**したがって本メモは、本件SLB取引の正味の経済効果について「評価できない」と明記し、これを
判定の積極的な理由（BUY方向）にも消極的な理由（PASS方向）にも用いない。** この不能をBUY方向の
根拠に転用すること（「賃料が分からないのだから悪材料ではないはず」という推論）は、3863-T5先例
（「材料が未定量であることはPASSを回避する理由にならない」）の趣旨を裏返しに適用したものに
相当し、同じ理由で禁止する——**未定量の材料を好材料に転化してはならない**（4073校閲JDG-O76の
規律をここでも適用する）。

## 8. バリュエーション（基準2の当てはめ）

出典: 企業調査メモRSH-S78 8節。本メモがPythonで再検算。

|---|---|---:|---:|---:|

**PBRは6社中3位（0.58<0.59<0.73）で中位。PERは6社中最高（他5社9.4〜16.3倍に対し45.3倍）。**

### 8-1.【裁定】PER45.3倍とPBR0.73倍の乖離が意味するもの

PERとPBRの関係は定義上 `PBR = PER × ROE` である。PERが極端に高くPBRが1倍未満に沈んでいるのは、
**分子（利益水準）が分母（純資産・株価）に対して極端に薄いことを意味する**——すなわち
**ROE（自己資本利益率）が著しく低い水準にあることの別表現である。**

```python
roe = bps/eps_fc  # 逆算: ROE ≈ EPS/BPS
print(round(eps_fc/bps*100, 2))   # => 1.62 (%)
```

**通期予想ベースのROEはわずか約1.62%である。** これは「株価に対して資産が割安（PBR基準では
中位）」であることと、「利益を生む力が資産規模に対して著しく弱い（PER基準では突出して割高）」
ことが同時に成立している状態であり、**市場が本銘柄を「資産は相応にあるが稼ぐ力が乏しい」と
評価していることの定量的な裏付け**である。この評価は4節（本業赤字）・2節（一過性利益依存）の
分析と整合する。

**D-012基準2（同業比バリュエーション下位であり、かつその割安さを正当化する構造的な欠陥が
見当たらない）は不成立と判定する。** PBRは中位であって最下位ではなく「明確に割安」とは言い
切れず、かつ仮に割安と扱ったとしても、その割安さを正当化しうる構造的な欠陥（本業赤字予想・
無配・ROE約1.6%・過去の私的整理歴・支配株主構造）が明確に存在する。

| (ii) 期日確定性 | **一部充足（backstopで補う）。** 正確な公表予定日は本メモの取得範囲では**取得不能**（会社開示に明記なし）。ただし有価証券報告書に「第１四半期連結累計期間及び第３四半期連結累計期間に係る財務情報に対するレビュー：有」と明記されており、四半期情報の開示自体は継続される制度上の裏付けがある。中間期（Q2）決算短信の公表日は2026-08-07（4月-6月期末から約38日後）であり、この間隔をQ3（7-9月期末）に適用すると2026年11月上旬頃と推定される。**確定日ではなく推定であることを明記し、backstop期日2026-11-30を設定する** |
| (iii) 判定連結性 | **充足。** D-012基準2・基準3双方の成否を動かす |

**3要件中(i)(iii)は充足、(ii)は「推定＋backstop」で部分充足として扱う。** 8165先例（校閲JDG-O79）
の処理に倣い、backstop期日を設けることで期日確定性の欠如を補う（10節・T3で条文化）。

### 9-3. 結論

**2つの検証経路のうち、経路A（物件引渡）は3要件を完全に満たし、経路Bは(ii)を推定＋backstopで
補って満たす。したがって本メモは「唯一の検証経路の保全」を理由にWATCH継続を正当化してよい。**
ただし、**この規範4の充足は「PASSを選ばない理由」であって「BUYする理由」ではない**点を明記する
（12節でD-012の4基準を別途、独立に検証する）。

## 10. PASS発火条件の設計（3673-T11・5074-T7・4052-T12/T13・8165-T3/T4の先例に倣う）

**設計方針**: 立証責任の転換（発火時はPASSを既定路線とし、WATCH継続には新規事実の積極的明記を
要する）と、無限後退の終端（最終検証点の処理をもって後継の同型トリガーを新設しない）を条文に
含める。9節の3要件テストにより、経路A・経路Bともに検証経路として正当であることを確認済み。

- **第1段階（経路B・Q3決算、推定2026年11月上旬・backstop 2026-11-30）**: 通期予想が据え置かれた
  まま維持されているか確認する。**(a)** 第3四半期累計の営業損益が通期予想△1,000百万円の
  損失枠を上回るペースで悪化している場合、または**(b)** 33億円の売却益を織り込んでもなお
  通期純利益予想が上方修正されない場合（＝2節仮説(ii)の確度が高まったと解される場合）、
  または**(c)** 通期予想が据え置かれたまま経路A（物件引渡）が延期・不成立となった場合、
  **PASSへの格下げを既定路線とする。**
- **第2段階＝無限後退の終端（経路A・物件引渡・売買代金受領、2026-10-01予定）**: 取引が予定どおり
  完了し、かつ**その後最初の決算（想定: 通期本決算または該当する四半期決算）で33億円の売却益の
  実際の計上内容・通期予想の修正有無が判明した時点**で、2節の3仮説（(i)上方修正余地の温存・
  (ii)H2損失の織り込み・(iii)精査未了）のいずれであったかを検証完了とみなす。**この処理をもって、
  「予想据置きの理由がいつか判明するかもしれない」という期日の定まらない期待を、以後WATCH
  継続の理由に用いることを禁止する。同型の後継トリガー（「その次の決算を待つ」式の機械的な
  繰り返し）を新設してはならない**（先例3673-T11・校閲JDG-O72の無限後退禁止条項を適用）。

具体的な条文化は14節のトリガー一覧（T3・T4）で行う。
