## 6.【最重要】D-012 4基準の逐条判定

### 6-1. 基準1: カタリスト特定済み・未織り込み — **不成立**

**(a) リンテック株式会社株式売却（約263億円の特別利益、個別決算）**

- **しかし市場は既に2026-08-21の時点で反応済みである。** 本起案が独自に取得した日足データ
  （1-2節）によれば、2026-08-21の株価は+2.35%（1,364円→1,396円）、出来高1,630,400株
  （基準日2026-08-28時点の20日平均877,690.0株に対し**約1.86倍**、参考値。08-21時点の
  トレーリング20日平均そのものではない点に留意）を記録している。研究メモも同日付でkabutan.jpニュース
  「日本紙が続伸、リンテック株式売却で27年3月期に投資有価証券売却益を計上へ」を確認済みである

  織り込み、株価に反映させている。**
- **正式な事象発生日（08-24）・臨時報告書提出日（08-25）の株価反応はむしろ軟調である**
  （08-24: -2.36%、08-25: +0.15%）。これは「まだ織り込まれていない」ことの根拠には
  ならず、逆に「既に消化された」ことと整合的である（JDG-O68のnon-probative原則の裏側:
  反応の不在・軟調さを積極的に「未織り込み」の証拠として使うことはできないが、少なくとも
  「未織り込み」を積極的に支持する材料が存在しないことは明確である）。

**(b) 事故2件・業績予想「未定」化**

- これは明確な悪材料であり、D-012基準1が想定する「株価を押し上げる好材料」には該当しない。

**結論: 基準1は不成立。**

### 6-2.【最重要】基準2: 同業比バリュエーション下位 — **不成立**

  手厚い」という組み合わせにはなっていない。**株価が絶対的に安いこと自体はBUY/WATCHいずれの

  不成立とする。**

### 6-3.【最重要・本件の中核】基準3: 業績進捗が会社予想を上回る — **構造的に判定不能＝不成立**

**通期業績予想が2026-08-05付で全項目「未定」に修正されており、進捗率（Q1実績 ÷ 通期予想）を
算出するための分母がそもそも存在しない。**

- 基準3が要求する「直近の決算・開示が会社側の計画を上回るペースで進捗しており」という命題は、
  比較対象となる「会社側の計画」が存在しない限り真偽を判定できない。これは「まだ判明していない
  ので保留する」という中間的な扱いではなく、**判定を行うための論理的な前提自体が欠落している**
  という構造的な事実である。
- **参考として、撤回前（2026-05-15公表）の通期予想（純利益100億円）を仮に生かした場合の
  進捗率も算出してみる**（この参考値は判定には用いない。撤回された予想を分母に使うことは
  会社の意思決定を無視することになるため）:

```python
q1_ni = -233          # FY2027.3 Q1 親会社株主帰属四半期純利益（百万円）
withdrawn_forecast_ni = 10000  # 撤回前の通期予想（百万円、2026-05-15公表）
print(round(q1_ni / withdrawn_forecast_ni * 100, 2), "%")
```

実行結果: **-2.33%**（撤回前予想を仮に生かしても進捗率はマイナスであり、「会社予想を上回る」
とは到底言えない）。**この参考計算は、「予想が撤回されているから判定できない」という構造的な
不能性を、仮に予想が存在したとしてもなお不成立であるという実質面からも裏づけるものである。**

**結論: 基準3は構造的に判定不能であり、成立の根拠は一切示せない。不成立として扱う。**

    simp = [cl_chrono[i]/cl_chrono[i-1]-1 for i in range(1,len(cl_chrono))]
    logr = [math.log(cl_chrono[i]/cl_chrono[i-1]) for i in range(1,len(cl_chrono))]
    return dict(pstdev_simple=st.pstdev(simp)*100, stdev_simple=st.stdev(simp)*100,
                pstdev_log=st.pstdev(logr)*100, stdev_log=st.stdev(logr)*100)

sA = sigma_calcs(closes_winA)
print("avg_vol_A:", round(avg_vol_A,1))
print("avg_amt_A(億円):", round(avg_amt_A/1e8,4))
print("sigma20 window A:", {k: round(v,4) for k,v in sA.items()})

close = 1396.0

tick = 1.0

print("2%成分:", round(two_pct,2), "円")
