## 3.【中心論点】σ20=16.93%の異常な変動性と、D-012基準1への含意

という、材料の裏付けを欠いた乱高下が続いている。

### 3-2. D-018ゲートとD-002損切りの位置関係（JDG-O59〔3907〕の定式化を適用）

Pythonで独立に再計算した（10節）:

```
基準629.0円（本日確定終値）
2%成分: 12.5800円 / σ20成分: 106.4671円 / 1ティック: 1.0円 -> 採用ゲート(max) = 106.4671円
上抜け閾値(切上げ): 736円以上
下抜け閾値(切下げ): 522円以下
D-002損切り参考値(-10%): 566.10円
-> 下抜け閾値522円 < 損切り566.10円 -> 損切りが先に発動する位置関係
```

**JDG-O59（3907案件、2026-08-08校閲確定）が定式化した一般則**——「`max(2%, σ20) ≥ 10%`
すなわち実質的にσ20≥10%の銘柄では、D-018の下抜けトリガーはD-002の損切りライン(-10%)より

損切りライン（566.10円）に到達した後でなければ発動しない。仮に本銘柄を将来BUYし、
このトリガーを「損切り前の早期警戒」として設計しても、その機能を構造的に果たせない。**
この点は8節のトリガー再設計に反映する。

### 3-3.「材料が特定できない値動きの繰り返し」とD-012基準1への含意

D-012基準1は「カタリスト特定済み、かつ市場に未だ十分織り込まれていないと判断できる根拠が
ある」ことを要求する。本件で繰り返し観測されている事実は逆である:

- 07/22〜07/31急騰: 材料「記載なし」と確定（1節）。
- 08/13の-20.46%急落: 材料「取得不能」（研究調査メモ2節、TDnet・EDINET機械照合済み）。
- 本日08/14の値動き: 決算内容とは無関係（時系列上あり得ない）。

**材料が特定できないという状態が3回連続で観測されている以上、「市場が織り込んでいない
具体的な材料がある」という基準1の前段（カタリスト特定済み）自体を主張する根拠が失われる。**
基準1は「カタリストは特定できるが未織り込み」を要求するのであり、「値動きの材料が
そもそも特定できない」状態は基準1の対象外である（値動きの結果をカタリストの代理指標に
しないという前回確定版〔08-05〕の原則とも整合）。**したがって基準1は、Tier1受注という
個別の新事実（4節）を除いては、成立の土台を欠く。**
