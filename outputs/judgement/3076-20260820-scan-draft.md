## 2.【最重要論点】「増収増益の好決算」という見出しと実態の乖離

### 2-1. 見出し数字（自社Python再計算・研究メモと一致）

```python
for label, cur, prior in [("売上高",85024,66197), ("営業利益",10762,8889),
                            ("経常利益",12535,9008), ("純利益",11937,21202)]:
    print(label, round((cur/prior-1)*100,1))
# 売上高 28.4 / 営業利益 21.1 / 経常利益 39.2 / 純利益 -43.7
```

見出しの前期比だけを見れば、営業利益+21.1%・経常利益+39.2%は強い決算に見える。**しかし
以下の3点を総合すると、単純に「好決算」と要約するのは実態を見誤らせる。**

### 2-2. 論点(a): 売上高は会社自身の期初計画に届いていない

会社は期初計画（売上90,000／営業10,700／経常11,400／純利益10,300百万円）を**期中に一度も
修正しなかった**（第3四半期短信「修正の有無：無」を研究メモが原本で確認済み）。この未修正の
計画に対する実績は:

```python
guidance = {'売上高': 90000, '営業利益': 10700, '経常利益': 11400, '純利益': 10300}
actual   = {'売上高': 85024, '営業利益': 10762, '経常利益': 12535, '純利益': 11937}
for k in guidance:
    diff = actual[k] - guidance[k]
    print(k, diff, round(diff/guidance[k]*100,2))
# 売上高 -4976 -5.53 / 営業利益 62 0.58 / 経常利益 1135 9.96 / 純利益 1637 15.89
```

**売上高は期初計画に△5.53%届いていない。** これは「増収」という見出しの下で見過ごされがちな
事実である——前期比+28.4%という高い伸び率自体は事実だが、**会社自身が期初に立てた目標水準には
未達である。** 利益3段階（営業・経常・純利益）はいずれも計画を上回って着地しており、この点は
純粋に好材料である。

### 2-3. 論点(b): 純利益は前期比△43.7%であり、増益基調とは方向が逆

前期（FY2025）に負ののれん発生益17,878百万円（特別利益）が計上されていた反動で、当期純利益は
前期比△43.7%となった。研究メモが原本で確認したとおり、これは営業利益・経常利益の実質的な
伸びとは別の一過性会計要因であり、**「本業の実力が悪化した」ことを意味しない。** ただし
**「増収増益」という見出し表現を機械的に使うなら、純利益は減益であり、この表現自体が不正確**
である点は記録しておく。

### 2-4. 論点(c)【最重要】FY2027会社予想は3指標とも明確に減速する

```python
fy2026 = {'売上高': 28.4, '営業利益': 21.1, '経常利益': 39.2, '純利益': -43.7}
fy2027 = {'売上高': 1.1, '営業利益': 2.2, '経常利益': -6.7, '純利益': -24.6}
for k in fy2026:
    print(k, fy2026[k], "->", fy2027[k], "diff", round(fy2027[k]-fy2026[k],1))
# 売上高 28.4 -> 1.1 diff -27.3
# 営業利益 21.1 -> 2.2 diff -18.9
# 経常利益 39.2 -> -6.7 diff -45.9（増益から減益予想へ転換）
# 純利益 -43.7 -> -24.6 diff +19.1（減益率は縮小するが依然減益）
```

**経常利益は+39.2%の大幅増益から△6.7%の減益予想へ45.9pt悪化する。** これは会社自身が
公表した来期の見通しであり、**当期の見出し数字がそのまま来期も続くという前提でこの決算を
「好決算」と評価するのは誤りである。**

### 2-5. 総合評価: 河西工業（7256）で確立した規律の適用

7256の判断メモが確立した規律「割安材料ではなく見せかけの割安の消滅を取り違えない」と同じ
姿勢で、**本メモは「増収増益」という見出しラベルと、その中身（売上未達・翌期減速）を混同しない。**

**結論**: 本決算は、(1)利益3段階の据置き計画超過という限定的な好材料、(2)売上高の期初計画未達、
(3)純利益の前期比大幅減（一過性要因）、(4)翌期の明確な減速計画、という**複数の方向の異なる
事実が併存する決算であり、単純に「好決算」と呼べるものではない。** 3〜6節のD-012逐条判定は
この認定を前提に行う。

## 8. 基準1・3後段の読み方——2つの解釈の正面からの比較

**読み方(i) 未織り込みが残っている**:

**読み方(ii) 既に織り込み済み・追加材料価値なし**:
- 出来高が大商いでありながら価格変動がTOPIX並みにとどまったことは、買い方・売り方の力が
  拮抗し均衡に達したことを示唆する（「大商いなのに動かない」は「材料が出尽くした」ことの

- 2-5節で確認したとおり、決算の実態（売上未達・翌期減速）は見出しの増益率ほど強気材料で
  はなく、市場がこれを織り込んだ結果としてTOPIX並みの反応にとどまったと解釈することも可能。

**先例の教訓**:
- **4099（JDG-O70）**は「出来高6.07倍・日中値幅8.8%・終値ほぼ横ばい」を起案が「均衡に達した」

- **6033（JDG-O77）**は同型の状況で翌営業日データが無く「検証不能」を判定根拠に使わないと
  明示した。

**本件は「最初の反応日のデータが既に存在する」点で4099・6033より条件が良い。** 4099・6033は
判定日当日のデータしかない状態で判断を迫られたが、**本件の判定基準日は2026-08-20であり、

**この利点を正しく使う**: 4099のように「反応をこれから待つ」のではなく、本メモは**既に

**読み方(ii)（既に相応に織り込まれた）がやや有力**と判定する。ただし**1日のデータのみでの
