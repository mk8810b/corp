### 校閲-2.【重要・起案では未検討】σ20が10%を超えると、下抜けトリガーは損切りラインより後ろに来る

```

D-002 損切り     = ceil(1,673 × 0.9) = 1,506円（同 -10%）
→ 株価が下落する過程では 1,506円（損切り）に先に到達し、1,444.98円（トリガー）は後になる。
```

**一般則（校閲による定式化）**: D-018の下抜けゲートは `max(2%, σ20, 呼び値1ティック)` であり、
D-002の損切りは一律 -10%。したがって **`max(2%, σ20) ≥ 10%` すなわち実質的に σ20 ≥ 10% の銘柄では、
「明確に下抜け」トリガーが損切りラインより必ず後ろに来る。**

```
σ20 = 1.5% → ゲート2.0%  : 下抜けトリガーが先（-2%で発動、損切り-10%より手前）
σ20 = 5.0% → ゲート5.0%  : 下抜けトリガーが先
σ20 = 9.9% → ゲート9.9%  : 下抜けトリガーが先（かろうじて）
σ20 = 10.0%→ ゲート10.0% : 同着以降。損切りが先に発動
σ20 = 13.63%(3907) → ゲート13.63% : 損切りが先に発動
```

## 10. 再評価トリガー（D-018統制語彙）

### 10-0. σ20が13.6297%という異例な大きさについて（設計上の対処）

D-018の「明確に上抜け/下抜け」ゲートは `max(対象価格の2%, σ20, 呼び値1ティック)` で定義される。

```python

two_pct = close * 0.02          # => 33.46円
sigma_yen = close * (sigma20_pct / 100)  # => 228.024881円

# => 33.46 228.024881 228.024881
```
