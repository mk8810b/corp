## 3. 担保差入れの規模評価（Python再検算）

```python
pledge_mizuho, pledge_resona = 370_000, 250_000
pledge_total = pledge_mizuho + pledge_resona  # 620,000

pct_of_p2_holdings      = pledge_total / p2_shares * 100

pct_of_combined_holdings = pledge_total / combined_holdings * 100
```

実行結果:

```
担保合計: 370,000(みずほ) + 250,000(りそな) = 620,000株
提出者2保有株数に対する比率:        620,000/1,180,000  = 52.5424%
発行済株式等総数に対する比率:        620,000/12,187,300 = 5.0873%
2者合計保有(1,907,200株)に対する比率: 620,000/1,907,200  = 32.5084%
```

**評価**:

- ジュノー（都木聡の資産管理会社）は自社保有株の**過半（52.54%）**を担保に供している。
  代表取締役社長の実質保有株の相当部分が金融機関の与信管理下に入ったことを意味する。
- 発行済株式等総数対比では5.09%と絶対的には大きくないが、**単一の株主・単一のイベント（同日付）
  で発生した担保設定としては規模が大きい**。
- **報告義務発生日（2026年7月31日）は、07/31の逆行安（日経平均+4.03%に対し-2.76%・出来高3.09倍、
  T2の成立日）と同日である。** ただし担保設定＝売却ではなく、担保設定自体が当日の株価下落の
  直接原因になったとは考えにくい（担保設定は市場外の相対取引であり売り注文を伴わない）。
  むしろ因果は逆方向の懸念——**急落や含み損の拡大が先にあり、それに対応する形で金融機関が
  追加担保を求めた、または借入継続の条件として担保を差し入れた**——という仮説も成立しうるが、
  契約の背景・条件（LTV・担保維持率・借入使途）は本報告書に記載がなく**取得不能**であり、
  どちらの因果かは断定しない。
- **将来リスクとしての意味**: 担保株式は、株価が一定水準を割り込んだ場合の追加担保請求
  （マージンコール）や、最悪の場合の担保処分（強制売却）の対象となりうる。これは**新たな
  需給テールリスク**であり、T7が本来想定していた「機関投資家の分売」とは異なる経路
  （インサイダー・支配株主の与信リスク）から生じる潜在的な将来供給圧力である。

## 5. T7の調査目的への回答（07/31逆行安＝機関投資家の分売仮説の検証）

   ことのみである**（両者の「最近60日間の取得又は処分の状況」欄が空欄）。
3. **したがって本報告書が否定できるのは「都木聡・ジュノーの2者による売却」だけであり、
   AM One・Invescoを含む他の株主（真の機関投資家）による07/31の売却の有無については、

4. **むしろ本報告書は「機関投資家の分売」という当初の仮説とは独立の、新たな事実（担保契約）を

   3章で述べた別種のリスク情報として扱う。

**結論**: T7は形式的に成立し、条文が求める精読・評価は実施したが、**07/31逆行安の機序（機関投資家
